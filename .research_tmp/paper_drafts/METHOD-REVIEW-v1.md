## 1. CRITICAL（2 条）

### C-1 【A 数字/行为对账】3.7 写入闸行为描述与代码不符，连带动摇 3.8 "四级链条全部机器可复检"卖点

- 原文（3.7）："写入闸——笔记行的回指标识必须命中**工具观察中出现过的标识**，无效行拒写并返回教学信息……"；原文（3.8）："笔记锚点经写入闸约束到记录标识……四级链条全部机器可复检。"
- 代码事实（harness `run_question`）：`valid_ids = set(REC_INDEX) | {manifest 全部 paper_id} | {注册表全部 canonical+aliases}`，再并入本题运行中观察到的 id。即写入闸校验的是"标识属于**知识库标识全集**（含注册表实体名）"，**不是**"在本题工具观察中出现过"。模型引用一条真实存在但从未被观察到的记录 id，闸会放行。"copied verbatim from tool observations"只是 NOTES_SPEC 里对模型的提示语，不是闸的执行语义。
- 后果：这是论文最强卖点（可溯源四级链）的地基描述；照发即方法陈述不实，且审稿人复现代码即可戳穿。
- 修法：3.7 改为"写入闸——笔记行的回指标识必须命中知识库标识全集（记录标识、论文标识、注册表规范名与别名）；无中生有的标识拒写并返回教学信息……"。3.8 第二级链条相应改为"笔记锚点经写入闸约束到**真实存在的**记录标识"，并可加半句如实限定："写入闸复检的是标识存在性，观察出处由提示协议约束"。若论文坚持"观察内命中"强口径，则须改代码——超出本评审范围，但二选一必须做，不能文实分离。

### C-2 【B/F 禁语 F10 精神】3.2 预实验归因句：无归置，且测量口径疑似与审计档案颠倒

- 原文（3.2 决策三末尾）："分轨使'谁说的'与'说了什么'正交存储，避免了将转述数值误作一手结果的绑定错误——**这类错误在预实验中被测量为自由文本记录形态下的主要缺陷来源**。"
- 问题：(1) 全句无任何归置（不指向实验章/审计档案），是方法章里的裸实验结果断言，违反任务 F 类纪律与 F10 精神；(2) 口径疑点：记忆档案链（B3 离线审计→J1 重判）记载"绑定错误主缺陷实锤"的确认语境是 **B′ typed-tools 臂**（typed 记录形态，tools adjusted 2.84），而草稿把它安到"**自由文本记录形态**下"——方向可能正好写反；flat（自由文本）臂的档案失败模式是渲染算术墙/材料覆盖率，不是绑定错误主缺陷。
- 修法：先核对 J1/离线审计原始档案确认测量语境。若确认口径是 typed-tools 臂，删除"自由文本记录形态下"，改为"预实验审计将绑定错误定位为主要缺陷来源（归因与口径详见实验章）"；若另有档案支撑自由文本层读数，补上具体归置。核不实则整句降为设计动机表述（"分轨的设计动机是杜绝将转述数值误作一手结果"），删去"被测量为"。

## 2. MAJOR（8 条）

### M-1 【A 数字对账】引文纪律豁免范围与 schema 不符，且章内三处互相矛盾

- 原文（3.2 决策一）："**除纯否定性的缺席记录外**，每类记录必须携带不超过 40 词的原文引文……"
- schema 事实：`QUOTE_REQUIRED_KINDS` 含全部七类+overflow；注释明确"absence: quote required for **explicitly_stated / cannot_tell**；仅 not_reported 以 `evidence` 字段承担举证"。即豁免只覆盖 absence 的一个状态，不是整类。
- 章内矛盾：同节决策二自己写"explicitly_stated（论文自述未做——**这是带引文的文献知识**）"，而表 3-1 absence 行字段又只列"对象、缺失内容、缺席类型、证据"（无引文）——一句话内三处口径打架。
- 修法：决策一改"除 not_reported 状态的缺席记录（以 evidence 字段承担举证）外，每类记录必须携带……；explicitly_stated 与 cannot_tell 缺席同样要求引文"。表 3-1 absence 行补"引文（not_reported 态豁免，以证据字段代之）"。

### M-2 【A/D 数字+结构】"四种视图"与 build_views 实际产物不符；shift 与 notation 两类记录无消费路径

- 原文（3.1/3.5）："将记录编译为**四种视图**"；"四种视图对应四类高频访问负载"（对比矩阵、谱系、覆盖地图、方法卡）。
- 代码事实（`views/compiler.py: build_views`）：返回 `matrix, genealogy, coverage, cards, narrative, pair_deltas, notation_index, stats`——除四种主视图外还有叙事（含 shifts、family_lines）、成对差值、符号索引三个派生产物，且 `render.py` 将 narrative/pair_deltas 一并渲染。连带问题：七类记录中 **shift 与 notation 在 3.5/3.6 的视图与工具面上没有任何被消费的路径**（代码里它们恰好由 narrative 视图与 notation_index 承接——草稿漏掉的正是这两个产物）。
- 修法：二选一。(a) 如实扩数："四种主视图（……）之外，另派生叙事时间线（承接 shift 记录）、成对差值与符号索引（承接 notation 记录）等编译产物"；(b) 若坚持"四视图"叙事，须在 3.5 明说"其余派生产物不进入 agent 访问面"并解释 shift/notation 记录如何被消费——否则"每一类文献问题都有一个类型化的落点"（3.2 首句）对这两类不成立。

### M-3 【B/F1 邻接+F10 精神】3.1 开头的失效集中断言无限定、无归置

- 原文（3.1 首句）："智能体在科学文献上执行跨论文任务时，**失效并不集中在'读不懂单篇论文'，而集中在**文献信息的组织形态与访问方式上……"
- 问题：这是无限定的实证断言。E2-R2 修正档案明文：强模型（Qwen3.8-Max 关思考）直读 4.00/聚合 4.33，"直读也失效"只在中端模型档与规模档成立（F1 违例原因栏）。方法章开篇即以无限定形态复述被推翻的口径，是审稿人第一句就能攻击的位置。
- 修法：加档位限定+归置，例如"中端模型档的实测显示，失效按信息分散度分层而非集中于单篇理解（规模档退化与算术墙证据详见实验章）"；或整体降为设计动机句式（"本方法的出发点是三类访问负载的观察……实证依据见实验章"）。

### M-4 【B/F10 精神】3.7 "实测通病"句：无引用、无归置

- 原文（3.7）："缺口清单连续闭合而模型仍继续检索时，循环注入停止指令——**自判停止过晚是文献 agent 的实测通病**，停止纪律因此由循环强制而非由模型自觉。"
- 问题："实测通病"是对整个文献 agent 群体的经验概括，既无外部引文也无自家实验归置。harness 头注明确 H1-H8 参数"carry survey sources"，且 H2 的本地证据是 pilot cap-hit 100%（自家观测，不是领域通病）。
- 修法：引预注册 H2 所携 survey 来源作【引注】，或改为自家口径："试点观测中模型自判停止普遍过晚（步数触顶率见实验章），停止纪律因此由循环强制"。

### M-5 【B/F10 精神】3.5 "个位数百分比"数字本地档案无支撑

- 原文（3.5）："该原则来自一个**实测教训**：渲染截断使下游可见覆盖率**跌到个位数百分比**，智能体在残缺视图上的失败被误诊为检索能力问题（归因详见实验章）。"
- 问题：归置指针有（合格），但具体数字对不上档案：B3 离线审计的读数口径是"材料覆盖率 50%（142 未查到+119 截断）"，未见"个位数百分比"的对应读数。方法章引一个实验章可能不承接的数字，等于自己埋雷。
- 修法：与离线审计档案/实验章逐字核对；若实验章承接的确是个位数口径，保留并在实验章给出同一读数；若承接的是 50% 口径，此处删数字改定性（"渲染截断曾使下游可见覆盖率大幅塌陷"）。"实测教训"四字建议一并中性化（"该原则来自一次截断事故的归因分析"）。

### M-6 【D 逻辑】视图/工具命名漂移："as_of 视图"实为工具；"compare 视图"与"对比矩阵"不统一

- 原文（3.2）："时间类问题以 **as_of 视图**配合权威年份字段处理……"；"数值对比落在 result 与 **compare 视图**"。

- 修法：3.2 改"以 as_of 工具（3.6 节）"；全文统一"对比矩阵（compare）"，首现给中英对照后择一使用。

### M-7 【C 自包含】核心术语"带"（条件带/预算带/同带/分带）首现无定义，全章使用 6+ 次

- 原文（3.2 首现）："比较两个数值前必须**同带**（3.6 节第二招）"；此后"条件带""按预算带分块渲染""跨带错比""dims 同带""矩阵分带"贯穿 3.2/3.5/3.6。

- 修法：3.2 dims 段首现处加定义，例如："dims 中参与可比性判定的维度（预算档、协议环境等）构成记录的**条件带**（band）；'同带'指两条记录在选定维度组上的取值一致，带的划分由词表仲裁冻结"。

## 3. MINOR（19 条）

### N-1 【A】数值闸豁免描述不全
原文："专名与系统常量经豁免表放行"。代码（IL-C1/IL-C3）另有：年份豁免、数学/LaTeX 上下文豁免、边界保护（<2 位数字不算claim）、markdown 标题行跳过。修法："年份、专名数字、系统常量与公式上下文经豁免规则放行"。

### N-2 【A】兜底路径与代码两级兜底不符
原文："兜底路径将笔记编译为散文答案后提交，**不交白卷亦不交原始笔记**"。代码：散文编译失败/退化时仍回退提交原始笔记（raw-notes last resort）。修法："兜底路径优先将笔记编译为散文答案；仅当编译产物不可用时退化为附说明的原始笔记提交"。

### N-3 【A】"笔记是循环的唯一记忆/历史轨迹不进入提示"存在例外
代码每步提示注入已查询清单（最近 14 条签名）、缺口清单与最新观察。修法："除最新观察、缺口清单与已查询清单外，历史轨迹不进入提示；笔记是唯一的内容性记忆"。

### N-4 【F】"上下文长度与步数解耦"过强
笔记本身全量重写但跨步累积，上下文仍随步数增长（只是不随对话历史线性增长）。修法："上下文增长由受验证的笔记主导，而非随对话历史无界累积"。

### N-5 【A】"工具在本地确定性执行、零模型调用"对 search 不成立
search 兜底的查询向量需嵌入模型调用（`embed_cst`）。修法："八个类型化工具本地执行、零模型调用；search 的查询向量由冻结嵌入器产生"。

### N-6 【D】"四道确定性验证闸"的分组是论文叙述口径，与代码自述不同
harness 头注将答案侧验证器自述为三闸（write-time/numeric/citation lock），anti-loop 与 budget-exhaust injection 是循环控制机制。草稿把四者行为都描述准确了，仅分组命名不同。修法：可保留四闸分组（论文叙事权），建议加一个脚注说明分组口径，或改"三道验证闸与一组反循环控制"。

### N-7 【A】记录质量旗标整体缺失
schema v1.1 RC8：`QUALITY_FLAGS = (suspect_binding, parse_warning, figure_only)`，且明文"render layer **MUST** surface these"；harness find_gap 描述也带"+ flags"。方法章 3.2/3.5 无一字。修法：3.2 公共字段处补一句（记录携带质量旗标，渲染层必须透出），或 3.5 类目完整性原则旁补。

### N-8 【A】3.4 "语料内首现论文"字段口径需核
harness 中 `in_corpus_paper_id` 的语义是"语料内有全文的论文"（prompt 中 * 号=full text in corpus），不是"首现"。修法：对照注册表 builder 字段语义统一措辞（若确为首现论文则保留，若是有全文论文则改）。

### N-9 【D】3.8 "答题提示不含领域硬编码"与主臂提示词残留领域示例有张力
MAIN_SYSTEM 招六含 "DQN-family"/"value-based" 示例（IL-P6 已 genericize 自我描述，但示例仍带语料域色彩）。修法：提示词示例泛化，或 3.8 措辞精确为"不含领域硬编码的语义规则（提示中仅保留少量示例性类目词）"。

### N-10 【D】3.2 "降格为可判定的字符串问题"与 3.8 "保真下界而非语义完备性"张力
引文存在性是可判定的必要条件，不是忠实的充分判定；3.8 自己承认了下界性质。修法：3.2 加限定"降格为可判定的字符串**必要条件复检**"。

### N-11 【D】表 3-1 overflow 注与 3.3 残差队列段近复
