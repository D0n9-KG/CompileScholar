# 3 方法：需求驱动的类型化科学文献知识库

## 3.1 设计动机与总体架构

智能体在科学文献上执行跨论文任务时，直接阅读原始文本的空间受两侧挤压：中端模型档的实测显示，答题失效按信息分散度分层，信息散落于多篇论文的聚合类问题最难（档位限定与规模档退化证据见实验章）；而语料规模增长时，整读上下文成本线性上升直至超出窗口上限。更根本的是，三类访问负载在直读范式下没有稳定载体：同一方法在不同预算条件下的数值散落于多篇论文的表格与正文，比较两类方法需要跨越若干论文拼装证据，而"某对比在语料中不存在"这类否定性事实没有任何可检索的形态。本章描述的方法针对这三类负载设计一个位于原始文献与智能体之间的知识层：将论文语料编译为带溯源的类型化记录，在记录之上派生确定性视图，并以类型化工具与一个带验证器的 ReAct 式（推理与工具调用逐步交替）循环向智能体提供访问。

方法的设计原则是访问负载驱动而非资产形态驱动。数据库领域的经验是，存储结构由查询负载决定（列存之于分析查询）；本方法采取同一立场：记录类型、条件维度与工具面均由"智能体会问什么"反向推出，而非由"论文里有什么"正向堆叠。这一原则带来两个直接后果。其一，知识层的每一项结构都必须能指认它服务的访问负载，无负载支撑的结构在治理环中作为删除候选（3.4 节）；其二，语料内容的表达力优先于图结构的形态美观——知识库表达的是论文断言的类型化内容，而不是以实体-关系三元组为最终形态的图。

总体架构如图 3-1 所示，由四个部分组成。记录层（3.2 节）以七类类型化记录承载论文内容，每条记录携带逐字引文与条件维度；抽取管线（3.3 节）以大模型切片抽取加确定性后检链的方式生产记录，并以金丝雀度量（按已知地面真值构造的合成哨兵论文，见 3.3 节）监测抽取保真；治理环（3.4 节）在语料批次之间对实体注册表与维度词表做版本化演进，运行时冻结；访问层（3.5–3.7 节）将记录编译为主视图与派生产物，经九个类型化工具与七招动作手册暴露给推理循环，循环内的笔记协议与验证闸全部为确定性规则。

## 3.2 类型化记录层

记录层的设计目标是让智能体的每一类文献问题都有一个类型化的落点：数值对比落在 result 记录与对比矩阵（3.5 节），条件追问落在条件维度，谱系追问落在 lineage 记录，而"没人做过什么"落在 absence 记录。一条记录由公共字段与类型专属字段构成。公共字段六项：记录标识、来源论文标识、类型、文内位置、认识状态（epistemic）与条件维度组（dims）；记录另可携带质量旗标（疑似绑定错误、解析告警、仅图来源），渲染层有义务将其透出而非静默吸收。类型专属字段如表 3-1 所列，共七类记录加一个残差类型。

【表 3-1：七类记录的类型语义与必填字段。result=数值结果（方法引用、度量六元组、结果角色、引文）；config=配置事实（方法引用、条目、取值、引文；条目涵盖超参数、组件架构参数与协议项，角色含 best_reported/default/used_in_experiment/protocol）；finding=定性结论（断言、强度、引文；可选主张子类型：机制/批评/定义/建议/定性消融/观察）；absence=缺席事实（对象、缺失内容、缺席类型、证据；explicitly_stated 与 cannot_tell 两态另需引文）；lineage=方法间关系（源方法、关系、目标方法、证据基础、引文；关系词表九项：extends/improves/uses/component_of/replaces/compares_with/motivated_by/generalizes/concurrent_with）；shift=范式迁移（源状态、目标状态、驱动因素、引文）；notation=符号定义（符号、定义、引文）；overflow=残差（原因、引文）。】

记录层有三项关键设计决策。

第一，逐字引文纪律。每类记录必须携带不超过 40 词的原文引文（表格类记录以"行头+列头+单元格"拼接为引文），数值必须逐字抄自引文而非改写。唯一豁免是缺席三态中的 not_reported——"未见报告"无从引证，其举证责任由证据字段（检索过程与范围）承担；explicitly_stated 与 cannot_tell 两态的缺席仍要求引文。引文是记录与原文之间唯一可机器复核的锚点：后检链以归一化字符串匹配验证引文真实存在于源文本（3.3 节），答题期的数值闸以引文锚点验证答案数字有据（3.7 节）。这一纪律将"大模型抽取是否忠实"降格为可判定的字符串存在性复检——它是忠实的必要条件而非充分条件（3.8 节），但足以拦截凭空生成与错位改写两类主要失真。

第二，缺席三态。absence 记录区分 not_reported（语料中未见报告——这是语料库状态，换语料会变）、explicitly_stated（论文自述未做——这是带引文的文献知识）与 cannot_tell（证据不足以判断）。三态区分的先例来自循证医学的证据缺口实践【引注：Cochrane Handbook for Systematic Reviews of Interventions 对"无证据/证据表明缺席/证据不足"的区分指令；3ie Evidence Gap Maps 框架】，本方法将其计算化为记录层的一等公民：find_gap 工具按三态分别返回，动作手册禁止智能体在措辞上混用两类缺席（3.6 节）。否定性事实在传统抽取范式中没有载体，而在"某方法是否在某条件下被评测过"这类问题上恰恰是答案本身。

第三，认识状态分轨。每条记录标注 epistemic ∈ {stated, demonstrated, cited}：论文自述的、论文用实验证明的、论文转述他人的。cited 记录是转述而非一手证据，动作手册第一招要求智能体对其追源（3.6 节）；时间类问题以 as_of 工具（3.6 节）配合年份双轨字段处理——时序权威取预印本年（时间戳首现原则），发表年用于叙述展示，两者同时给出以消解预印本与正式版的时间分歧。分轨使"谁说的"与"说了什么"正交存储，其设计动机是杜绝将转述数值当作一手证据、将转述结论当作一手发现。

条件维度组 dims 承载"在什么条件下成立"：六个维度中 subject（评测对象）与 setup（协议环境）、variant（方法变体）为显式词表维度，值经注册与仲裁进词表；budget（算力/帧数/步数预算）、repeats（种子数）、hyperparam（数值超参）为类型化维度，值带单位开放生长。其中参与可比性判定的维度（协议环境、预算档等）共同构成记录的条件带（band）："同带"指两条记录在选定维度组上取值一致，带的划分随词表仲裁冻结。result 记录的度量采用六元组（指标、数值、单位、方向、聚合方式、时点），其中方向与聚合方式两个字段直接服务跨论文数值对比的可比性判定：比较两个数值前必须同带（3.6 节第二招），聚合方式不一致的数值（如中位数与均值）不得直接对比。

## 3.3 抽取管线与确定性验证

抽取管线的输入是解析后的论文全文与论文卡片（题目、作者、机构、图表清单的骨架抽取产物），输出是记录集合、残差队列与实体候选队列。管线分四步：确定性切块、切片注入的大模型抽取、确定性后检与修复、金丝雀度量。

切块与切片注入。切块边界由文本结构确定性给出，同一输入永远得到同一分块。模式（schema）体积与单次提示解耦：每块按其内容特征路由到相关记录类型的模式切片，而非将全部七类模式灌入每次调用——切片注入使模式扩展不推高单次提示长度，这是记录类型能够随治理环生长而不失控的工程前提。

抽取与后检。大模型对每块产出候选记录，quote-first 纪律要求先抄引文再填字段。后检链完全确定性、零大模型：引文经空白归一、LaTeX 命令折叠与表格行列头拼接规则映射回原文，验证逐字存在；答案数值必须能在引文内定位；枚举字段对照闭合词表；必填字段按类型核验。未过检记录进入修复通道按同样协议重抄一次，仍未通过者丢弃并计数——丢弃率与修复率作为管线健康指标随批报告。块级调用失败进入重试队列，保证语料覆盖不因网络或解析抖动出现空洞。

金丝雀度量。每批抽取随跑一篇合成金丝雀论文：五个已知事实加四个已知陷阱（否定翻转、转述状态翻转、条件丢失、近邻数值错绑），以零大模型的规则判分。金丝雀的作用是分离两类退化——真实论文上抽取质量下降，可能源于语料难度变化，也可能源于管线自身回归；金丝雀分数只反映后者。

残差队列。无法归入七类的内容以 overflow 记录入队而非丢弃，队列在治理环中聚类仲裁：有信号的簇升格为模式扩展（3.4 节），无信号的簇留档。这一出口保证了"类型化"不以静默丢信息为代价——记录层对语料的覆盖率是可审计的。

## 3.4 实体注册表与治理环

类型化记录的绑定质量取决于一个受控词表：实体注册表。注册表收纳四类实体（方法、机制、实践、语料外对象），每个实体带规范名、别名集、表面名索引、语料内全文锚定论文与被引起源年份。表面名索引将抽取中出现的名称变体解析到唯一实体，是记录间可连接（同一方法在不同论文的记录可聚合）与工具可寻址（entity 参数必须命中注册表名）的基础。

治理环按三个时钟运行，三者的分离是本方法演化机制的核心纪律。运行时时钟：一次答题会话内注册表与词表完全冻结，智能体永远面对确定的语义。语料间时钟：一个语料批次的抽取结束后，实体候选队列（抽取中未能解析到既有实体的表面名）经批量映射去重，产出新实体候选与变体归并建议。版本间时钟：候选经仲裁成为注册表新版本——仲裁是人工决策点，其政策在本文实验域内包括：方法变体与组件组合不入注册表而改道 variant 维度词表（防止注册表被变体名淹没），基准与环境名改道 setup 词表，具名机制实体入籍，泛称与引用残渣丢弃。仲裁产物版本化冻结，作答实验只允许引用已冻结版本，保证任何一次实验的语义环境可复现。

词表生长遵循"组合不造新概念"的纪律【引注：XBRL Dimensions 1.0 规范的维度建模惯例】：新的表面名优先解释为既有实体与既有维度值的组合，只有跨语料复现的具名概念才升格为实体（残差簇到显式条目的升格机制在材料科学文献库建设中已有同型先例【引注：Materials Explorer, arXiv:2606.27384】）。与之对偶，治理环包含减法议程：每轮仲裁前对既有实体与维度值跑填充率与引用率审计，零使用的条目列为删除候选。加法与减法同议程处理，抑制词表膨胀。

## 3.5 编译视图

视图层是记录集合的确定性函数：给定记录层与注册表版本，视图可整体重编译，不存在独立于记录的状态。四种主视图对应四类高频访问负载。对比矩阵（compare）以（方法 × 指标）为轴聚合 result 记录，单元格携带数值、条件带与认识状态，且按预算带分块渲染——不同预算带的数值在物理上不进入同一表格，从呈现层阻断跨带错比。谱系视图对 lineage 记录做传递闭包，支持"某方法的祖先与后代"类追问。覆盖地图以实体×主题聚合记录存在性并叠加 absence 三态与质量旗标，服务"哪些方法在哪些条件下没有被评测"类负载。方法卡档案按实体聚合其全部记录（配置、结果、结论、谱系），是广度题的入口结构。主视图之外，编译另产出三个派生产物：叙事时间线（承接 shift 范式迁移记录）、成对差值表（跨论文数值差的可比对）与符号索引（承接 notation 记录）——七类记录在视图面上各有消费路径。

视图渲染遵循类目完整性原则：渲染产物必须覆盖记录层中该类目的全部条目，超预算时显式分块而非静默截断。该原则来自一次截断事故的归因分析：渲染层的静默截断曾使大量记录对下游不可见，而智能体在残缺视图上的失败在初期被误诊为检索能力问题（归因过程与读数见实验章）。

## 3.7 推理循环与确定性验证器

答题循环采用 ReAct 形态：每步产出笔记、缺口清单与一个动作（工具调用）或最终答案。循环的三项机制针对长程文献任务的特有失败模式设计。

笔记协议与受控上下文。笔记是循环的唯一内容性记忆：每一步全量重写，除最新观察、缺口清单与已查询清单外，历史轨迹不进入提示。笔记行有固定模式——N 行携带回指标识（记录标识或论文标识）、结论陈述、逐字锚点与条件；被新证据推翻的结论改写为 X 行保留痕迹而非抹除。受控上下文将长程任务的增长项从对话历史转移到受验证的笔记上：上下文增长由笔记主导，而非随对话历史无界累积。

确定性验证闸。验证器全部为规则实现、零大模型判定，其设计依据是：文献任务中验证器的失败模式集中在协议层而非智力层，规则闸可复检、可归因、无裁判噪声（运行期账本形态的验证器近邻见【引注：LedgerMind, arXiv:2607.28374】，本方法为编译期记录层形态，划界见相关工作章）。本章将四组机制统称验证闸，其中前三道作用于笔记与答案内容，第四组作用于循环行为。写入闸：笔记行的回指标识必须命中知识库标识全集（全部记录标识、论文标识、注册表规范名与别名），无中生有的标识拒写并返回教学信息；标识真实存在但未被本题观察到的情形予以放行，"逐字抄自观察"作为证据规范由提示协议约束。连续拒写触发断路器，将仍无效的行以"无据"标记自动收录而非让循环死锁，无据行的数值在答案闸被禁引。数值闸：答案中每个数值必须存在于笔记锚点，年份、专名数字、系统常量与公式上下文经豁免规则放行，少于两位的数字不构成断言。引用锁：含数值的断言句必须携带论文标注。反循环组套：同参数查询签名去重，观察指纹重复超限即终止检索，连续两步笔记零增量触发回滚与换角度指令，步数预算耗尽注入强制作答指令。

步数预算与收敛。预算按题型两档（广度题与精确题），剩余步数逐步可见。缺口清单连续闭合而模型仍继续检索时，循环注入停止指令——试点观测中模型自判停止系统性过晚（步数触顶率见实验章；停止纪律的文献依据见循环参数调研档案【引注：H2 条，react_loop 预注册档案】），停止纪律因此由循环强制而非由模型自觉。预算耗尽仍未产出规范答案时，兜底路径优先将笔记编译为散文答案；仅当编译产物不可用时退化为附说明的原始笔记提交，不交白卷。

## 3.8 方法性质与边界

本方法的三项性质由构造保证。可溯源性：答案中每个数值断言经引用锁与数值闸约束到笔记锚点，笔记锚点经写入闸约束到真实存在的记录标识，记录经逐字引文约束到论文文内位置——链条各级均为机器可复检（其中写入闸复检的是标识存在性，观察出处由提示协议约束，见 3.7 节）。可演化性：模式、注册表与词表的每次变更都是版本化的仲裁产物，任何实验的语义环境可由版本号精确复现。域无关性：抽取与答题提示不含领域硬编码的语义规则（仅保留少量示例性类目词），记录类型的语义由字段结构而非领域词表承载；域知识全部位于经仲裁的词表层，换域等价于换词表与重跑治理环（跨域实证见实验章）。

边界同样由构造决定。知识层为文本形态，图表内容以卡片清单与表格行记录承载，图像本体不入知识库，依赖图像证据的任务超出方法边界；记录层有构建成本，其摊销分析（构建投入随查询次数的盈亏平衡）见实验章；抽取质量是访问质量的天花板，后检链与金丝雀度量的是保真下界而非语义完备性。
