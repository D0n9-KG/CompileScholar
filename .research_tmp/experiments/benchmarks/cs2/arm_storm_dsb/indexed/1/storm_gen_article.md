# summary

The Key-Value (KV) cache is a foundational optimization in Transformer-based Large Language Models (LLMs) that eliminates redundant recomputation of past token representations during autoregressive generation, significantly reducing computational overhead for efficient inference.[1][2] However, the memory footprint of the KV cache scales linearly with both sequence length and batch size, creating a severe scalability bottleneck that quickly dominates GPU memory usage.[3][1] As production LLMs expand context windows to support applications such as agentic workflows and deep research, this linear growth imposes critical constraints on GPU memory capacity, memory bandwidth, and inference throughput.[1]
The challenge is further exacerbated by the quadratic computational complexity of Multi-Head Self-Attention (MHSA) mechanisms, which remains a fundamental bottleneck in scaling LLMs for long-context tasks.[4] While sparse and linearized attention mechanisms attempt to mitigate this complexity, they often compromise the representation of global dependencies or fail to capture multiscale semantic granularity effectively.[4] Consequently, efficient KV cache management has become a first-order challenge for scalable LLM deployment, with recent research organizing optimization techniques into five principal directions: cache eviction, cache compression, hybrid memory solutions, novel attention mechanisms, and combination strategies.[1]
To address these limitations, various methodologies have been proposed to optimize KV cache usage without significantly degrading model quality. For instance, ManifoldKV introduces a training-free scorer that ranks tokens by Euclidean distance to the key centroid, improving robustness in multi-key retrieval scenarios compared to traditional cosine similarity-based eviction methods.[5] Similarly, Low-Rank Key-Value (LRKV) attention reduces KV cache memory by exploiting redundancy across attention heads, achieving equivalent baseline quality with only 45–53% of the standard Multi-Head Attention (MHA) KV cache footprint.[6] Other approaches, such as TTKV, draw inspiration from human memory systems by partitioning the KV cache into temporal tiers with heterogeneous capacity and precision, decoupling fast and slow memory using High Bandwidth Memory (HBM) and Dynamic Random-Access Memory (DRAM).[2]
Beyond software-level optimizations, hardware architectures are also being reimagined to handle the memory bandwidth constraints imposed by the KV cache. Conventional inference architectures suffer from high energy and latency due to frequent data movement across memory hierarchies; to counter this, systems like Ouroboros propose wafer-scale SRAM-based Computing-in-Memory (CIM) architectures that execute operations in situ, eliminating off-chip migration and achieving significant gains in throughput and energy efficiency.[7] Furthermore, emerging non-volatile memory (NVM) technologies offer high capacity and low energy compared to traditional storage, presenting potential solutions for the dichotomy between DRAM and durable storage in large-scale data processing.[8] These diverse approaches collectively aim to balance the trade-offs between memory efficiency, computational cost, and model performance in the era of long-context LLM inference.

# Overview

The Key-Value (KV) cache is a foundational optimization in Transformer-based Large Language Models (LLMs) that eliminates the redundant recomputation of past token representations during autoregressive generation.[1] By storing the key and value vectors of previously processed tokens, the KV cache significantly reduces computational overhead, making it critical for efficient inference.[2] However, the memory footprint of the KV cache scales linearly with both sequence length and batch size, creating a severe scalability bottleneck that quickly dominates GPU memory usage.[3][1] As production LLMs push context windows from thousands to millions of tokens to support applications such as agentic workflows and deep research, this linear growth imposes critical constraints on GPU memory capacity, memory bandwidth, and inference throughput.[1]
The challenge is further exacerbated by the quadratic computational complexity of Multi-Head Self-Attention (MHSA) mechanisms, which remains a fundamental bottleneck in scaling LLMs for long-context tasks.[4] While sparse and linearized attention mechanisms attempt to mitigate this complexity, they often compromise the representation of global dependencies or fail to capture multiscale semantic granularity effectively.[4] Consequently, efficient KV cache management has become a first-order challenge for scalable LLM deployment, with recent research organizing optimization techniques into five principal directions: cache eviction, cache compression, hybrid memory solutions, novel attention mechanisms, and combination strategies.[1]
To address these limitations, various methodologies have been proposed to optimize KV cache usage without significantly degrading model quality. For instance, ManifoldKV introduces a training-free scorer that ranks tokens by Euclidean distance to the key centroid, capturing both angular and radial deviations to improve robustness in multi-key retrieval scenarios compared to traditional cosine similarity-based eviction methods.[5] Similarly, Low-Rank Key-Value (LRKV) attention reduces KV cache memory by exploiting redundancy across attention heads, achieving equivalent baseline quality with only 45–53% of the standard Multi-Head Attention (MHA) KV cache footprint.[6] Other approaches, such as TTKV, draw inspiration from human memory systems by partitioning the KV cache into temporal tiers with heterogeneous capacity and precision, decoupling fast and slow memory using High Bandwidth Memory (HBM) and Dynamic Random-Access Memory (DRAM).[2]
Beyond software-level optimizations, hardware architectures are also being reimagined to handle the memory bandwidth constraints imposed by the KV cache. Conventional inference architectures suffer from high energy and latency due to frequent data movement across memory hierarchies; to counter this, systems like Ouroboros propose wafer-scale SRAM-based Computing-in-Memory (CIM) architectures that execute operations in situ, eliminating off-chip migration and achieving significant gains in throughput and energy efficiency.[7] Furthermore, emerging non-volatile memory (NVM) technologies offer high capacity and low energy compared to traditional storage, presenting potential solutions for the dichotomy between DRAM and durable storage in large-scale data processing.[8] These diverse approaches collectively aim to balance the trade-offs between memory efficiency, computational cost, and model performance in the era of long-context LLM inference.

# Workload Characterization

Understanding the specific patterns of Large Language Model (LLM) workloads is critical for optimizing serving systems, particularly regarding Key-Value (KV) cache management. Recent studies have moved beyond synthetic benchmarks to characterize real-world workload patterns, revealing that traditional assumptions about cache reuse and request structures are often insufficient for production environments.

## Reuse Patterns and Predictability

Systematic characterization of KV cache workloads from leading LLM service providers indicates that KV reuses are skewed across requests, with reuses between single-turn requests being equally important as those in multi-turn conversations.[9] While the reuse time and probability appear diverse when considering all requests collectively, the patterns tend to be predictable when analyzed within specific request categories.[9] This predictability suggests that workload-specific optimizations can be more effective than generic approaches. Furthermore, real-world LLM workloads exhibit long reuse distances and sparse local recurrence, rendering traditional cache replacement signals based on limited-window statistics, such as recency and frequency, less robust.[10]

## Evolution of Request Interfaces

The nature of LLM requests is evolving beyond simple chat completion to include inference-time scaling, deep reasoning, and Retrieval-Augmented Generation (RAG). To generalize these diverse use cases, researchers have introduced the concept of "span queries," which express chat, RAG, inference-time scaling, and agentic workloads as expression trees.[11] A critical distinction in these workloads is whether the order of inputs matters; in chat scenarios, inputs generally do not commute, whereas in RAG, they often do.[11] This structural difference has significant implications for how inference servers are optimized and how KV caches are managed across different application types.

## Memory and Computational Constraints

The scaling of LLM services faces significant cost and latency challenges, making effective caching under tight capacity constraints crucial.[10] Long-context inference is particularly constrained by KV-cache memory, which grows linearly with sequence length and batch size, quickly dominating GPU memory usage.[3] This is exacerbated in Large Vision Language Models (LVLMs), where high-resolution input data generates massive amounts of visual tokens, aggravating the quadratic complexity of attention mechanisms.[12] Consequently, memory optimization strategies must account for the fact that for reasoning models, the KV cache rather than model size can dominate memory requirements.[13]

## Impact on Scheduling and Sustainability

The unpredictability of LLM execution and the heterogeneity of workloads pose challenges for scheduling policies. Traditional first-come-first-serve (FCFS) scheduling suffers from head-of-line blocking and long job response times, necessitating new frameworks that can estimate execution times to assign appropriate job priorities.[14] Additionally, the environmental impact of LLM inference is becoming a major concern, with operational costs potentially exceeding training costs by 25x per year and significant water usage per request.[15] These factors drive the need for workload characterizations that not only optimize for latency and throughput but also for energy efficiency and sustainability.

# Optimization Strategies

The deployment of Large Language Models (LLMs) and Large Vision Language Models (LVLMs) faces significant challenges due to the massive computational and memory requirements associated with the Key-Value (KV) cache, particularly as context windows expand and input sequences grow longer [16][12]. To mitigate these constraints, researchers have developed a variety of optimization strategies spanning compression, caching mechanisms, system-level scheduling, and architectural modifications.

## Compression and Quantization

Compression techniques aim to reduce the memory footprint of the KV cache without significantly degrading model performance. Traditional methods often rely on fixed heuristics or fixed-precision quantization, which can be inefficient as they may waste bits on low-impact tokens while over-compressing informative ones [17][18]. To address this, adaptive approaches have been proposed. For instance, adaptive KV-cache quantization utilizes a learned policy to assign bit-widths proportional to token importance, inspired by Huffman coding principles, thereby minimizing expected memory and latency while maintaining competitive accuracy [18].
Reinforcement learning (RL) has also been applied to create elastic pruning frameworks. RAP, for example, is an RL-driven framework that dynamically adjusts compression strategies in a runtime-aware manner [17]. It tracks the evolving ratio between model parameters and the KV cache, recognizing that Feed-Forward Networks (FFNs) house most parameters while attention layers dominate KV-cache formation [17]. By retaining only components that maximize utility within memory constraints, such frameworks can better adapt to heterogeneous KV-cache demands arising from diverse user requests [17].

## Caching Mechanisms and Eviction Policies

Efficient management of the KV cache is critical for reducing redundant computation and improving serving efficiency. Prefix caching is a common technique that reuses KV cache for previously processed tokens, but it is limited by strict prefix matching requirements [19]. To overcome this, Position-Independent Caching (PIC) enables chunk-level reuse at arbitrary positions, though it requires selective recomputation and positional-encoding adjustments [19]. However, without page alignment, chunk KV layouts can diverge in memory, preventing effective page sharing [19].
Cache eviction policies are another area of active research. Existing policies, whether heuristic or learning-based, often rely on limited-window statistics such as recency and frequency, which may not be robust for real-world LLM workloads characterized by long reuse distances and sparse local recurrence [10]. The Relation-Aware Cache (RAC) addresses this by leveraging semantic relations among requests to guide eviction decisions [10]. RAC synthesizes signals such as Topical Prevalence, which aggregates access evidence at the topic level to capture long-horizon reuse, and Structural Importance, which leverages local intra-topic dependency structures to discriminate entries by their future reuse potential [10].

## System-Level and Hierarchical Caching

As the storage footprint of long-context caches exceeds GPU memory capacity, production systems increasingly adopt hierarchical caching across memory hierarchies [20]. However, transferring large cached contexts back to the GPU can introduce severe performance bottlenecks due to fragmented I/O from paged layouts and schedulers that fail to account for cache-loading delays [20]. Strata is a hierarchical context caching framework designed to address these issues by introducing GPU-assisted I/O to combat KV cache fragmentation and employing cache-aware request scheduling [20]. This approach decouples GPU and CPU memory layouts, helping to keep systems compute-bound rather than loading-bound [20].
In multi-device clusters, communication overhead between GPUs or NPUs can significantly increase inference latency [21]. The PRESERVE framework addresses this by prefetching model weights and KV-cache from off-chip High Bandwidth Memory (HBM) to the on-chip cache of AI accelerators during communication operations [21]. This prefetching strategy offers performance improvements by overlapping communication with compute more effectively than prior methods, demonstrating up to 1.6x end-to-end speedup on state-of-the-art LLMs [21].

## Decoding and Serving Architectures

Optimization strategies also extend to decoding algorithms and serving architectures. For Video-LLMs, where inference latency increases with input sequence length, the Sparse-to-Dense (StD) decoding strategy integrates sparse top-K attention and dense full attention modules [22]. The fast sparse model speculatively decodes multiple tokens, while the slow dense model verifies them in parallel, achieving significant speedups without loss of accuracy [22].
Furthermore, serving systems are evolving to handle diverse workloads beyond simple chat completion. The introduction of "span queries" generalizes the interface to inference servers, allowing chat, Retrieval-Augmented Generation (RAG), inference-time scaling, and agentic workloads to be expressed uniformly [11]. This generalization highlights that the critical distinction between these workloads often lies in whether input orders commute, which impacts KV cache hit rates and optimization strategies [11]. Additionally, streaming-aware systems like Stream2LLM address the tension between retrieval latency and time-to-first-token by overlapping context retrieval with inference, using adaptive scheduling for concurrent prefill-decode disaggregated deployments [23].

# Evaluation and Performance

The evaluation of KV cache optimization strategies is increasingly complex, moving beyond simple memory reduction metrics to assess the impact on generation quality, latency, and robustness across diverse workloads. A significant challenge in benchmarking these methods is the inadequacy of traditional metrics, such as perplexity on short-text evaluations, which often fail to capture the nuances of long-context performance[24]. Consequently, recent studies emphasize the need for more convincing evaluation frameworks that account for the specific characteristics of real-world LLM workloads, including long reuse distances and sparse local recurrence[10].

## Impact on Generation Quality and Accuracy

Optimizing KV cache memory often involves a trade-off between efficiency and model accuracy, particularly when employing aggressive compression or eviction techniques. Traditional eviction strategies, which discard less critical key-value pairs based on attention scores, frequently lead to notable accuracy degradation, context loss, or hallucinations, especially under high compression ratios[25][26]. To mitigate this, advanced frameworks have introduced more sophisticated selection criteria. For instance, ManifoldKV, a training-free scorer that ranks tokens by Euclidean distance to the key centroid, achieves 95.7% accuracy on the RULER benchmark at 4K-16K contexts with 20% compression[5]. This method demonstrates superior robustness compared to cosine-based baselines, particularly in multi-key retrieval tasks, where it reduces directional collisions and achieves 92.4% accuracy on 3-key NIAH at 50% compression, outperforming KeyDiff by 15.4 points[5].
In multimodal scenarios, the evaluation of KV cache merging strategies must account for distributional biases across modality tokens. FlowMM, an adaptive framework for cross-modal information flow-guided merging, addresses these biases by dynamically applying layer-specific strategies and introducing a sensitivity-adaptive token matching mechanism[26]. This approach aims to preserve contextual integrity while merging low-risk tokens, thereby maintaining generation quality in complex multimodal reasoning tasks[26]. Similarly, NACL proposes a general framework for long-context KV cache eviction that operates in a single operation during the encoding phase, combining accurate attention score statistics with diversified random eviction to achieve more optimal performance than methods relying on biased local statistics[24].

## Latency and Computational Efficiency

Beyond accuracy, the computational efficiency of KV cache management is a critical performance metric, particularly for applications demanding low latency and high throughput. The memory footprint of the KV cache grows linearly with sequence length, batch size, and model size, creating a significant bottleneck in long-context scenarios[25][20]. Techniques such as RoPE-Aligned Pruning (RAP) address this by pruning entire RoPE-aligned column pairs to preserve the 2x2 rotation structure of Rotary Positional Embeddings (RoPE), thereby restoring the absorption of latent KV states into downstream weights[27]. Evaluations on LLaMA-3-8B and Mistral-7B models show that RAP enables a joint reduction of KV-Cache, attention parameters, and FLOPs by 20-30%, while reducing attention latency to 83% during prefill and 77% during decoding compared to baselines[27].
Speculative decoding (SD) offers another avenue for lossless acceleration, but its effectiveness in long-context scenarios is often limited by the mismatch between short-context training and long-context inference[28]. State-of-the-art SD methods trained on texts fewer than 4k tokens face performance degradation and excessive memory demands from draft models due to large KV caches[28]. To overcome this, new approaches focus on optimizing tree attention mechanisms and managing the memory overhead of draft models to ensure that the acceleration benefits are maintained even as context lengths extend[28].

## System-Level and Serving Optimizations

At the system level, the performance of KV cache management is evaluated in the context of serving efficiency and cost. The scaling of LLM services faces significant cost and latency challenges, making effective caching under tight capacity constraints crucial[10]. Existing cache replacement policies, which rely on limited-window statistics such as recency and frequency, have been shown to be not robust for real-world LLM workloads[10]. In response, Relation-Aware Cache (RAC) proposes an online eviction strategy that leverages semantic relations among requests, synthesizing signals such as Topical Prevalence and Structural Importance to guide eviction decisions[10]. This approach aims to improve the hit rate and overall serving efficiency by capturing long-horizon reuse patterns that traditional heuristics miss[10].
Furthermore, the integration of KV cache optimizations with broader system designs is essential for practical deployment. Surveys in the field highlight the need for comprehensive understanding of how algorithmic modifications, such as token eviction and quantization, interact with system-level changes to achieve efficient LLM serving[16]. The evaluation of these integrated systems often requires balancing multiple dimensions, including visual token compression, memory management, and advanced decoding strategies, particularly in the context of Large Vision Language Models (LVLMs) where quadratic attention complexity exacerbates memory constraints[12].

# Discussion

The characterization of Key-Value (KV) cache workloads in production environments reveals significant deviations from patterns observed in synthetic benchmarks, necessitating a reevaluation of current system design assumptions. A primary finding is that KV cache reuse is highly skewed across requests, with reuses between single-turn requests proving to be as critical as those in multi-turn conversations [9]. While the reuse time and probability appear diverse when considering the entire request population, specific request categories exhibit predictable patterns, suggesting that workload-aware optimization strategies can be effectively tailored to distinct user behaviors [9].
These empirical observations highlight the limitations of traditional cache replacement policies, which often rely on limited-window statistics such as recency and frequency. In real-world LLM workloads, which are characterized by long reuse distances and sparse local recurrence, these conventional signals are not robust [10]. To address this, advanced eviction strategies like Relation-Aware Cache (RAC) have been proposed, leveraging semantic relations among requests to guide decisions. By synthesizing signals such as Topical Prevalence and Structural Importance, such methods can better capture long-horizon reuse and discriminate entries based on future utility, thereby improving cache efficiency under tight capacity constraints [10].
The implications of these findings extend beyond simple caching mechanisms to broader architectural and scheduling challenges in LLM serving. The quadratic computational complexity of Multi-Head Self-Attention (MHSA) remains a fundamental bottleneck, driving the development of novel attention mechanisms like Grouped Cross Attention (GCA) and Multiscale Aggregated Hierarchical Attention (MAHA) to handle long contexts without prohibitive memory costs [29][4]. Furthermore, the efficiency of inference is heavily influenced by hardware-level optimizations and system-level scheduling. For instance, frameworks like PRESERVE mitigate communication overheads by prefetching model weights and KV caches to on-chip memory, while speculative schedulers in systems like ALISE reduce head-of-line blocking by estimating job execution times [21][14].
Additionally, the deployment of LLMs in heterogeneous cloud environments introduces further complexity, requiring scheduling algorithms that accommodate diverse GPU types and fluctuating network conditions, as seen in systems like ThunderServe [30]. The environmental impact of these intensive inference operations is also a growing concern, with studies indicating that the cumulative carbon footprint of the operational phase can far exceed that of training, prompting the development of sustainability-focused frameworks like SLIT [15]. Finally, emerging hardware architectures, such as the wafer-scale SRAM-based Computing-in-Memory (CIM) design Ouroboros, aim to eliminate off-chip data migration, offering substantial gains in throughput and energy efficiency for KV cache management [7]. Collectively, these developments underscore the need for a holistic approach to LLM serving that integrates workload characterization, algorithmic innovation, and hardware optimization.
