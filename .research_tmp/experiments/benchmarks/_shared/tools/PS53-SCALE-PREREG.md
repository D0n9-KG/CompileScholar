## 1. 假设与科学问题

**规模假设**：预编译 KB 的优势是语料规模条件性的——语料太小（16 篇）检索平凡，优势被抹平（dev30 打平 −0.073 已诊断为伪影）；语料放大到检索非平凡（53 篇），"编译一次+结构化精准访问"的优势应当显现。

**检验逻辑**：同一 53-KB（同抽取模型 Qwen3.6-27B、同管线版本、同判分），唯一变量=可访问语料规模 {16, 53}，2×2 因子设计隔离规模效应。

## 4. KB 状态与 round2 处置（推荐+披露，待用户确认）

**推荐：round2 实体生长 = OFF（主跑）**。理由：
- entity_queue 实测 **9551 条**（vs PS16 时代 211 条），全量生长成本高且主体是干扰篇实体；
- gold 题全部锚定 16 gold 篇，干扰实体不需要 dossier 级覆盖；
- 规模操纵的核心要求（干扰篇在检索面构成噪声）已由记录层满足：matrix 302→1026 表、search/compare 全量可达；
- 代价（如实披露）：distractor37 的 method_ref 实体链接率仅 **6.3%**（gold16 为 46.3%），干扰篇在 cards/coverage 层不可见——ours53 臂的干扰是"记录级噪声"而非"全层噪声"，对 ours 略偏有利，写进披露。若审稿级别需要对称，round2 全量生长后重编 views 作敏感性分析（成本另估报批）。

**其余披露项**：①slot 抽取 seed registry 是 Sep 9 旧版（pre-F33/F34），views 用 v35_f34 修复版（记录 canonical 经 F34 扫描 PS 侧 0 条需修）②第 53 篇 aJx9onwsR4 skeleton 失败被优雅跳过，实际建库 52 篇（干扰篇，不影响 gold）③manifest53=16 全字段+37 简字段 ④建库全账 15.78M/2532 calls 全 PURE Qwen3.6-27B，帽 20M 内。

## 5. 判据（批准后冻结，paired bootstrap 95% CI，n=30）

记 D53 = mean(ours53 − A9-53) 逐题配对差；D16 = mean(ours16 − A9-16)；ΔD = D53 − D16（交互）。

- **规模收益成立**：ΔD CI 下界 > 0 且 D53 点估计 > 0
- **部分成立（忠实规模赢）**：D53 CI 不含零且 > 0，但 ΔD CI 跨零 → 报告为"53 篇忠实规模下赢"，交互作用降探索性
- **不成立**：D53 点估计 ≤ 0，或 D53 与 ΔD CI 均跨零且点估计均 ≤ 0 → 规模假设失败，触发定位回退讨论（ASSET-STATE §4 解冻条件联动）
- **灰区**：其余组合 → 冻结判读报用户，不自行解释
- **红线**（任一触发即停跑取证）：编造仲裁 FAIL / idle > 0 / 崩坏率 > dev30 历史带（ours 臂 hard_stop 对照 PSV5 基线）/ 成本超帽+10%

## 7bis. 追记（2026-09-16 晚，点火前操纵强度检查——零 token，发现设计缺陷）

**发现**：A9×53 臂的检索操纵**基本无效**。全量 dev30 题操纵检查（FileSearchEngine over corpus53，官方同款引擎+缓存）：
- top-3/top-5 干扰篇侵入 = **0/30 题全零**（A9 agent 默认 top_k=3 → 它实际看到的检索结果与 16 篇时完全相同）；
- top-10 侵入 61/300，其中单篇 uIppiU2JKP 占 29/30（广谱相似篇），其余零星；
- 根因：37 干扰篇是**跨主题随机 AI 论文**（bandits/diffusion 库/分子文法/deepfake…，manifest53 实查），而 dev30 题全部锚定人体姿态/部位检测主题族——嵌入检索把两个主题干净分开，语料 16→53 对 A9 检索难度≈无变化；
- 对我方臂：views 记录面 4269→17822、matrix 302→1026 表，干扰是**纯噪声无难度收益**（gold 题不需要干扰篇材料）→ 现设计的 2×2 对我方偏不利、对 A9 无操纵，**ΔD 交互判据在现语料上不可解释**。

**处置（判据重绑，防"在缺陷操纵上误杀假设"）**：
- **Stage 1a（现 53 语料）降级为单向探针**：本地 backend 下真金仅 judge ~0.3M。**解释规则冻结：赢（D53>0 且 CI 不含零）=强信号（带伤仍赢）；平/输=不可解释，不触发 §5"假设死"条款**。
- **§5 判据（规模收益成立/不成立/灰区）重绑到 Stage 1b = 硬负例干扰集版**：37 干扰篇换为**主题邻近硬负例**（从 corpus1 500 池按 dev30 题面相似度选取——仅用题面，gold-blind；池现只有 title+id，需补 abstract/PDF 获取+mineru 解析+3.6-27B 重抽 ~10M+A9 缓存重建）。选取协议与成本另附 v1.1。
- 本追记为设计缺陷披露+判据重绑，非判据软化：单向探针的解释规则与 1b 的正式判据都在点火前冻结。
- 附带学术价值（记录）：**"离主题语料增长≠检索难度增长"本身就是规模边界实验的方法学要点**（A 线查新：无人做过正确的边界分析——操纵检查是原因之一），可进论文实验设计节。

**工具资产**：a9_sanity53.py（操纵检查脚本，零 token 可复用于 1b 验收：硬负例版预期 top-5 侵入率显著>0）。
