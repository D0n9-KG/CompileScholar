## 1. 假设与科学问题

**主假设**：在科学文献多论文综合任务（跨论文对比/综合/机制/缺口负载）上，**预编译类型化知识层**（编译一次+确定性工具访问）优于**运行时检索式系统**（给定语料现读现答）。

**检验逻辑**：闭卷固定语料（430 篇 union 语料编译库）上，同题同判分对比：我方编译栈 vs 闭卷协议自跑的检索式代表系统（PaperQA2 / LightRAG，09-21 终局矩阵裁定）+ 已发表数字引用行（协议不同不混表，分层呈现）。

**次级问题（分析节，非主判据）**：①未预期负载子集的表现（"只能做题"攻击的实证回应）②typed 层净贡献（search-only 消融臂）③跨域迁移（结构在 AI 语料设计、bio/photonics 语料验证）。

## 2. 语料与 KB 协议

- **语料 = 108 题全部 ctxs 的去重并集**（终数，09-21 收口）：439 题名 → 436 身份解析（398 DOI + 80 arXiv，3 无身份）→ 432 获取成功（99.1%）→ **430 篇唯一全文就位**（两组语料条目各共享一个文件；4 篇不可达入披露）。渠道分布：Sciverse 167 / arXiv 91 / OpenAlex OA 43 / S2 OA 42 / Crossref link 39 / 本地 DOI 库 36 / 手动+浏览器 18。解析=mineru VLM（PDF）+ Sciverse .md 直拷；LSST Science Book（300 页/40MB）单独长超时解析（1.93M 字符）。**获取失败篇入披露清单，不静默替换。**
- **语料披露清单（v0.2 定稿）**：①4 篇不可达（Judging the Judges 无 DOI / Dispersion Compensation IEEE 2024 付费墙且同题不同文 / “210983829” 脏数据条目 / Electrochemical biosensors CRC 书章节）——影响约 4 题各 1 篇引用；②2 篇获取事故已修复（Speckle-OCT 与 On-chip nanoparticle 初次抓到的是 Erratum/Corrigendum 页——身份解析阶段拿到的 DOI 本身就是勘误条目的 DOI；经修正 DOI 重抓真身并解析，证据留存 corpus/short_md_quarantine/；获取链教训=题名验证防不住勘误页，因为其标题包含原题名）；③1 篇题名不一致沿承上程人工判定（基准题名 Strategies to enhance... EPR effects vs 实抓 Izci Chem Rev 2021，内容主题相符）；④两组语料条目各共享同一文件（Label-free nanoparticle detection / Laser cooling of nanomechanical oscillator——同文不同题录，判分 id_mapping 按 1文本→多ctx 处理）。
- **闭卷协议**：KB=union 语料全库（我们的论点形态：编译一次全库服务，不按题过滤）。合法性=官方 ctxs 是 abstract 级、我们做全文深编译是闭卷增强（先例=OpenScholar 自检索语料，协议差异如实披露）。
- **干扰池（待裁，两案）**：A 案（推荐）=不添加人工干扰，430 篇即全库（协议最干净、与题集自然对齐；检索挑战=每题从 430 选对 2-10 篇）；B 案=A+同域干扰池（PaperScope 经验复制，检验 findability 稳健性）。**推荐 A 案为主跑、B 案作可选稳健性臂**——待用户裁。
- **建库管线（v-next，全部本地 Qwen3.8-27B，零 API 成本）**：
  - skeleton 通读（含**章节语义图**新输出：每章节六分类标签，当类型路由主通道；正则兜底；ROUTE_STATS 仪表随建库报告）
  - registry 语料级合并+**round2 默认 ON**（PS-53 教训：OFF 的实体链接 6.3% 是 typed tools 可用性头号短板；链接率入建库门）
  - slot 深抽（分块路由走章节语义图）+ postcheck 五门（repair-not-kill）
  - **表格通道 F24+F35**（F35 以 `--canary --provider local` 形态先行金丝雀，G5 硬停线）
  - **公式通道 notation_harvest**（新：双形态公式扫描+四门；预期覆盖 40 公式/篇 → notation 收割，逐字纪律同槽位协议）

  - 视图编译（四视图+pair_deltas+notation_index）

## 3. 题集与判分（冻结条款）

- **主题集 = Multi-108 全量**（108 题，数据零损伤已审计）。题面按 subject 分布：cs_nlp 33 / photonics 30 / bio 20 / cs_hci 10 / biophysics 9 / physics 6。
- **判分三轨（官方协议逐字）**：
  1. **Citation F1（确定性）**：官方 extract_citations 正则（`[0]`/`[2,3]` 零起编号，对应各题 ctxs 序号）。**我方引用适配**：模型按现有纪律标 `[paper_id]`，判分走官方 id_mapping 钩子翻译 ctx 序号（官方为我们这类系统设计的通道；题外引用按官方机制丢弃=协议内处理，不钻空子）。
  2. **AutoAIS（本地 NLI 模型）**：osunlp/attrscore-flan-t5-xl，逐字对齐官方。
  3. **Rubric（Prometheus 本地模型）**：官方 rubric 逐字。
- **判分阵容**：GLM-5.3 单主判+官方逐字协议+κ=0.428 一次性披露（09-19 判分换装定案，沿承）。judging 走 Paratera（预估 ~2-3M tokens，108 题）。
- **对照数字（表结构，永不混表）**：
  - 引用行：OpenScholar Table 2（OS-70B Cite 54.7 / PaperQA2 47.2 / OS-8B 42.8 / Llama3-70B+OSDS 41.4 / OS-GPT4o 37.5 / GPT4o 0.7）——注明协议差异（开放检索 vs 闭卷）
  - 自跑行：闭卷协议下的 PaperQA2 / LightRAG（语料指定为本 union 语料）
  - 我方行：ours（全栈）
  - 消融行：search-only（同记录关 typed tools——见 §5）

## 4. 答题栈规格（Multi 适配层）

- **答案形态校准**：gold 答案 median 1695 字符、叙述文+列表（0/108 表格）——Multi 版 craft 条款按此校准（枚举化数字密集+长度带），首跑用 gold 探针验证（gold 答案原文交 judge 的天花板测量，复用 09-19 探针法）。
- **引用形态**：`[paper_id]` 回引纪律不动（笔记/答案两层关卡），判分翻译（§3.1）。**id_mapping 已建**（build_id_mapping.py，确定性桥 stem←m-hash←题名）：ctx 覆盖 642/647=99.23%（适配故障率 0.77% < 5% 红线；5 个未映射=4 篇不可达披露）。**实测数据形态**：647 ctx 中 118 条（18.2%）为题内同名重复条目（同文同 URL 不同摘要段）→ 88 组一文本对多 ctx 序号。**一对多展开策略**（全展开 vs 首序号）待 S2 接线时按官方 id_mapping 钩子语义裁定并记录——两案对 precision/recall 的影响方向相反，不预设。
- **A7 时机**（已落地）：连续 3 次类型化工具零命中→一次性 search_text 引导。
- **findings 窗口**（已落地）：IL-G2e-1 精益版（15 条全可见不触发收缩）。
- 行为闸（沿承+新增）：早杀=0 / 多 action 步>30% / search_text 使用率（对照"躺平监控"）/ rejects 分布 / **A7 引导触发率**（新仪表：引导后实际调用比例）。

## 6. 判据（批准后冻结，paired bootstrap 95% CI，n=108）

- **主判据**：Citation F1 配对差 ours vs 自跑对照（PaperQA2、LightRAG 各自配对）CI 下界 > 0 且点估计优势成立；rubric 分同向为辅证。两轨背离时以确定性 Citation F1 为主（rubric 偏差披露）。
- **次级判据**：①未预期子集（~38 道论坛口吻题，预注册分类清单）单独报分——与主集差异 < 阈值 = "只是做题"攻击的实证回应；②search-only 臂与 ours 差 = typed 层净贡献；③AutoAIS 归因质量。
- **红线**（任一触发停跑取证）：编造仲裁 FAIL / 空转早杀 > 历史带 / citation 适配故障率 > 5%（id_mapping 未命中率监控）/ 成本超帽+10%（本地零成本，仅判分计费）。
- **失败分支**：主判据不成立 → 败题归因四分类（抽取缺口/检索未达/答案编译/判分器风格）→ 修复方向按归因定，不盲目迭代。

## 7. 披露节（写作时全文呈现）

1. **模型代际**：我方建库/答题用 Qwen3.8-27B（2026 代）vs 引用行 2024 代模型（Llama3.1/GPT-4o）——代际差双向（他们的 SOTA 也是旧模型跑的），用代际定位不用参数量自贬。
2. **闭卷增强**：ctxs=abstract 级 vs 我方全文编译——协议差异明示。
3. **dev 迭代史**：我方答题栈曾在 PaperScope dev30 上迭代（六轮修复）——108 题从未参与任何迭代（真 held-out），此为与 PSV 时代的关键差异。
4. **图/公式通道状态**：公式通道进本实验（notation 收割）；数值图表通道未上（判据：败题归因指向"数据只在图里"再启动，本判据入档）。
5. **负载透明表素材**：每视图/工具的设计输入负载证据+本实验实测使用遥测并排（"为题设计"指控的透明化解）。
