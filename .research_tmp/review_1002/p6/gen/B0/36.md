**Related Works**

The rapid advancement of Large Language Models (LLMs) has driven significant research into efficient deployment strategies, particularly for resource-constrained environments. Early foundational models, such as GPT-4 [1], PaLM [2], and the LLaMA series [3][4], demonstrated that scaling parameters yields superior performance but imposes prohibitive computational and memory demands. These requirements typically necessitate data-center-grade hardware, creating a barrier for edge deployment where storage, power, and latency constraints are strict. Consequently, recent literature has focused on algorithmic optimizations, hardware-aware scheduling, and specialized accelerators to bridge this gap.

A primary avenue for reducing LLM inference costs involves model compression techniques, including quantization, pruning, and sparsity. Quantization reduces the bit-width of weights and activations to lower memory footprint and accelerate computation. For instance, LLM.int8() [12] enables 8-bit matrix multiplication, while SmoothQuant [14] addresses activation outliers to achieve accurate 8-bit weight and activation quantization with negligible accuracy loss. Similarly, pruning methods like SparseGPT [16] demonstrate that massive GPT-family models can be pruned to high sparsity levels in one-shot without retraining. Sparsity can also be exploited at inference time; DejaVu [13] leverages contextual sparsity to predict active attention heads and MLP parameters, significantly reducing latency. Furthermore, knowledge distillation offers a path to smaller, more efficient models. MiniLLM [18] and DistiLLM [17] propose improved distillation frameworks that preserve the generative capabilities of large teacher models in smaller student models, thereby reducing inference overhead.

Beyond static model compression, system-level optimizations focus on efficient memory management and resource scheduling. The key-value (KV) cache is a major bottleneck in LLM serving. PagedAttention [8] introduces a virtual memory-inspired approach to manage KV cache fragmentation, enabling high-throughput serving with vLLM. In distributed settings, ExeGPT [6] optimizes execution schedules to maximize throughput under latency constraints, while Splitwise [7] decouples the compute-intensive prompt processing from the memory-intensive token generation phase, allowing each to run on hardware best suited for its specific workload. For scenarios with limited memory, FlexGen [22] aggregates resources from GPU, CPU, and disk to run large models on a single commodity GPU, and "LLM in a flash" [9] utilizes flash memory to store parameters, optimizing data transfer patterns to run models exceeding DRAM capacity. PowerInfer [5] further exploits the power-law distribution of neuron activations to design a GPU-CPU hybrid engine, preloading "hot" neurons to the GPU for fast access.

For edge-specific deployments, algorithm-hardware co-design is critical to balance energy and latency. EdgeBERT [24] pioneered this approach for NLP tasks by employing dynamic voltage-frequency scaling (DVFS) and early exit mechanisms to minimize energy consumption on a 12nm accelerator. This concept of dynamic power management is supported by foundational work on variation-aware DVFS [26] and fast per-core DVFS using on-chip regulators [27]. More recently, NeuOS [28] proposed a latency-predictable optimization framework for DNN-driven systems, while Approxcaliper [25] provided a programmable framework for application-aware neural network optimization. A comprehensive review of these trends highlights the growing importance of LLM-hardware co-design and accelerator compilation [10].

Our work, CLONE, builds upon these foundations by integrating real-time energy optimization with model-level algorithms specifically for edge devices. Unlike server-centric approaches like ExeGPT [6] or Splitwise [7], CLONE targets the unique constraints of always-on edge computing, leveraging a 28nm scalable hardware accelerator to achieve significant speedups and energy savings while maintaining generative quality.
