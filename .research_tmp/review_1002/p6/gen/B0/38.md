**Related Works**

The challenge of achieving predictable timing in real-time systems has led to extensive research in partitioned scheduling and resource isolation. Early work on multiprocessor real-time scheduling established foundational strategies for assigning tasks to cores, highlighting the trade-offs between partitioned and global scheduling approaches [2][3]. More recently, partitioned scheduling of recurrent real-time tasks has been refined to improve utilization and predictability in complex systems [1]. However, these scheduling techniques often assume fixed execution times, which is an invalid assumption in modern architectures where execution time is heavily influenced by shared resource contention.

To mitigate interference, cache partitioning has emerged as a critical technique for hard real-time systems. Initial studies evaluated the impact of cache partitioning on multi-tasking embedded systems, demonstrating its potential to reduce worst-case execution times (WCET) [15]. Subsequent work provided a closer look at the effectiveness of cache partitioning, confirming its role in ensuring timing guarantees [13][14]. Recent advancements have focused on minimizing cache usage to further optimize resource allocation [16]. In the context of virtualization, real-time cache management has been adapted for multi-core environments to ensure isolation between virtual machines [4]. Furthermore, the interplay between cache sharing and isolation in mixed-criticality systems has been analyzed to balance performance and safety [19]. Hardware support for these techniques has also evolved, with specifications such as Arm’s Memory System Resource Partitioning and Monitoring (MPAM) providing standardized mechanisms for partitioning cache and memory resources [12].

Memory bandwidth regulation is another key component for performance isolation. MemGuard was introduced as a system for policing core memory bandwidth from outside the cores, enabling efficient performance isolation on multi-core platforms [7]. More recent developments include MemPol, which extends bandwidth policing capabilities [8], and dynamic memory bandwidth allocation strategies specifically designed for real-time GPU-based SoC platforms [17]. On commodity servers, coordinated partitioning of last-level cache and memory bandwidth has been explored to achieve fairness-aware workload consolidation [18]. Hardware-based solutions like Intel’s Resource Director Technology (RDT) have been evaluated for their ability to manage memory and cache resources, with recent studies providing a closer look at their practical implications [9][11].

The co-allocation of tasks and resources is essential because task execution times depend strongly on the available allocated resources. Holistic resource allocation for multicore real-time systems has been proposed to jointly optimize task placement and resource partitioning [10]. This holistic approach has been extended to multicore real-time virtualization, where both cache and memory bandwidth are considered [23]. For parallel real-time tasks under federated scheduling, holistic resource allocation strategies have been developed to handle the increased complexity [24]. Dynamic resource allocation for soft real-time multicore systems has also been investigated to adapt to varying workload demands [25].

Specific algorithms for co-allocation have been proposed to address the combinatorial nature of the problem. The $IA^3$ algorithm introduced an interference-aware allocation approach for multicore hard real-time systems [21]. PDPA proposed a period-driven task and cache partitioning algorithm to optimize multi-core systems [20]. More recently, a hybrid multi-layer design space exploration technique was proposed to co-optimize cache partitioning and multi-core task scheduling. This approach uses a breadth-first search in the outer layer, a first-fit heuristic in the middle layer, and recurrence relations for schedulability analysis in the inner layer, demonstrating the flexibility of such frameworks for different scheduling policies [22]. Additionally, strategies combining hardware management with mixed-criticality provisioning have been explored to address the one-out-of-m multicore problem [5]. While these works provide valuable insights, they often rely on mixed-integer programs or single-objective heuristics. Our work extends this line of research by proposing a 0-1 linear program and a multi-objective multi-layer heuristic that specifically targets the minimization of resource usage while guaranteeing schedulability under preemptive EDF, leveraging fine-grained partitioning enabled by the Jailhouse hypervisor and MemGuard.
