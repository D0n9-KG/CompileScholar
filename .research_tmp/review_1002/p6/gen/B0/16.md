Open-vocabulary object detection (OVOD) has emerged as a critical paradigm in computer vision, addressing the limitations of traditional closed-set detectors that are restricted to pre-defined categories [1]. By leveraging vision-language models, OVOD systems enable the detection of objects based on natural language descriptions, allowing for flexible and user-defined class vocabularies at inference time [1]. Early foundational work, such as CLIP, demonstrated that pre-training on large-scale image-text pairs allows for zero-shot transfer to various downstream tasks, including object recognition, by aligning visual and textual embeddings [2]. This capability has been extended to the detection domain through methods that map visual features to semantic spaces, enabling detectors to recognize novel classes without explicit supervision [1].

Recent advancements have focused on improving the alignment between image regions and textual concepts to enhance detection accuracy. RegionCLIP, for instance, addresses the domain shift inherent in applying image-level CLIP models to region-based tasks by pre-training on region-text pairs derived from template captions [7]. Similarly, CoDet reformulates region-word alignment as a co-occurring object discovery problem, leveraging visual similarities within groups of images that share specific concepts to improve localization accuracy and generalization [8]. These methods have significantly outperformed prior state-of-the-art approaches on benchmarks such as COCO and LVIS, particularly for novel categories [7][8]. Furthermore, the expansion of detector vocabularies has been facilitated by datasets like LVIS, which introduces a long-tail distribution of over 1,000 categories, and methods like Detic, which train detector classifiers on image-level classification data to support tens of thousands of concepts [4][6].

Despite these progressions, a significant challenge remains in the robustness of OVOD models when faced with overly broad or mis-specified user vocabularies. Existing detectors often exhibit variability in performance depending on the semantic granularity of the provided class list, which can hamper real-world deployment [9]. For example, including irrelevant or overly generic terms in the vocabulary can introduce noise and degrade detection precision. To mitigate this, SHiNe proposes a semantic hierarchy nexus that integrates super- and sub-categories from class hierarchies to generate more robust classifier vectors, thereby enhancing performance across diverse vocabulary granularities [9]. While SHiNe operates offline to refine class representations, our work, VocAda, complements these efforts by operating at inference time to dynamically tailor the user-defined vocabulary to the specific content of the input image.

The evaluation of these methods typically relies on standard benchmarks such as COCO and LVIS. COCO provides a foundational dataset with 91 object types in complex everyday scenes, serving as a common baseline for detection tasks [3]. LVIS extends this by focusing on large vocabulary instance segmentation, posing challenges related to the low-sample regime for rare categories [4]. Detic has demonstrated strong performance on these benchmarks, closing the gap between common and rare classes by leveraging large-scale image classification data [6]. Our experiments build upon these established benchmarks, demonstrating that VocAda consistently improves performance across three state-of-the-art detectors, validating its versatility as a plug-and-play solution for vocabulary refinement. By automatically discarding irrelevant classes based on image captions, VocAda addresses the specific issue of vocabulary mis-specification, offering a lightweight alternative to offline hierarchy-based methods like SHiNe [9].
