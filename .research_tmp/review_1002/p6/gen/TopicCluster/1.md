## Related Work

**KV Cache Reuse and Prefix Sharing**
Recent research has extensively explored mechanisms to exploit the redundancy inherent in LLM inference by reusing Key-Value (KV) states across requests. Early approaches focused on prefix sharing, where systems like ChunkAttention [2] and Prompt Cache [4] utilize prefix trees or modular attention reuse to share KV tensors for common system prompts, thereby reducing time-to-first-token latency. For multi-turn conversations, CachedAttention [3, 24] leverages cached attention states to maintain context efficiency, while EPIC [7] introduces position-independent context caching to further enhance serving performance. Beyond strict prefix matching, CacheBlend [6] extends reuse capabilities to Retrieval-Augmented Generation (RAG) scenarios by fusing precomputed KV caches of non-prefix text chunks, allowing for the reuse of knowledge without full recomputation. In contrast to these systems that primarily optimize for specific structural patterns or application domains, our work provides the first systematic characterization of KV cache reuse patterns in a production cloud environment, revealing that reuse is skewed across requests and that single-turn request reuses are as significant as multi-turn ones, insights that inform our workload-aware eviction policy.

**KV Cache Compression and Quantization**
To mitigate the memory footprint of KV caches, a parallel line of work focuses on compression and quantization techniques. StreamingLLM [8] exploits the "attention sink" phenomenon to enable infinite sequence length inference by retaining only a small set of initial tokens and recent context. H2O [9] identifies "heavy-hitter" tokens that contribute disproportionately to attention scores, prioritizing them for retention to reduce cache size. InfiniGen [10] employs dynamic KV cache management to speculate essential tokens and prefetch only necessary entries, optimizing offloading-based serving. PyramidKV [11] allocates cache resources based on pyramidal information funneling patterns, assigning more capacity to lower layers, while KVQuant [12] enables low-precision quantization for extremely long contexts (up to 10 million tokens) using per-channel key quantization and non-uniform datatypes. While these methods effectively reduce the per-request memory overhead, they operate at the token or layer level and do not address the system-level challenge of managing finite cache capacity across a diverse population of concurrent requests, which is the primary focus of our eviction strategy.

**LLM Serving Systems and Memory Management**
The development of efficient LLM serving systems has been driven by the need to manage large memory footprints and high concurrency. vLLM [1, 23] introduced PagedAttention, a virtual memory-inspired technique that manages KV cache memory in non-contiguous blocks, achieving near-zero memory waste and significant throughput improvements. SGLang [5] further advances this domain by providing a programming framework that optimizes LLM serving through efficient compilation and execution of complex model programs. These systems establish the foundational infrastructure for high-throughput serving but typically rely on standard or simple eviction policies when cache capacity is exceeded. Our work complements these systems by providing a deep characterization of the workload patterns that these systems must handle, demonstrating that generic memory management strategies are insufficient for optimal performance under real-world, skewed reuse patterns, and proposing a specialized eviction policy to enhance their efficiency.

**Cache Replacement Algorithms and Serverless Workloads**
The design of effective cache replacement policies has a rich history in database and operating system research, with algorithms ranging from simple heuristics to adaptive and learning-based approaches. Classic algorithms such as LRU-K [13] and 2Q [14] aim to balance recency and frequency, while adaptive policies like EELRU [15], LRFU [16], and LIRS [17] refine these metrics to improve buffer cache performance. More recent developments include self-tuning algorithms like ARC [18] and CAR [19], which adapt to workload changes with low overhead, as well as improvements to the Clock algorithm such as CLOCK-Pro [20]. Additionally, LHD [21] maximizes hit density, and Cacheus [22] applies machine learning to optimize replacement decisions. In the context of cloud computing, Serverless in the Wild [25] characterized production FaaS workloads to optimize resource management, highlighting the importance of workload-specific insights. Unlike these general-purpose cache algorithms, which are often designed for static or predictable workloads, our study characterizes the unique, diverse, and skewed reuse patterns of KV caches in LLM serving, showing that a workload-aware policy tailored to these specific patterns outperforms generic replacement strategies, particularly under limited cache capacity.
