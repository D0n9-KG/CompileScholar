## Related Work

### Cache Partitioning and Management for Real-Time Systems
Cache partitioning is a fundamental technique for mitigating interference and ensuring timing predictability in real-time systems. Early studies evaluated the effectiveness of cache partitioning in hard real-time contexts, analyzing its impact on worst-case execution times and system reliability [13, 14]. Subsequent work examined the broader implications of these strategies on multi-tasking embedded systems and proposed methods to minimize cache usage to further reduce interference [15, 16]. In virtualized environments, techniques such as cache-coloring have been implemented to optimize memory access patterns and reduce interference between virtual machines [6], while other approaches focus on real-time cache management to guarantee predictable performance in multi-core virtualization settings [4]. More recent research has explored the tradeoffs between cache sharing and isolation in mixed-criticality systems [19] and proposed period-driven algorithms for jointly partitioning tasks and cache resources [20]. Furthermore, hybrid multi-layer design space exploration techniques have been developed to co-optimize cache partitioning and multi-core task scheduling, exploiting cache sensitivity to improve schedulability [22]. In contrast to these approaches, which often treat cache partitioning in isolation or with limited co-allocation strategies, this paper integrates cache partitioning into a comprehensive multi-objective framework that jointly optimizes task and resource allocation to minimize overall resource usage while guaranteeing schedulability.

### Memory Bandwidth Allocation and Isolation
Memory bandwidth is a critical shared resource that can significantly impact the timing behavior of real-time tasks. To address this, several mechanisms have been proposed for policing and regulating memory bandwidth usage. MemPol, for instance, polices core memory bandwidth from outside the cores to regulate resource usage [8], while MemGuard introduces a reservation system designed to achieve efficient performance isolation on multi-core platforms [7]. In the context of heterogeneous systems, dynamic memory bandwidth allocation has been proposed to ensure real-time performance on GPU-based System-on-Chip platforms [17]. Additionally, coordinated partitioning schemes, such as Copart, have been introduced to jointly manage last-level cache and memory bandwidth for fairness-aware workload consolidation on commodity servers [18]. While these works focus on the isolation and regulation of memory bandwidth, they often do not address the complex co-allocation of tasks and multiple resource types simultaneously. This paper extends this line of work by incorporating memory bandwidth regulation via MemGuard into a holistic optimization problem that considers both cache and bandwidth constraints alongside task scheduling.

### Hardware Resource Partitioning and Monitoring Technologies
The feasibility of software-based resource partitioning relies heavily on underlying hardware support for resource management and monitoring. Intel’s Resource Director Technology (RDT) enables software to partition and monitor shared resources such as cache and memory bandwidth [9], with detailed evaluations highlighting its functionality, performance, and limitations [11]. Similarly, the Arm Memory System Resource Partitioning and Monitoring (MPAM) specification defines mechanisms for partitioning and monitoring memory system resources in Arm-based systems [12]. These hardware technologies provide the necessary primitives for implementing fine-grained resource control. Our work leverages such hardware capabilities, specifically utilizing the Jailhouse hypervisor on an AMD UltraScale+ platform to enable fine-grained cache set partitioning and memory bandwidth regulation, thereby providing the physical basis for the optimization algorithms proposed in this paper.

### Task Scheduling and Holistic Resource Allocation
Task scheduling and resource allocation are tightly coupled in multicore real-time systems, where execution times depend on the available resources. Partitioned scheduling algorithms have been developed for recurrent and sporadic real-time tasks to ensure deadline adherence on multiprocessor systems [1, 3], with new strategies introduced to improve assignment efficiency and feasibility [2]. To address the complexity of resource management, holistic approaches have been proposed for allocating resources in multicore real-time systems to ensure predictable performance [10]. More advanced techniques include interference-aware allocation algorithms for hard real-time systems [21] and dynamic resource allocation methods for soft real-time multicore systems [25]. Recent work has extended holistic allocation to multicore real-time virtualization [23] and parallel real-time tasks under federated scheduling [24]. Additionally, the one-out-of-m multicore problem has been addressed by combining hardware management with mixed-criticality provisioning [5]. While these studies provide robust frameworks for task scheduling and resource allocation, they often rely on mixed-integer programming or single-objective heuristics. This paper contributes to this area by proposing a 0-1 linear program and a multi-objective multi-layer heuristic that outperforms existing mixed-integer programs and state-of-the-art co-allocation algorithms in terms of optimality, schedulability, and computational efficiency.
