## Related Work

**Data Lake Management and Table Join Discovery**
Recent advancements in data lake management have focused on optimizing the discovery and integration of heterogeneous data sources, with a particular emphasis on identifying joinable tables to facilitate complex analytical workflows [1]. To address the challenge of finding tables that can be joined, JOSIE employs overlap set similarity search to efficiently identify joinable pairs within large data lakes [2]. More recently, DeepJoin leverages pre-trained language models to embed columns into a vector space, enabling accurate and efficient discovery of both equi- and semantic joins by capturing deep semantic relationships between table attributes [3]. While these methods effectively handle structural and semantic joinability, they primarily focus on pairwise table relationships rather than direct natural language-driven retrieval of specific tables from a repository, a gap that our work addresses by unifying indexing and search for NL queries.

**Table Retrieval and Question Answering**
A substantial body of research has been dedicated to table retrieval and question answering, evolving from keyword-based matching to deep semantic understanding. Early approaches, such as ad hoc table retrieval using semantic similarity, utilized supervised learning models to combine various semantic representations and similarity measures for matching keyword queries with tables [9]. The advent of deep contextualized language models, particularly BERT, transformed this field; for instance, one study applied BERT to ad hoc table retrieval by encoding table content with structural awareness and jointly training it with features from prior literature [10]. In the domain of question answering, TAPAS introduced a weakly supervised table parsing approach that answers natural language questions by directly predicting denotations through cell selection and aggregation [7]. For open-domain settings, dense retrieval systems have been developed to improve retrieval quality and end-to-end QA results compared to traditional BERT-based retrievers [6]. Furthermore, frameworks like GTR have proposed generalizable natural language table retrieval using multi-granular graph representation learning to capture complex table layouts and structures [8]. In the context of data lakes, Starmie offers an end-to-end framework for dataset discovery using contrastive learning to train column encoders from pre-trained language models, enabling effective table union search [4]. Additionally, Solo introduces a self-supervised approach for data discovery that allows users to write natural language questions by assembling training datasets without human intervention, outperforming state-of-the-art keyword search systems [5]. Although these methods achieve remarkable accuracy using the traditional dense vector search pipeline, they often suffer from error accumulation during representation and indexing phases and limited query-table interaction, limitations that Birdie mitigates through a differentiable search index.

**Generative Retrieval and Differentiable Search Indexes**
The paradigm of generative retrieval has emerged as a powerful alternative to traditional vector search, utilizing neural networks to directly generate document identifiers. The Differentiable Search Index (DSI) pioneered this approach by using a single Transformer model to encode corpus information in its parameters and directly map string queries to relevant document identifiers [11]. Similarly, the Neural Corpus Indexer (NCI) proposed an end-to-end sequence-to-sequence network that generates relevant document identifiers for queries to improve recall performance in document retrieval [12]. To address the data distribution mismatch inherent in these models, DSI-QG was introduced, a framework that indexes documents using generated and re-ranked queries to better align the indexing process with retrieval [13]. More recently, CorpusLM has proposed a unified language model that integrates generative retrieval, closed-book generation, and RAG through a unified decoding process to tackle knowledge-intensive tasks and reduce hallucination [14]. Our work builds upon this line of research by adapting the differentiable search index paradigm specifically for table discovery, leveraging prefix-aware identifiers and synthetic query generation to enhance semantic alignment between natural language queries and table structures.

**Dynamic and Continual Learning for Generative Retrieval**
A critical challenge in deploying generative retrieval systems is the ability to handle dynamic corpora without catastrophic forgetting. DSI++ presents a method for updating the memory of Transformer-based search indexes with new documents, although specific mechanisms for mitigating forgetting are not extensively detailed in its primary summary [15]. To more robustly address this issue, CLEVER introduces a model for continual learning in generative retrieval that utilizes incremental product quantization and memory-augmented learning to index new documents in dynamic corpora without forgetting previous knowledge [16]. In this paper, we introduce an index update strategy via parameter isolation, which specifically targets the issue of catastrophic forgetting in the context of table discovery, demonstrating a reduction in forgetting by over 90% compared to other continual learning approaches.
