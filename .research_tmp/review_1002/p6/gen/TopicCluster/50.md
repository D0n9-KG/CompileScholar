## Related Work

**Knowledge Graph-Based ML/DL Recommendation**
Recent advancements in leveraging structured data for machine learning resource management have led to the development of knowledge graph (KG) based recommendation systems. [1] and [2] represent two distinct approaches within this domain, focusing on enhancing the granularity and applicability of recommendations for ML practitioners. Specifically, [1] proposes a description-enhanced knowledge graph to improve the accuracy of machine learning method recommendation by incorporating rich textual descriptions into the graph structure. In contrast, [2] focuses on task-oriented library recommendation, utilizing a knowledge graph to map specific user tasks to appropriate machine learning and deep learning libraries. While both works demonstrate the utility of KGs in narrowing down relevant ML resources, they primarily address the selection of methods or libraries for specific tasks. Our work extends this line of research by constructing HuggingKG, a large-scale knowledge graph derived from the Hugging Face community, which not only supports recommendation but also enables broader analyses such as tracing model evolution and classifying resources, thereby addressing the limitations of existing platforms that lack explicit structured representations.

**Cross-Platform Paper-Repository Matching**
Another significant area of research involves bridging the gap between academic literature and open-source code repositories. [3] introduces paper2repo, a system designed to recommend relevant GitHub repositories for academic papers. This approach maps paper and repository embeddings into a shared space using text encoding and graph convolutional networks, employing distant supervision to align the two domains. This work highlights the potential of cross-modal matching to facilitate the discovery of code implementations for theoretical research. In contrast to [3], which focuses on linking static academic papers to code, our study focuses on the internal ecosystem of the Hugging Face platform. By constructing HuggingKG, we enable more fine-grained interactions within the ML resource community, such as recommending datasets and tracing the lineage of models, rather than merely linking external papers to repositories.

**GitHub Repository Tagging**
The automatic classification and tagging of code repositories is another critical task for improving resource discoverability. [4] presents GRETA, a graph-based approach for assigning tags to GitHub repositories. By modeling the repository ecosystem as a graph, [4] leverages structural information to improve the accuracy of tag assignment. This work underscores the importance of graph structures in understanding the relationships between code artifacts. Our paper aligns with this perspective by utilizing a graph-based representation for the Hugging Face community. However, while [4] focuses on tagging repositories in a general coding context, our HuggingBench benchmark specifically targets the unique characteristics of ML resources, providing test collections for classification tasks that are tailored to the specific needs of the machine learning community, such as identifying model types and dataset categories within the Hugging Face ecosystem.
