**Related Works**

Efficient memory management is a critical challenge in Large Language Model (LLM) serving, primarily due to the substantial memory footprint of the Key-Value (KV) cache. PagedAttention, introduced in vLLM, addresses memory fragmentation and redundant duplication by borrowing virtual memory concepts from operating systems, enabling flexible sharing of KV caches within and across requests [1][23]. Similarly, SGLang provides an efficient programming model for LLMs that optimizes execution through structured generation [5]. While these systems focus on the fundamental mechanics of memory allocation and execution efficiency, our work shifts focus to the specific workload patterns that dictate how effectively these caches are utilized, rather than the underlying memory management primitives.

A significant body of research has explored KV cache reuse to accelerate inference by leveraging shared prefixes or common text segments. ChunkAttention detects matching prompt prefixes across requests and shares their KV tensors using a prefix tree structure to improve memory utilization and data locality [2]. Prompt Cache takes a modular approach, precomputing attention states for reusable text segments like system messages and templates, thereby reducing time-to-first-token latency [4]. For scenarios involving multiple context chunks, such as Retrieval-Augmented Generation (RAG), CacheBlend enables the reuse of precomputed KV caches even when the reused text is not a prefix, by selectively recomputing a subset of tokens to maintain generation quality [6]. EPIC further extends this by providing position-independent context caching, allowing for more flexible reuse of cached states [7]. In contrast to these approaches that assume specific structural overlaps or prefix sharing, our study characterizes the broader spectrum of KV reuse patterns in production environments, revealing that reuse is skewed across requests and that single-turn request reuses are as significant as multi-turn interactions.

Another line of work focuses on KV cache compression and eviction to handle long contexts and limited memory resources. StreamingLLM introduces the concept of "attention sinks," demonstrating that retaining the KV states of initial tokens allows models to generalize to infinite sequence lengths without fine-tuning [8]. H2O proposes a heavy-hitter oracle to identify and retain only the most important KV entries for generative inference [9]. PyramidKV leverages the observation that attention information flows through a pyramidal funnel, dynamically adjusting cache size across layers to retain only a small fraction of the full cache [11]. KVQuant addresses memory constraints through low-precision quantization of KV activations, enabling inference with context lengths up to 10 million tokens [12]. InfiniGen optimizes offloading-based systems by prefetching only essential KV entries based on speculative attention scores [10]. Unlike these methods that rely on static heuristics or layer-specific compression strategies, our work provides a systematic characterization of real-world workload patterns, showing that reuse probability and time are diverse overall but predictable within specific request categories, which informs the design of workload-aware eviction policies.

Finally, cache replacement policies have been extensively studied in the context of database and operating system buffer management. Classical algorithms such as LRU-K [13], 2Q [14], EELRU [15], LRFU [16], LIRS [17], ARC [18], CAR [19], and CLOCK-Pro [20] have established foundational techniques for balancing recency and frequency to maximize hit rates. More recent advancements include LHD, which maximizes hit density [21], and CacheUS, which uses reinforcement learning to adapt replacement policies [22]. In the cloud computing domain, characterizing production workloads has proven essential for optimizing resource management, as seen in studies of serverless FaaS workloads [25]. While these general-purpose cache policies provide a theoretical foundation, they have not been specifically tailored to the unique temporal and structural characteristics of LLM KV caches. Our paper bridges this gap by applying workload-aware insights from production LLM traces to propose an eviction policy that significantly improves serving performance under limited cache capacity, addressing the specific skew and predictability patterns observed in real-world LLM serving.
