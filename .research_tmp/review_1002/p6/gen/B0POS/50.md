### Related Works

The integration of knowledge graphs (KGs) into machine learning (ML) workflows has emerged as a critical area for enhancing resource management and recommendation systems. Early efforts focused on leveraging structured data to bridge the gap between unstructured code repositories and academic literature. For instance, paper2repo introduced a cross-platform recommender system that maps academic papers to relevant GitHub repositories by integrating text encoding with constrained graph convolutional networks [3]. This approach addressed the challenge of identifying similarity across different platforms without relying on human labeling, utilizing automatic labels derived from user actions. Similarly, GRETA proposed a graph-based method for assigning tags to GitHub repositories, aiming to improve the discoverability of open-source projects through structured metadata [4]. While these works established foundational techniques for linking code and text, they primarily operated within the general software development ecosystem rather than the specific domain of ML artifacts. In contrast, our work constructs HuggingKG, a domain-specific knowledge graph tailored explicitly for the Hugging Face community, capturing rich textual attributes and domain-specific relations that general-purpose code repositories do not inherently provide.

More recent research has shifted toward task-oriented recommendations specifically for ML and deep learning libraries. Task-Oriented ML/DL Library Recommendation utilizes knowledge graphs to suggest appropriate libraries based on specific user tasks, recognizing that the selection of ML tools is often driven by functional requirements rather than just code similarity [2]. This line of work acknowledges the complexity of the ML ecosystem, where dependencies and task compatibility are crucial factors in recommendation accuracy. However, these systems often rely on pre-existing, smaller-scale knowledge bases or focus narrowly on library selection without considering the broader ecosystem of models and datasets. Our study builds on this by expanding the scope to include not only libraries but also models and datasets within a unified graph structure, enabling more comprehensive resource management beyond simple library recommendation.

Furthermore, the application of description-enhanced knowledge graphs has been explored to improve method recommendation in ML. DEKR (Description Enhanced Knowledge Graph for Machine Learning Method Recommendation) demonstrates that incorporating detailed textual descriptions into the graph structure can significantly enhance the accuracy of recommending ML methods [1]. This approach highlights the importance of rich textual attributes in capturing the nuances of ML resources, which are often lost in purely structural representations. By integrating these textual details, DEKR enables more precise matching between user needs and available methods. Our work aligns with this emphasis on textual richness but scales it to a much larger extent. HuggingKG incorporates rich textual attributes for 2.6 million nodes, allowing for advanced queries and analyses that were previously infeasible due to data scale and structure limitations.

Despite these advancements, existing platforms like Hugging Face have not fully exploited structured representations for advanced analytical tasks such as tracing model evolution or recommending relevant datasets. Most prior work has focused on binary recommendation tasks or tag assignment, leaving a gap in the ability to perform complex, multi-step reasoning over the ML resource ecosystem. HuggingKG addresses this gap by providing a large-scale, structured representation that captures the dynamic relationships between models, datasets, and users. By introducing HuggingBench, a multi-task benchmark derived from this graph, we provide a standardized framework for evaluating IR tasks in this specific domain. Unlike previous studies that treated ML resources as isolated items, our approach models them as interconnected entities, enabling novel tasks such as tracing the lineage of model improvements and recommending datasets based on complex relational patterns. This shift from isolated item recommendation to graph-based relational reasoning represents a significant step forward in open-source ML resource management.
