**Related Works**

**Natural Language Table Discovery**
Natural language table discovery aims to retrieve relevant tables from large repositories based on textual queries. Early approaches focused on ad hoc table retrieval using semantic similarity, representing queries and tables in multiple semantic spaces to improve matching accuracy [9]. With the advent of deep learning, methods began leveraging pre-trained language models (PLMs) to capture complex syntactic and semantic relationships. For instance, BERT-based models were adapted to encode table content while considering structural constraints, significantly outperforming previous baselines [10]. More recent work has addressed the complexity of table layouts by converting tables into multi-granular graphs, allowing for better generalization across diverse structures [8]. In the context of data lakes, specialized systems have been developed for specific tasks such as joinable table discovery, where embedding-based retrieval using PLMs facilitates the identification of joinable columns [3], and dataset discovery, which employs contrastive learning to train column encoders for union search [4]. Additionally, self-supervised approaches have been introduced to mitigate the need for expensive labeled data by generating synthetic training pairs [5]. While these methods achieve high accuracy, they typically rely on a traditional dense vector search pipeline that separates representation, indexing, and search phases, leading to error accumulation and limited query-table interaction. In contrast, our work, Birdie, unifies these phases into a single encoder-decoder model to eliminate such errors and enable deeper semantic alignment.

**Differentiable Search Indexes and Generative Retrieval**
A paradigm shift in information retrieval has been driven by Differentiable Search Indexes (DSI), which encode corpus information directly into the parameters of a Transformer model [11]. This approach simplifies retrieval by mapping queries directly to document identifiers, bypassing the need for a separate index structure. Subsequent research has refined this paradigm by addressing data distribution mismatches between indexing and retrieval. For example, DSI-QG introduces query generation to bridge the gap between long document texts and short queries, improving retrieval performance [13]. Similarly, the Neural Corpus Indexer (NCI) proposes a sequence-to-sequence network that generates document identifiers, utilizing prefix-aware decoding and semantic identifiers to enhance recall [12]. These generative retrieval methods have also been extended to knowledge-intensive tasks, where unified language models integrate retrieval with generation to reduce hallucinations [14]. Although these frameworks demonstrate the power of parametric indexing, they are primarily designed for textual documents rather than structured tabular data. Our paper adapts this differentiable search index paradigm specifically for table discovery, assigning prefix-aware identifiers to tables and leveraging synthetic queries to facilitate effective query-table interaction within a unified language model.

**Continual Learning in Retrieval Systems**
Dynamic data environments require retrieval systems to continuously index new content without forgetting previously learned knowledge. Traditional continual learning approaches often suffer from catastrophic forgetting, where the model’s performance on old data degrades as it learns new data. In the domain of generative retrieval, recent works have addressed this by proposing mechanisms to incrementally update document identifiers and memory structures. For instance, CLEVER introduces incremental product quantization and memory-augmented learning to preserve knowledge of old documents while integrating new ones [16]. Other approaches focus on updating Transformer memory with new documents to maintain retrieval accuracy over time [15]. These methods highlight the importance of parameter isolation and adaptive updating strategies in dynamic corpora. However, most existing solutions are tailored for general document retrieval rather than the specific structural challenges of table repositories. Our work introduces a novel index update strategy via parameter isolation specifically for table discovery, which mitigates catastrophic forgetting by over 90% compared to other continual learning approaches, ensuring robust performance in dynamic table environments.
