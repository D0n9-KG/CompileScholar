**Related Works**

Real-time multiprocessor scheduling has long been a focus of research to ensure predictable execution times. Early strategies for assigning real-time tasks to multiprocessor systems laid the groundwork for partitioned scheduling approaches [2]. Subsequent work extended these concepts to sporadic task systems, analyzing the complexities of partitioned multiprocessor scheduling [3]. More recent studies have examined the partitioned scheduling of recurrent real-time tasks, addressing specific patterns in task arrival and execution [1]. While these works establish fundamental scheduling policies, they often treat resource allocation as a secondary concern or assume fixed resource configurations. In contrast, this paper integrates scheduling with dynamic resource co-allocation, specifically optimizing task placement under a preemptive EDF policy while simultaneously managing cache and memory bandwidth resources.

Cache partitioning is a critical technique for mitigating interference in hard real-time systems. Early evaluations highlighted the impact of cache partitioning on multi-tasking embedded systems [15] and its effectiveness in hard real-time contexts [13][14]. Recent efforts have focused on minimizing cache usage to improve system efficiency [16] and exploring the tradeoffs between cache sharing and isolation in mixed-criticality systems [19]. Algorithms such as PDPA have proposed period-driven task and cache partitioning strategies [20], while IA^3 introduced interference-aware allocation for multicore hard real-time systems [21]. Furthermore, recent work has investigated co-optimizing cache partitioning and multi-core task scheduling, utilizing multi-layer design space exploration to exploit cache sensitivity [22]. Although these studies address cache management, they typically isolate cache partitioning from other memory subsystem resources. This paper builds on this line of work by extending the multi-layer optimization framework to include memory bandwidth regulation alongside cache partitioning, providing a more holistic resource management solution.

Memory bandwidth regulation is another essential component for performance isolation in multi-core platforms. Hardware-based solutions like Intel’s Resource Director Technology (RDT) have been widely studied [9][11], and ARM’s MPAM specification provides a similar framework for memory system resource partitioning [12]. Software-based approaches, such as MemGuard, offer memory bandwidth reservation for efficient performance isolation [7], while MemPol polices core memory bandwidth from outside the cores [8]. In the context of real-time systems, dynamic memory bandwidth allocation has been explored for GPU-based SoC platforms [17], and coordinated partitioning of last-level cache and memory bandwidth has been proposed for fairness-aware workload consolidation [18]. Additionally, real-time cache management for multi-core virtualization has been addressed to support hypervisor-based isolation [4]. These works demonstrate the importance of memory bandwidth control, but often focus on single-resource optimization or specific hardware architectures. This paper differs by jointly optimizing memory bandwidth and cache partitioning within a unified 0-1 linear program, ensuring that both resources are co-allocated to tasks to guarantee schedulability.

Holistic resource allocation approaches aim to manage multiple resources simultaneously for multicore real-time systems. Recent works have proposed holistic resource allocation for multicore real-time systems [10] and virtualization environments [23]. Other studies have extended these concepts to federated scheduling for parallel real-time tasks [24] and dynamic resource allocation for soft real-time systems [25]. Some research has also combined hardware management with mixed-criticality provisioning to address multicore interference [5]. While these holistic approaches recognize the interdependence of resources, they may not fully exploit the specific constraints of fine-grained partitioning enabled by hypervisors like Jailhouse. This paper contributes to this area by leveraging the Jailhouse hypervisor for fine-grained resource partitioning and proposing a multi-objective heuristic that outperforms existing mixed-integer programs in finding optimal task-resource co-allocations within strict time limits.
