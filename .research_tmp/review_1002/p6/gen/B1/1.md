## Related Works

Serving large language models (LLMs) at scale presents significant challenges regarding memory management, specifically concerning the Key-Value (KV) cache, which stores intermediate attention states to accelerate inference. The KV cache footprint grows dynamically with sequence length and batch size, often becoming the dominant contributor to memory consumption [1]. Inefficient management of this memory leads to fragmentation and redundant duplication, which limits the effective batch size and overall throughput [2]. To address these issues, recent research has focused on optimizing KV cache storage, reuse, and eviction strategies.

**KV Cache Management and Compression**
Several approaches aim to reduce the memory overhead of the KV cache. PagedAttention, introduced in vLLM, draws inspiration from operating system virtual memory and paging techniques to manage KV cache memory with near-zero waste, enabling flexible sharing of KV states within and across requests [2]. This approach significantly improves throughput by mitigating fragmentation [2]. For long-context inference, compression techniques are essential. PyramidKV leverages the observation that attention patterns follow a "Pyramidal Information Funneling" structure, dynamically adjusting cache size across layers to retain only a small fraction of the KV cache while maintaining accuracy [3]. Similarly, KVQuant employs low-precision quantization techniques, such as per-channel key quantization and non-uniform datatypes, to enable serving models with context lengths up to 10 million tokens on multi-GPU systems [1]. InfiniGen addresses the memory bottleneck in offloading-based systems by speculating essential KV entries to prefetch only critical data from host memory, improving performance by up to 3x [4].

**KV Cache Reuse and Sharing**
A major avenue for improving latency is the reuse of precomputed KV states. Prompt Cache identifies overlapping text segments, such as system prompts, and precomputes their attention states to reduce time-to-first-token latency, achieving speedups of up to 60x on CPU-based inference [5]. ChunkAttention extends this by using a prefix-tree structure to share KV tensors across requests with matching prompt prefixes, optimizing data locality during self-attention computation [6]. CacheBlend tackles the challenge of reusing KV caches for non-prefix text chunks, common in Retrieval-Augmented Generation (RAG), by selectively recomputing a small subset of tokens to ensure generation quality while reducing time-to-first-token by 2.2–3.3x [7]. StreamingLLM addresses the limitation of finite attention windows in streaming applications by identifying "attention sinks" in initial tokens, allowing models to generalize to infinite sequence lengths without fine-tuning [8].

**Eviction Policies and Workload Characterization**
While many studies focus on synthetic workloads or specific architectural optimizations, there is limited understanding of how real-world LLM serving workloads interact with cache eviction policies. Traditional cache replacement algorithms, such as LRU, LRFU, and ARC, have been extensively studied in database and web caching contexts [9][10][11][12]. However, the specific characteristics of KV cache workloads in LLM serving—such as the skew in reuse patterns across single-turn and multi-turn requests and the predictability of reuse times within specific request categories—remain under-explored. Our work fills this gap by providing the first systematic characterization of KV workload patterns from a leading LLM service provider, revealing that ideal cache hit ratios can be achieved with moderate cache sizes. Based on these observations, we propose a workload-aware eviction policy that outperforms generic strategies under real-world traces, particularly when cache capacity is constrained.
