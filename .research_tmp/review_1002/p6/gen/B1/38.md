## Related Works

Memory bandwidth regulation and cache partitioning are fundamental techniques for achieving predictable timing in real-time multicore systems. Cache partitioning mitigates interference among concurrently executing real-time tasks by isolating cache resources, which is critical because the execution time of cache-sensitive tasks strongly depends on the available cache [1]. Recent studies have evaluated the effectiveness of cache partitioning in hard real-time systems, demonstrating its impact on multi-tasking embedded systems and the tradeoffs between cache sharing and isolation in mixed-criticality environments [2][3][4][5]. To minimize cache usage and further reduce interference, specific algorithms have been proposed to optimize cache allocation for real-time workloads [6].

Memory bandwidth regulation complements cache partitioning by controlling access to shared memory resources. Systems such as MemGuard provide memory bandwidth reservation for efficient performance isolation on multi-core platforms [7], while MemPol polices core memory bandwidth from outside the cores to enforce isolation [8]. Hardware-based solutions, including Intel’s Resource Director Technology (RDT) [9][10] and Arm’s Memory System Resource Partitioning and Monitoring (MPAM) [11], offer fine-grained control over memory and cache resources. Dynamic allocation strategies have also been developed for real-time GPU-based SoC platforms [12] and for coordinated partitioning of last-level cache and memory bandwidth to ensure fairness in workload consolidation [13].

Task scheduling and resource co-allocation are essential for integrating these isolation mechanisms. Partitioned scheduling of recurrent real-time tasks [14] and sporadic task systems [15] requires careful assignment of tasks to multiprocessor systems [16]. Holistic resource allocation approaches have been proposed for multicore real-time systems [17] and virtualization environments [18], including strategies for parallel real-time tasks under federated scheduling [19] and dynamic resource allocation for soft real-time systems [20]. Interference-aware allocation algorithms, such as $IA^3$ [21] and PDPA [22], aim to optimize task placement by considering resource dependencies.

Co-optimizing cache partitioning and task scheduling has emerged as a key area of research. A recent hybrid multi-layer design space exploration technique systematically interleaves cache partitioning search, task allocation heuristics, and schedulability analysis to improve system performance [1]. This approach demonstrated that co-optimization can significantly enhance the schedulability of non-preemptive fixed-priority task sets, with improvements averaging 15.2% and reaching up to 233.6% for highly cache-sensitive tasks [1]. The study also highlighted that clustering tasks with similar periods often yields higher schedulability than clustering by cache sensitivity alone [1].

In the domain of virtualization, real-time cache management for multi-core virtualization [23] and Xilinx Xen support with cache-coloring [24] provide mechanisms for resource isolation in virtualized environments. Additionally, combining hardware management with mixed-criticality provisioning has been explored to address multicore scheduling challenges [25]. These works collectively underscore the necessity of joint optimization of task allocation and resource partitioning to guarantee schedulability while minimizing resource usage, a challenge addressed by the proposed 0-1 linear program and multi-objective heuristic in this paper.
