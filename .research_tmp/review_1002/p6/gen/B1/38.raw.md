## Related Works

Memory bandwidth regulation and cache partitioning are fundamental techniques for achieving predictable timing in real-time multicore systems. Cache partitioning mitigates interference among concurrently executing real-time tasks by isolating cache resources, which is critical because the execution time of cache-sensitive tasks strongly depends on the available cache \[[Sun](http://arxiv.org/abs/2310.02959v1)\]. Recent studies have evaluated the effectiveness of cache partitioning in hard real-time systems, demonstrating its impact on multi-tasking embedded systems and the tradeoffs between cache sharing and isolation in mixed-criticality environments \[[Altmeyer](https://ref.local/13)\]\[[Sebastian A. Altmeyer and Roeland Douma and Will Lunniss and Robert I. Davis](https://ref.local/14)\]\[[Bui](https://ref.local/15)\]\[[Chisholm](https://ref.local/19)\]. To minimize cache usage and further reduce interference, specific algorithms have been proposed to optimize cache allocation for real-time workloads \[[Sun](https://ref.local/16)\].

Memory bandwidth regulation complements cache partitioning by controlling access to shared memory resources. Systems such as MemGuard provide memory bandwidth reservation for efficient performance isolation on multi-core platforms \[[Yun](https://ref.local/7)\], while MemPol polices core memory bandwidth from outside the cores to enforce isolation \[[Alexander Zuepke and
                  Andrea Bastoni and
                  Weifan Chen and
                  Marco Caccamo and
                  Renato Mancuso](https://ref.local/8)\]. Hardware-based solutions, including Intel’s Resource Director Technology (RDT) \[[Intel](https://ref.local/9)\]\[[Sohal](https://ref.local/11)\] and Arm’s Memory System Resource Partitioning and Monitoring (MPAM) \[[Arm](https://ref.local/12)\], offer fine-grained control over memory and cache resources. Dynamic allocation strategies have also been developed for real-time GPU-based SoC platforms \[[Aghilinasab](https://ref.local/17)\] and for coordinated partitioning of last-level cache and memory bandwidth to ensure fairness in workload consolidation \[[Park](https://ref.local/18)\].

Task scheduling and resource co-allocation are essential for integrating these isolation mechanisms. Partitioned scheduling of recurrent real-time tasks \[[Ekberg](https://ref.local/1)\] and sporadic task systems \[[Baruah](https://ref.local/3)\] requires careful assignment of tasks to multiprocessor systems \[[Burchard](https://ref.local/2)\]. Holistic resource allocation approaches have been proposed for multicore real-time systems \[[Xu](https://ref.local/10)\] and virtualization environments \[[Xu](https://ref.local/23)\], including strategies for parallel real-time tasks under federated scheduling \[[Nie](https://ref.local/24)\] and dynamic resource allocation for soft real-time systems \[[Gifford](https://ref.local/25)\]. Interference-aware allocation algorithms, such as $IA^3$ \[[Paolieri](https://ref.local/21)\] and PDPA \[[Berna](https://ref.local/20)\], aim to optimize task placement by considering resource dependencies.

Co-optimizing cache partitioning and task scheduling has emerged as a key area of research. A recent hybrid multi-layer design space exploration technique systematically interleaves cache partitioning search, task allocation heuristics, and schedulability analysis to improve system performance \[[Sun](http://arxiv.org/abs/2310.02959v1)\]. This approach demonstrated that co-optimization can significantly enhance the schedulability of non-preemptive fixed-priority task sets, with improvements averaging 15.2% and reaching up to 233.6% for highly cache-sensitive tasks \[[Sun](http://arxiv.org/abs/2310.02959v1)\]. The study also highlighted that clustering tasks with similar periods often yields higher schedulability than clustering by cache sensitivity alone \[[Sun](http://arxiv.org/abs/2310.02959v1)\].

In the domain of virtualization, real-time cache management for multi-core virtualization \[[Kim](https://ref.local/4)\] and Xilinx Xen support with cache-coloring \[[Xilinx](https://ref.local/6)\] provide mechanisms for resource isolation in virtualized environments. Additionally, combining hardware management with mixed-criticality provisioning has been explored to address multicore scheduling challenges \[[Kim](https://ref.local/5)\]. These works collectively underscore the necessity of joint optimization of task allocation and resource partitioning to guarantee schedulability while minimizing resource usage, a challenge addressed by the proposed 0-1 linear program and multi-objective heuristic in this paper.
