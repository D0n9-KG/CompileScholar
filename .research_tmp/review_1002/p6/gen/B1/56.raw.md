## Related Works

**Sequential Recommendation Architectures**
Early approaches to sequential recommendation relied on Markov Chains and Recurrent Neural Networks (RNNs) to model user behavior. Markov Chains assume next actions depend only on recent history, performing well in sparse datasets, while RNNs capture longer-term semantics in denser data \[[Kang](http://arxiv.org/abs/1808.09781v1)\]. To address the limitations of unidirectional RNNs, which assume rigidly ordered sequences, BERT4Rec introduced a bidirectional encoder using the Cloze task to predict masked items, leveraging both left and right context \[[Sun](http://arxiv.org/abs/1904.06690v2)\]. SASRec further balanced these approaches by employing self-attention to identify relevant items from a user's history, achieving high efficiency and performance across varying dataset densities \[[Kang](http://arxiv.org/abs/1808.09781v1)\]. More recently, Transformer-based models have become dominant, though they face challenges with computational complexity. LinRec proposed a linear attention mechanism to reduce the quadratic complexity of standard dot-product attention, improving time and memory efficiency for long-term sequences \[[Liu](http://arxiv.org/abs/2411.01537v1)\].

**State Space Models in Recommendation**
To overcome the quadratic computational bottleneck of attention mechanisms, State Space Models (SSMs) have emerged as a promising alternative. Mamba, a selective SSM, enables linear-time sequence modeling by allowing parameters to be functions of the input, thereby selectively propagating or forgetting information based on content \[[Gu](http://arxiv.org/abs/2312.00752v2)\]. This architecture achieves fast inference and linear scaling, outperforming Transformers of the same size in various modalities \[[Gu](http://arxiv.org/abs/2312.00752v2)\]. Theoretical connections between SSMs and attention mechanisms have been formalized through the State Space Duality (SSD) framework, which demonstrates that these model families are closely related and allows for the design of more efficient architectures like Mamba-2 \[[Dao](http://arxiv.org/abs/2405.21060v1)\]. In the context of sequential recommendation, Mamba4Rec was the first to explore selective SSMs, demonstrating that Mamba blocks can effectively tackle the effectiveness-efficiency dilemma, outperforming RNN and attention-based baselines \[[Liu](http://arxiv.org/abs/2403.03900v2)\]. For lifelong sequential recommendation, where sequences exceed 2,000 items, RecMamba leverages Mamba to model user sequences selectively, reducing training duration by approximately 70% and memory costs by 80% compared to representative models \[[Yang](http://arxiv.org/abs/2403.16371v1)\]\[[Yang](http://arxiv.org/abs/2403.16371v1)\].

**Hybrid and Frequency-Domain Approaches**
Recent research has focused on enhancing sequential models by integrating frequency-domain information and hybrid architectures. FEARec shifts the perspective to the frequency domain, using a ramp structure to explicitly learn both low- and high-frequency information, which standard self-attention often filters out \[[Du](http://arxiv.org/abs/2304.09184v3)\]. It also employs auto-correlation to capture periodic characteristics in user behavior \[[Du](http://arxiv.org/abs/2304.09184v3)\]. Similarly, EchoMamba4Rec harmonizes bidirectional state space models with spectral filtering, using learnable Fast Fourier Transform (FFT) filters to refine item embeddings and reduce noise, thereby capturing complex patterns in user interaction data \[[Wang](http://arxiv.org/abs/2406.02638v2)\]. Other advanced architectures include DMAN, which uses dynamic memory blocks to preserve long-term interests by segmenting long behavior sequences, and Hierarchical RNNs, which personalize session-based recommendations by transferring latent hidden states across user sessions \[[Quadrana](http://arxiv.org/abs/1706.04148v5)\]\[[Tan](http://arxiv.org/abs/2102.09269v1)\]. These developments highlight a trend toward more efficient, multi-faceted models that can handle the diverse and variable-length nature of modern user behavioral data.
