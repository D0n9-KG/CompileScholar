## Related Works

The management and recommendation of open-source machine learning resources have become critical areas of research as platforms like Hugging Face and GitHub host vast repositories of models, datasets, and code. Existing approaches primarily focus on cross-platform matching, library recommendation, and metadata enrichment, yet often lack the structured representations necessary for advanced information retrieval tasks such as tracing model evolution or complex resource classification.

A significant body of work addresses the challenge of linking academic papers with their corresponding source code repositories. The *paper2repo* system introduces a novel item-item cross-platform recommender that identifies relevant GitHub repositories for given academic papers [1]. By integrating text encoding with constrained graph convolutional networks (GCN), *paper2repo* maps paper and repository embeddings into a shared space to determine similarity without human labeling [1]. This system utilizes distant supervision, automatically computing training labels from user actions on GitHub, and has demonstrated superior performance over state-of-the-art recommendation methods on real-world datasets [1]. While effective for paper-to-code matching, such systems do not inherently provide the structured knowledge graph infrastructure required for broader resource management within specific ML communities.

Parallel efforts have focused on leveraging knowledge graphs to enhance machine learning library and method recommendations. The Description Enhanced Knowledge Graph (DEKR) aims to improve method recommendation by enriching knowledge graph descriptions, thereby facilitating more accurate matching between user needs and available ML methods [2]. Similarly, task-oriented ML/DL library recommendation systems utilize knowledge graphs to identify appropriate libraries based on specific task requirements [3]. These approaches highlight the utility of structured data in guiding developers toward suitable tools, but they generally operate at the level of library or method selection rather than managing the full ecosystem of models and datasets found in modern open-source platforms.

Further research has addressed the enrichment of repository metadata through automated tagging. GRETA employs graph-based methods to assign tags to GitHub repositories, improving the discoverability and organization of open-source projects [4]. By structuring repository attributes, such systems lay the groundwork for more sophisticated retrieval tasks. However, these methods typically focus on code repositories in isolation, rather than integrating diverse resource types (models, datasets, papers) into a unified, large-scale knowledge graph.

The proposed work, HuggingKG, distinguishes itself by constructing the first large-scale knowledge graph specifically from the Hugging Face community, capturing domain-specific relations and rich textual attributes across 2.6 million nodes and 6.2 million edges. Unlike previous systems that focus on cross-platform matching [1] or library recommendation [2][3], HuggingKG enables advanced IR tasks such as resource recommendation, classification, and tracing model evolution. The associated HuggingBench benchmark further validates the unique characteristics of this structured representation, addressing the gap left by existing platforms that do not explicitly utilize structured knowledge for resource management.
