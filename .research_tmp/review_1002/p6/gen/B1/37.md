## Related Works

Vision Transformers (ViTs) have achieved significant milestones in computer vision by leveraging the transformer architecture to capture global context, yet their deployment on resource-limited edge devices is hindered by high computational and memory costs [1]. A primary challenge in accelerating ViTs on hardware is the presence of complex arithmetic operations, such as Softmax and LayerNorm, which are sensitive to model accuracy and difficult to map onto efficient low-precision hardware [1]. Existing acceleration methods often exploit parallelism only in matrix multiplication operations, leaving these complex operations on the CPU, which results in suboptimal performance due to communication overhead between the CPU and the accelerator [1].

To address efficiency challenges, model quantization has emerged as a widely used technique to compress and accelerate deep neural network inference [2]. Conventional quantization algorithms often ignore specific hardware architectures and apply uniform bit-widths to all layers, which is sub-optimal [2]. The Hardware-Aware Automated Quantization (HAQ) framework addresses this by leveraging reinforcement learning to determine optimal mixed-precision policies (1-8 bits) based on direct hardware feedback, such as latency and energy, rather than proxy signals [2]. HAQ demonstrates that optimal quantization policies vary drastically across different hardware architectures, such as edge and cloud systems, achieving significant reductions in latency and energy with negligible accuracy loss [2].

In the domain of natural language processing, the GOBO technique compresses 32-bit floating-point parameters of BERT models to 3 bits without requiring fine-tuning or retraining [3]. GOBO introduces a co-designed hardware architecture that maintains most weights in 3-bit precision during computation, replacing multiply-accumulate operations with additions to improve area efficiency and reduce off-chip traffic [3]. This approach highlights the potential of low-precision formats to enhance both memory storage and computational efficiency in transformer-based models [3].

Recent advancements in data representation have introduced new narrow-precision formats to improve quantization accuracy. The Block Data Representations (BDR) framework enables the evaluation of various narrow-precision formats, identifying new formats based on shared microexponents (MX) that outperform state-of-the-art approaches like narrow-precision floating-point and block floating-point [4]. MX utilizes multiple levels of quantization scaling with ultra-fine scaling factors, demonstrating effectiveness in large-scale generative pretraining and production-scale recommendation systems [4].

For ViT-specific acceleration, HeatViT proposes a hardware-efficient adaptive token pruning framework for embedded FPGAs [1]. By dynamically identifying and consolidating non-informative tokens, HeatViT reduces computation while maintaining accuracy [1]. The framework employs 8-bit fixed-point quantization and polynomial approximations for nonlinear functions to improve hardware efficiency, achieving significant speedups on Xilinx FPGAs compared to baseline accelerators [1]. While HeatViT focuses on token pruning and fixed-point quantization, the current work introduces the Microscaling Integer (MXInt) format to map all ViT operations, including complex arithmetic, onto FPGAs, addressing the limitations of previous methods that offload sensitive operations to the CPU [1].
