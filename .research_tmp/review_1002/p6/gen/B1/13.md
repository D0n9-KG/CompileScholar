## Related Works

Long-tailed recognition addresses the challenge of class imbalance in real-world datasets, where a few head classes dominate the data while most tail classes are under-represented [1][2]. This imbalance biases standard deep learning models toward dominant classes, degrading performance on tail classes [2]. Existing solutions are broadly categorized into class re-balancing, information augmentation, and module improvement [2].

Class re-balancing strategies, such as re-sampling and re-weighting, are prominent methods for mitigating imbalance [1][3]. Oversampling has been identified as a dominant method for addressing class imbalance in convolutional neural networks, effectively eliminating imbalance without causing overfitting [4]. However, these data-level approaches can alter the original data distribution, increasing computational costs [5]. Furthermore, re-balancing methods may inadvertently damage the representational ability of deep features while promoting classifier learning [3]. To address this, decoupling representation learning from classifier learning has emerged as an effective strategy. This approach suggests that data imbalance may not hinder the learning of high-quality representations, allowing for strong long-tailed recognition by adjusting only the classifier [6]. Subsequent works have refined this decoupled training by using stochastic weight averaging to improve feature generalization and re-training classifiers with stochastic representations [7].

Contrastive learning has gained significant attention for its ability to learn robust visual representations. Supervised Contrastive Learning (SCL) pulls samples of the same class together in embedding space while pushing apart different classes, achieving state-of-the-art results on balanced data [8]. However, SCL exhibits inherent biases when applied to long-tailed data. Theoretical analyses indicate that SCL tends to bias toward high-frequency classes, increasing the difficulty of imbalanced learning [9][10]. This bias results in poor uniformity in the feature space, where minority class samples exhibit poor separability [11]. Additionally, SCL fails to form a regular simplex, an ideal geometric configuration for representation learning, due to the imbalanced distribution [12].

To overcome these limitations, several advanced contrastive frameworks have been proposed. Parametric Contrastive Learning (PaCo) introduces learnable class-wise centers to rebalance the optimization process, adaptively enhancing the intensity of pushing same-class samples together [9][10]. Balanced Contrastive Learning (BCL) addresses the geometric irregularity by employing class-averaging and class-complement strategies to ensure all classes appear in mini-batches, thereby satisfying the regular simplex condition [12]. Targeted Supervised Contrastive Learning (TSC) improves feature uniformity by forcing features to converge to uniformly distributed targets on a hypersphere, enhancing class boundaries for minority classes [11]. Other approaches include Subclass-balancing Contrastive Learning (SBCL), which clusters head classes into subclasses to capture semantic substructures and enforce instance balance [13], and Probabilistic Contrastive Learning (ProCo), which estimates data distributions using von Mises-Fisher distributions to sample contrastive pairs efficiently in small batches [14]. Furthermore, recent work interprets long-tailed recognition as mutual information maximization between latent features and ground-truth labels, seamlessly integrating contrastive learning with logit adjustment [15]. Logit adjustment itself, based on label frequencies, encourages a larger relative margin between logits of rare and dominant labels, providing a statistical grounding for handling imbalance [16].
