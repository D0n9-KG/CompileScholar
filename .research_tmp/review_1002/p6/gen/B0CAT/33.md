**Related Works**

Rehearsal-based methods constitute a primary class of strategies for mitigating catastrophic forgetting in continual learning (CL). These approaches store a subset of past data in a memory buffer and train on it concurrently with new data. Representative implementations include Gradient Episodic Memory (GEM), which projects gradients to avoid conflicting with past tasks [8], and A-GEM, which offers an efficient approximation of this constraint [6]. Other variants include iCaRL, which combines experience replay with feature regression to handle class-incremental learning [7], and Deep Generative Replay, which uses a generative model to synthesize past data samples [5]. While these methods have demonstrated strong empirical performance, they typically rely on concurrent training strategies where past and new data are optimized simultaneously. However, it remains unclear whether this concurrent rehearsal strategy is always optimal, particularly regarding the trade-offs between forgetting and generalization error under varying task similarities.

A second family of approaches focuses on regularization and gradient projection techniques to constrain weight updates without storing raw data. Elastic Weight Consolidation (EWC) slows learning on important weights [2], while Progressive Neural Networks use lateral connections to leverage prior features [1]. More recent methods, such as Gradient Projection Memory (GPM) [3] and Trust Region Gradient Projection (TRGP) [4], project gradients onto subspaces orthogonal to those of previous tasks to minimize interference. Theoretical analyses of these methods, such as those for Orthogonal Gradient Descent (OGD), provide generalization guarantees in the Neural Tangent Kernel (NTK) regime [9] and characterize forgetting through NTK overlap matrices [10]. Additionally, regularization-based CL has been analyzed as a second-order Taylor approximation of the loss function [11]. Despite these advances, these methods often impose restrictive constraints on the optimization space, which can hinder performance on new tasks, especially when new tasks are strongly correlated with old ones.

Theoretical analyses of continual learning in linear models provide foundational insights into the mechanics of forgetting. Early works studied overparameterized linear regression, establishing exact expressions for forgetting and connecting CL to alternating projections and the Kaczmarz method [13]. Subsequent studies analyzed linear classification on separable data, showing that weak regularization reduces to a sequential max-margin problem [12]. Further research explored the impact of overparameterization on forgetting in random orthogonal transformation tasks [16] and derived general theoretical frameworks for forgetting in both underparameterized and overparameterized regimes using SGD [15]. A comprehensive theoretical analysis of forgetting and generalization in overparameterized linear models was provided in [14], which explicitly characterizes how task similarity and ordering affect performance. More recently, [17] extended these insights to replay-based CL, characterizing the impact of buffer size and model capacity on forgetting rates. However, prior to the current work, there has been a lack of comprehensive theoretical analysis specifically comparing concurrent versus sequential rehearsal strategies in overparameterized linear models, leaving open the question of whether sequential revisiting of past data offers superior benefits compared to standard concurrent rehearsal.
