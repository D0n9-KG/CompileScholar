**Related Works**

**Table Discovery and Retrieval**
Research on table discovery and retrieval encompasses a diverse range of approaches, including keyword-based semantic matching [9], deep contextualized language models for ad hoc retrieval [10], graph-based representation learning for complex layouts [8], and specialized frameworks for joinable table discovery [3] and dataset union search [4]. Early methods focused on representing queries and tables in multiple semantic spaces to perform ad hoc table retrieval [9]. Subsequent work leveraged pre-trained language models like BERT to encode table content while accounting for structural constraints [10]. To handle complex table layouts with nested headers, graph-based approaches convert tables into tabular graphs for multi-granular representation learning [8]. In the domain of data lakes, specific tasks such as finding joinable tables have been addressed using embedding-based retrieval with pre-trained language models [3], while dataset discovery for table union search has utilized contrastive learning on column encoders [4]. Additionally, open-domain question answering over tables has been improved through dense retrieval techniques tailored for tabular context [6], and natural language question answering over tables has been advanced by weakly supervised parsing models that predict denotations directly [7]. Despite these advancements, most existing methods rely on a traditional dense vector search pipeline, where errors accumulated during the separate representation and indexing phases negatively impact subsequent search accuracy, and insufficient query-table interaction hinders effective semantic alignment [1].

**Differentiable Search Indexes and Generative Retrieval**
The paradigm of differentiable search indexes and generative retrieval includes the original Differentiable Search Index (DSI) [11], the Neural Corpus Indexer (NCI) [12], the DSI-QG framework [13], and the unified CorpusLM model [14]. The DSI paradigm demonstrated that information retrieval can be accomplished with a single Transformer, where corpus information is encoded in model parameters, allowing queries to be mapped directly to document identifiers [11]. This approach eliminates the separation between indexing and retrieval, thereby avoiding error accumulation inherent in traditional pipelines. The Neural Corpus Indexer (NCI) further refined this by using a sequence-to-sequence network to generate document identifiers, employing a prefix-aware weight-adaptive decoder and query generation techniques to optimize recall [12]. To address the data distribution mismatch between long indexed documents and short queries, DSI-QG proposed representing documents with generated queries during the indexing phase [13]. More recently, CorpusLM integrated generative retrieval with closed-book generation and retrieval-augmented generation into a unified language model for knowledge-intensive tasks [14]. While these methods significantly simplify the retrieval process and improve accuracy by unifying indexing and search, they have primarily been applied to text corpora, and their application to structured table repositories with dynamic indexing requirements remains an open challenge.

**Continual Learning for Dynamic Corpora**
Approaches for handling dynamic corpora in generative retrieval include the DSI++ update strategy [15] and the CLEVER model for continual learning [16]. As document collections in practical scenarios are dynamic, the ability to incrementally index new documents without forgetting previously learned knowledge is vital. The DSI++ framework introduced methods for updating Transformer memory with new documents [15]. The CLEVER model specifically addresses continual learning for generative retrieval by proposing Incremental Product Quantization to encode new documents with low computational cost and a memory-augmented learning mechanism to prevent catastrophic forgetting [16]. These techniques aim to maintain the model's ability to answer queries for both previously and newly indexed documents. However, existing continual learning approaches for generative retrieval often suffer from significant forgetting of old knowledge when new data is introduced, and their effectiveness in the specific context of natural language-driven table discovery, where tables are structured entities rather than plain text documents, has not been fully explored.
