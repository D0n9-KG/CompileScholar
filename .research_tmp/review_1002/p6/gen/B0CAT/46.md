**Related Works**

Sequential recommendation has evolved significantly from early recurrent architectures to modern transformer-based models. Early approaches utilized Recurrent Neural Networks (RNNs) to model session-based user behaviors, addressing the limitations of matrix factorization in short-session scenarios [2]. Subsequent works introduced attention mechanisms to capture user intent, such as the Neural Attentive Recommendation Machine (NARM) [4] and the Short-term Attention/Memory Priority Model (STAMP) [3]. The paradigm shifted with the introduction of the Transformer architecture [6], which dispensed with recurrence in favor of self-attention. This led to the development of Self-Attentive Sequential Recommendation (SASRec) [7], which balances long-term semantics with sparse attention, and BERT4Rec [8], which employs bidirectional encoding via a Cloze task. More recent advancements include Sparse-Interest Networks [10] for modeling diverse user intentions, low-rank decomposed self-attention for efficiency [11], and generative pretrained language models like M6-rec [12]. While these models effectively capture intra-domain sequential dynamics, they generally operate within a single domain, leaving the challenge of leveraging cross-domain information unaddressed.

Cross-Domain Sequential Recommendation (CDSR) aims to mitigate data sparsity by transferring knowledge across multiple domains. Early frameworks included Relational Learning via Collective Matrix Factorization [13] and Pi-Net, which shares information across domains for shared accounts [20]. More recent CDSR methods focus on explicit transfer mechanisms. DTCDR proposes a dual-target framework for cross-domain recommendation [14], while One for All, All for One focuses on learning and transferring user embeddings [15]. C^2DSR utilizes graph neural networks to mine inter-sequence collaborative relationships alongside sequential encoders [16]. Mixed Information Flow networks incorporate both behavioral and knowledge transfer units to decide when to use cross-domain information [21]. Furthermore, Pacer and Runner addresses negative transfer by adaptively weighting prediction losses based on the degree of negative transfer estimated through an asymmetric cooperative network [17]. Other recent approaches include Multi-Domain Sequential Recommendation via Domain Space Learning [18], MDMTRec for adaptive multi-task learning [19], and the Mixed Attention Network (MAN), which uses local and global attention modules to extract domain-specific and cross-domain information [22]. A common limitation in these existing CDSR frameworks is their reliance on explicitly injecting additional domain-specific components or complex transfer modules. These methods often overlook the inherent potential of the core self-attention mechanism to naturally learn correlations among behaviors, leading to increased computational overhead and the risk of negative transfer if the transfer process is not carefully controlled.

The Transformer architecture, originally proposed for machine translation [6], has become the backbone of modern sequential recommenders due to its ability to model long-range dependencies in parallel. SASRec [7] demonstrated that self-attention can capture relevant items from a user's history more effectively than RNNs in sparse datasets. BERT4Rec [8] further enhanced this by using bidirectional context, although it requires specific training strategies like the Cloze task to prevent information leakage. Recent efforts have focused on optimizing the self-attention mechanism itself, such as Longformer, which scales linearly with sequence length by combining local windowed and global attention [9], and low-rank decomposed self-attention networks that reduce computational costs for next-item recommendation [11]. Despite these architectural improvements, the standard self-attention mechanism in CDSR contexts is typically treated as a static component. Existing works often augment this core module with external domain-aware blocks rather than enhancing the attention mechanism itself to dynamically manage cross-domain interactions. This separation of concerns may limit the model's ability to automatically balance the trade-off between leveraging complementary knowledge and mitigating negative transfer, a gap that our work addresses by formulating cross-domain learning as a multi-objective optimization problem within the self-attention layer.
