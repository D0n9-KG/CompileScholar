### Related Works

The integration of knowledge graphs into machine learning resource management has emerged as a critical area of research, driven by the need to structure unstructured data for better retrieval and recommendation. Existing approaches in this domain can be broadly categorized into two sub-families: those focused on method and library recommendation, and those addressing cross-platform resource linking. Representative works in the first sub-family include DEKR, which proposes a Description Enhanced Knowledge Graph specifically for machine learning method recommendation [1], and a more recent task-oriented framework for ML/DL library recommendation based on a knowledge graph [2]. These systems leverage structured semantic relationships to enhance the precision of recommending specific algorithms or software libraries to users. In the second sub-family, research has extended to cross-platform scenarios, such as paper2repo, which recommends GitHub repositories for academic papers by mapping embeddings across different platforms [3]. Additionally, foundational work like GRETA has explored graph-based tag assignment for GitHub repositories to improve metadata quality [4]. While these methods have demonstrated the utility of graph structures in enhancing resource discoverability, they generally operate on smaller, domain-specific subsets of resources or focus on single-platform interactions. A shared limitation across these approaches is the lack of a unified, large-scale knowledge graph that explicitly captures the complex evolution and interdependencies of open-source ML resources within a single community ecosystem, thereby limiting the ability to perform advanced analyses such as tracing model lineage or recommending datasets based on holistic resource relationships.

The construction of large-scale knowledge graphs for software and academic artifacts has also been explored in the context of code repositories and academic publications. This thematic area encompasses approaches that utilize graph neural networks and text encoding to bridge the semantic gap between different types of digital artifacts. For instance, paper2repo integrates text encoding with constrained graph convolutional networks to learn joint embeddings of papers and repositories, enabling recommendation without human labeling [3]. Similarly, GRETA employs graph-based methods to assign tags to GitHub repositories, aiming to enrich the metadata available for search and retrieval [4]. These studies highlight the potential of graph-based learning to infer relationships from implicit user actions and textual content. However, these works primarily focus on the static association between papers and code or the tagging of individual repositories. They do not typically address the dynamic nature of machine learning resources, such as the versioning of models or the dependency chains between datasets and models. Consequently, there remains an open problem in effectively modeling the temporal and structural evolution of ML resources, which is essential for tasks like tracing model updates or understanding the provenance of data used in training.

Recent efforts have also sought to enhance the descriptive capabilities of knowledge graphs to improve recommendation accuracy in machine learning contexts. This sub-family of approaches focuses on enriching graph nodes with detailed textual attributes to capture the nuances of ML methods and libraries. DEKR, for example, introduces a Description Enhanced Knowledge Graph to facilitate more accurate method recommendation by incorporating rich textual descriptions [1]. This is complemented by task-oriented ML/DL library recommendation systems that utilize knowledge graphs to align user tasks with appropriate libraries [2]. These methods recognize that simple structural links are insufficient for capturing the functional similarities between ML resources. Despite these advancements, the scale of the knowledge graphs used in these studies is often limited to specific domains or smaller communities. A common open problem is the scalability of these enriched graph representations to massive, heterogeneous ecosystems like Hugging Face, where millions of nodes and edges must be managed to support diverse information retrieval tasks, including resource recommendation, classification, and tracing, without sacrificing the granularity of the textual attributes.
