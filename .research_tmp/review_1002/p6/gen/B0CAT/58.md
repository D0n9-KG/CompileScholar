Conversational recommendation systems (CRSs) have evolved from static preference estimation to dynamic, multi-turn interaction frameworks. Early approaches focused on modeling the dialogue process to explicitly capture user preferences, such as Estimation-Action-Reflection [1] and Interactive Path Reasoning on Graphs [2]. These methods treat recommendation as a path reasoning problem, walking through attribute vertices based on user feedback to prune irrelevant candidates [2]. Subsequent work addressed the cold-start problem by unifying attribute inquiry and item recommendation, moving beyond hand-crafted decision functions to more robust exploration-exploitation strategies [3]. More recent advancements leverage large language models (LLMs) and prompt learning to enhance CRS capabilities. This includes knowledge-enhanced prompt learning for unified systems [4], demonstration-augmented prompt learning to broaden the model’s perspective [7], and utilizing LLMs as zero-shot recommenders [8]. Furthermore, retrieval-augmented techniques have been developed to unleash the retrieval potential of LLMs in CRSs [9]. Despite these advancements, a shared limitation persists across these interactive frameworks: they heavily rely on real-time user involvement to clarify preferences. Frequent user interaction, while necessary for accuracy, can degrade the user experience, creating a tension between recommendation effectiveness and interaction efficiency.

To mitigate the reliance on real-time user data and address dataset imbalances, several studies have explored data simulation and augmentation. One line of work focuses on alleviating the long-tail problem, where a large proportion of items are rarely mentioned in conversations. LOT-CRS, for instance, simulates balanced CRS datasets to improve long-tail recommendation performance through specific pre-training tasks and retrieval-augmented fine-tuning [6]. Another approach involves counterfactual data simulation to improve CRSs by generating synthetic interactions that enhance model robustness [5]. These methods aim to enrich the training data to better represent diverse user preferences and item distributions. However, these simulation techniques primarily focus on improving the training data distribution or model generalization. They do not inherently provide a mechanism for the CRS to autonomously interact with a simulated user during the inference or evaluation phase to dynamically refine recommendations without actual user input, leaving the challenge of efficient, autonomous multi-turn interaction unaddressed.

The paradigm of reward-guided search and verification has emerged as a powerful technique in complex reasoning tasks, offering a pathway to improve decision-making efficiency. In mathematical reasoning, training verifiers to judge the correctness of model completions has been shown to significantly improve performance by selecting the best candidate from multiple generations [10]. This concept has been extended to the development of Generative Reward Models (GenRM). GenRM unifies Reinforcement Learning from Human Feedback (RLHF) and AI Feedback (RLAIF) by training LLMs on self-generated reasoning traces, producing synthetic preference labels that align well with human judgments [11]. Furthermore, Generative Verifiers propose training verifiers using next-token prediction objectives, allowing them to integrate seamlessly with instruction tuning and utilize chain-of-thought reasoning [12]. These generative verifiers outperform discriminative classifiers and LLM-as-a-Judge approaches in Best-of-N settings [12]. While these methods demonstrate the efficacy of reward-guided search and generative verification in reasoning tasks, their application to conversational recommendation remains underexplored. Specifically, there is a lack of frameworks that adapt these generative reward modeling techniques to simulate user feedback actions, such as item scoring and attribute-based critique, to drive efficient, autonomous interaction in CRSs.
