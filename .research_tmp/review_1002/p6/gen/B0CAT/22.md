**Related Works**

**Semantic Segmentation Architectures**
Recent advancements in semantic segmentation have evolved from fully convolutional networks (FCNs) [1] to architectures incorporating global context and attention mechanisms. Key approaches include DeepLab, which utilizes atrous convolution and spatial pyramid pooling to capture multi-scale context [2]; ParseNet, which augments local features with global average pooling [3]; PSPNet, which employs pyramid pooling for global prior representation [4]; and PSANet, which introduces point-wise spatial attention [5]. More recently, Transformer-based models such as SegFormer [6] and SETR [7] have demonstrated superior performance by leveraging hierarchical encoders and sequence-to-sequence prediction paradigms. While these architectures significantly improve segmentation accuracy in supervised settings, they typically rely on large-scale annotated datasets, making them less suitable for scenarios where target domain labels are unavailable or costly to acquire.

**Unsupervised Domain Adaptation for Semantic Segmentation**
To address the annotation bottleneck, Unsupervised Domain Adaptation (UDA) methods transfer knowledge from labeled source domains to unlabeled target domains. These methods can be categorized into adversarial learning approaches, such as those adapting structured output spaces [8], using conditional GANs [9], or learning discriminative patch representations [12]; feature alignment techniques, including texture-invariant representation learning [10], intra-domain self-supervision [11], and synergistic image-feature adaptation [13]; and self-training strategies, which refine pseudo-labels through confidence regularization [20], uncertainty-aware refinement [24], class-balanced sampling [18], or maximum squares loss [19]. Other notable methods include bidirectional learning [23], pyramid curriculum adaptation [22], cross-domain mixed sampling [26], and consistency-based training like PixMatch [15]. Recent works have also focused on architectural improvements for UDA, such as DAFormer [16] and high-resolution context-aware adaptation (HRDA) [17]. Despite their success, these methods generally assume that the category sets of the source and target domains are identical or that the specific domain shift setting (e.g., partial or open-set) is known a priori, which is often unrealistic in practical applications.

**Universal Domain Adaptation**
Universal Domain Adaptation (UNDA) addresses the limitation of unknown category shifts by handling arbitrary overlaps between source and target classes. Representative approaches include Universal Multi-Source Domain Adaptation (UMDA), which identifies common labels across multiple sources [27]; methods for detecting open classes [28]; and rotation-based self-supervision for open-set rejection [29]. DANCE proposes a framework using neighborhood clustering and entropy-based alignment to handle arbitrary category shifts without prior knowledge [30]. OVANet introduces a one-vs-all network to learn adaptive thresholds for rejecting unknown samples [31]. While these methods successfully reject unknown classes, they often focus on image classification or assume specific structural properties that may not generalize to the dense, pixel-level predictions required for semantic segmentation. Furthermore, existing UDA-SS methods struggle with the low confidence scores of common classes in the target domain, leading to confusion with private classes, a challenge that remains underexplored in current literature.
