**Related Works**

The literature on real-time multiprocessor scheduling has evolved significantly, encompassing partitioned, global, and federated approaches. Early foundational work established the theoretical bounds for assigning real-time tasks to multiprocessor systems [2] and analyzed the partitioned scheduling of sporadic task systems [3]. More recent studies have focused on recurrent real-time tasks [1] and holistic resource allocation strategies for multicore systems [10]. Federated scheduling has also been explored to balance the benefits of partitioning and global scheduling for parallel real-time tasks [24]. While these methods provide robust schedulability guarantees, they often treat resource allocation as a secondary concern or assume fixed resource availability, leading to suboptimal utilization when hardware resources are dynamically partitioned.

To mitigate interference and ensure predictable timing, hardware-based resource partitioning techniques have been widely adopted. Cache partitioning is a primary mechanism, with early evaluations establishing its impact on hard real-time systems [13][14][15]. Subsequent research has examined the tradeoffs between cache sharing and isolation in mixed-criticality environments [19] and proposed algorithms like PDPA for period-driven task and cache partitioning [20]. Interference-aware allocation algorithms, such as $IA^3$, have further refined this by considering the specific interference patterns of tasks [21]. Recent work has continued to explore the co-optimization of cache partitioning and scheduling, noting that execution times are strongly dependent on allocated cache resources [22]. Additionally, cache management has been extended to multi-core virtualization contexts [4] and specific hardware platforms like Xilinx with cache-coloring support [6]. Despite these advances, many existing approaches focus on cache partitioning in isolation or do not fully integrate it with other critical resources like memory bandwidth, leaving a gap in holistic multi-resource management.

Memory bandwidth regulation is another critical component for performance isolation, particularly in multi-core platforms. MemGuard was introduced as a system for memory bandwidth reservation to ensure efficient performance isolation [7]. More recent developments include MemPol, which polices core memory bandwidth from outside the cores [8], and dynamic allocation strategies for real-time GPU-based SoC platforms [17]. Hardware support for resource partitioning has also been standardized, with Intel’s Resource Director Technology (RDT) [9][11] and Arm’s Memory System Resource Partitioning and Monitoring (MPAM) specification [12] providing mechanisms for monitoring and controlling memory resources. Coordinated partitioning of both last-level cache and memory bandwidth has been proposed for fairness-aware workload consolidation on commodity servers [18]. However, these techniques often operate independently or are applied in non-real-time contexts, and their integration with real-time task allocation under preemptive scheduling policies remains an open challenge.

The co-allocation of tasks and multiple resources is a complex optimization problem that has attracted recent attention. Holistic multi-resource allocation for multicore real-time virtualization has been studied to address the interdependencies between tasks and resources [23]. Dynamic resource allocation for soft real-time multicore systems has also been explored to adapt to varying workloads [25]. Combining hardware management with mixed-criticality provisioning has been proposed to address the one-out-of-m multicore problem [5]. Recent work has specifically addressed the co-optimization of cache partitioning and multi-core task scheduling, utilizing multi-layer design space exploration to balance cache sensitivity and schedulability [22]. While these approaches recognize the need for joint optimization, they often rely on mixed-integer programming or heuristics that may not scale efficiently or may not fully exploit the structure of the problem for preemptive EDF scheduling. Our work builds upon these foundations by proposing a 0-1 linear program and a multi-objective heuristic that specifically targets the co-allocation of tasks and resources under preemptive EDF, leveraging both cache partitioning and memory bandwidth regulation to improve schedulability and resource efficiency.
