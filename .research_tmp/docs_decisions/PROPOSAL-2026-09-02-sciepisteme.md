# 提案：SciEpisteme——面向自主科研智能体的双层证据-技能超图基底

## 1. 问题与定位

自主科研智能体（AI Scientist 类系统）的核心瓶颈不是推理能力，而是**领域知识的使用形态**。现有系统（AI Scientist v1/v2、Agent Laboratory、OpenScholar、Google co-scientist 等）全部依赖平面检索+API 搜索获取文献，存在三类结构性缺陷：

1. **伪共识**：检索到 N 篇说同样话的论文就认为领域共识成立——但这 N 篇可能全部辗转引用同一篇原始论文。LLM 训练数据本身是重复放大器，此风险系统性存在。
2. **无法回答否定查询**："什么没被做过"（gap identification）是科研选题的核心问题，但检索只能返回存在的文本；缺席（absence）只在封闭世界表示中才有语义。
3. **知识不可执行**：检索返回文本块，智能体无法直接知道"领域怎么做这类实验"（程序性知识），需要逐篇阅读重新归纳。

## 2. 核心主张

科学文献应被建模为**双层结构**：

- **声明层（declarative）**：领域知道什么——n-ary 证据超边（方法×任务×条件×结果的组合性事实）+ 引文图（证据的来源与依赖结构）
- **程序层（procedural）**：领域会做什么——从方法使用模式中蒸馏的版本化技能库（skill = 使用条件+步骤+范例溯源+稳定度）

两层由**同一套语料复现机制**维护：同一声明被 N 篇独立抽出 → 共识边；同一方法使用模式在 N 篇复现 → 结晶为技能。共识计算不是数支持数，而是**引文图上的证据独立性分析**（N 个支持的 claim 在引文图上共享源头祖先 → 真实证据强度远小于表面计数——伪共识检测）。

在此基底上，智能体获得四类平面 RAG 原则上给不了的能力：
1. **共识/争议查询**："这个结论的可信度（独立性校正后）是多少、领域在哪里分歧"
2. **缺口查询（否定）**：方法×任务空间中哪些组合无超边且邻近结构支持可行
3. **时序谱系查询**：沿方法演化边+年份的 supersession 链回答"当前 SOTA"（等权检索会返回过时论文）
4. **技能导航**："做这类实验的标准做法"（压缩的程序性知识，非原始文本）

研究规划由此变成可计算问题：**缺口 × 技能覆盖的交叉**——有技能覆盖的缺口是可执行的研究计划；无技能覆盖的缺口标识方法学创新机会。

## 3. 与已有工作的划界

- HyperGraphReasoning (arXiv 2601.04878)：schema-free 超图构建+agentic 遍历，但平均超边 arity 仅 2.35、零 benchmark、零基线对比，且不建模共识/矛盾
- HyperGraphRAG (NeurIPS'25)：n-ary 超边检索 +7.45 F1 vs 平面 RAG，但超图是被动索引，无认知状态、无程序层
- HGMEM (ICML'26)：超图工作记忆，merge 是主导因子——但 merge 无置信语义、无科学领域语义
- Eigenius (2608.04457) / OIDA (2604.11759)：epistemic status 作为图属性已提出（计算保真/组织承诺语义）——我们划界为"文献证据聚合派生的科学共同体证据分布"
- Typed Claim Network (2605.30966)：claim 级 stance 网络——它是引用意图分类，我们是由证据聚合派生的领域级状态
- SCITE：引文级支持/反驳 tally，无 claim 归并、无图结构
- Scientific Agent Skills (2609.00065)：163 个手工策展技能——我们是自动蒸馏+与证据图耦合
- Filling holes in science (2608.28822)：嵌入空间持续同调检测知识空洞——我们是显式图上的封闭世界否定查询
- EvoGraph-R1 (CVPR'26)：RL 训练 agent 编辑超图——占"可变图记忆"位，我们的自生长是语料驱动的复现聚合

组合空位（经三轮调研确认）：超图形式化 × 证据聚合派生状态 × 独立性感知共识 × 程序层蒸馏 × 封闭世界缺口查询——检索不到第二个主人。

## 4. 系统架构

```
构建层：chunk → 两遍抽取（slim 语法 + refine 语义补全）
  ├─ verbatim 节点 + n-ary 参与者 + verbatim 证据（溯源）
  ├─ 关系：命中 15-pattern 词表→打类型；未命中→保留开放关系文本
  ├─ 无杀边验证（gate 仅 repair；LLM verifier 退出管线）
  └─ 每N篇 embedding 规范化（canonical 代表）
聚合层：跨篇复现 → 声明层共识状态（独立性校正）+ 程序层技能蒸馏（stability>阈值结晶）
导航层（交付物）：混合检索 / 共识查询 / 缺口查询 / 谱系查询 / 技能查询
评测层：下游智能体任务 with/without 超图，对照=平面RAG+二元投影+无独立性校正消融
```

关键设计决策：
- **验证从杀边改为溯源**：每条边带 verbatim 证据+chunk 溯源，精确性由下游智能体回源验证（HyperGraphRAG 实测：抽取 F1 0.17 的图下游照样赢——下游对上游精度容忍度高，覆盖与结构完整更重要）
- **置信度来自复现而非 LLM 判断**：单条边的可信度 = N 篇独立来源（引文图独立性校正后），非单个 verifier 的裁决——对应科学界的复现机制
- **矛盾显式建模**：负向声明（"X does not improve Y"）成为一等边类型，争议区域=高价值研究机会

## 5. 评测设计（预注册思想）

主实验：下游智能体任务四类查询（共识/缺口/谱系/技能），对照三臂：
1. 平面 RAG（同语料同 embedding）
2. 二元投影（同一图压平成 KG，检验 n-ary 必要性）
3. 无独立性校正消融（检验伪共识检测的贡献）

附加：对抗性伪共识评测（构造引用聚集语料，测识别能力）；token 效率（技能压缩 vs 原始文本检索）。

## 6. 风险与诚实声明

1. 最大技术风险：技能蒸馏质量未验证——方法使用模式抽取比 claim 抽取更难格式化
2. 覆盖是前提：图太稀疏则缺口查询全是假空白（构建层转向覆盖优先是必要条件）
3. 共识≠正确（领域集体犯错常见）——四值状态是导航信号不是真理
4. 组合创新：每层有邻接工作，贡献成立依赖受控下游评测证明组合>各部分
