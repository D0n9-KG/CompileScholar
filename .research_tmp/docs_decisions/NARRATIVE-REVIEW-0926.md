## 1. 总体判断与发展潜力

**判定：revise（接近 accept-to-develop）**。

概念在 LKM 占位后存活：验证层主张经全文级核查无占位者，error
laundering + 架构不变量的洞察是非显然的，规模轴是产品级评测给不出的
受控资产。两处实质修复（C1 判别性证据、C2 相关工作轴）+一处措辞
精确化（C3）后路线成立。

发展潜力：高——**条件依赖**在门消融的因果方向：若验证层对下游有可测
因果效应，是主会级论文；若效应小，退路=canary 方法学+核验仪器校准的
测量学论文（findings 级）。这不是缺陷，是分叉点，叙事定稿前应知道
自己更可能落在哪支（门消融是全文最优先实验的另一理由）。

置信度：中高。剩余不确定性=ScholarStack 全文（"verification status"
未定义）、三个未重核旧竞品家族、LKM 迭代速度。

## 2. 问题与价值（视角一）

强。问题不是假想缺口而是双向实测：内部（"真记录 id+编造数值"穿透
全部 LLM 侧检查的病例；无身份治理时推导空洞 375→15,512 爆炸；朴素
归一化通道 40/46+55/65 误杀）+外部（2607.20527 核验器漂移审计；
AstaBench 官方自认不验引文真实性）。编译库产品化（60 天内三家）使
"40M 篇图谱保真度无人知晓"成为基础设施级问题——重要性随时间上升。

一处未言明的价值依赖：叙事假设"验证问题"对 ACL 社区的紧迫性与
"答题正确性"同级。实际桥梁是因果链（验证→接地门→引用精度），C1
修复直接决定这座桥的承重。

## 3. 洞察与贡献拆解（视角四）

problem→insight→mechanism 重构后，非显然成分清晰：
- **非显然**：验证作为贯穿三层的架构不变量（而非抽取后过滤器）；
  canary 事实+陷阱双向测量作为无 gold 质量仪器；治理式演化（加法与
  减法审计配对）
- **实现组件（不当贡献卖）**：五门本身的具体规则、embedding 分块
  合并、typed tools 目录、循环健康装置
- **社区学到什么**：编译收益的受控分解+规模轴；LLM 验 LLM 在建库期
  同样失效的实证；无 gold 保真测量方法学

贡献类型判定（主=实证发现/诊断，次=系统设计）与证据形态匹配，正确
回避了范式/基准首创主张。

## 5. 机制与逻辑（视角三）

因果链内部一致，三处需要修复的概念问题（非实验要求）：

**C1 判别性缺口（最重要）**：头号证据（Multi-108 三臂 F1）判别的是
"编译 vs 检索"——这是 LKM 已发表的主张；它**不判别**"验证 vs 不验证"
——我们的边际主张。且已测量的因果史里最大单次 F1 杠杆是引用格式桥
修复（+0.13），敌意审稿人可说"赢在 harness 胶水不在验证不变量"。
最小修复：把**同一编译产物、同一答题栈、门开/门关**的判别对提升为
旗舰实验（蓝图文本已含此消融，但排位是 Claim 2 之一，应升为主判别
证据）；消融阶梯显式加"未验证记录"档（raw→records-unverified→
records-verified→views/tools→+absence）；引用修复双值敏感性同表。

**C3 "确定性验证"措辞过强**：修复调用是 LLM（在确定性复检下）、
表格语义层是 LLM propose+结构门裁决。论文措辞必须是"确定性裁决；
LLM 仅作提案/修复者，产物必须重新通过确定性裁决"——否则被抓
overclaim 后整个验证叙事的可信度连坐。

**A1 散文类回锚的部分性**：数值逐字=构造上成立；散文=模糊阈值 0.85
部分成立。蓝图已披露，保持；建议叙事中主动把"数值型主张的验证"与
"散文型主张的验证"分开陈述强度，不给审稿人发现落差的机会。

canary 迁移假设（合成→真实）：概念上成立（有人工审计 0.11% 与 drop
统计佐证），但叙事应把 canary+人工审计+drop 统计呈现为**三仪器面板**
而非 canary 单独承重（C4）。

## 6. 主要优势（可保留成分）

- S1 问题双向实测接地（内部病例+外部审计），非假想缺口
- S2 不变量框架给全系统部件以必要性论证（elegance 判据达标）
- S3 验证位存活经全文级核查（非检索空缺的侥幸）
- S4 规模轴三点受控数据是产品级评测结构性给不出的资产
- S5 判分纪律（gold 探针天花板/版本锁/配对 CI/官方协议逐字）与 NLP
  会场效度优先级精确对口，且与"仪器先审"方法论自洽
- S6 披露计划（修复双值/AutoAIS/死区）预先拆除诚信攻击面

## 9. 关键问题与改判条件

1. 门消融的下游因果效应方向与量级——若验证层对 F1/编造率无效应，
   主叙事降为方法学论文（改判 pivot-with-rescue-route 到仪器/测量学
   定位，rescue 路线已存在）
2. ScholarStack 全文的 verification status 机制——若其做了确定性保真
   验证，验证位差异收窄，需重新措辞（改判条件=一手全文证据）
3. LKM 后续版本是否加入抽取验证章节——若加，抢时间窗的紧迫性升级为
   生存问题
4. 引用修复的审稿接受度——双值披露+机械性质论证若被判不对称优势，
   主结果需以修复前值保守呈现（叙事不变，数字变保守）
