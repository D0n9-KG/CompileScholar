# 提案 v4：SciAudit——科研 agent 结论的结构化审计（数据支撑版）

（v1 认知状态地图被否决；v2 双层方案被判重设计；v3 吸收审稿意见但被判定"主打检查数据层撑不住+验证脚手架膨胀"；v4 = v3 骨架 + E0/E1 两个判定实验的实证结果 + 第三轮审稿全部修正。**本版与前三版的本质区别：每条核心主张现在都有数据**）

## 1. 定位

**主命题：科研 agent 的结论可以被一个只依赖高置信知识结构的审计器审计——审计器只在图中有据时提起指控（prosecutor-not-judge），图的不完备性是安全边界而非缺陷。**

领域背景（外部实证）：
- 35 个 AI-Scientist 系统审计，仅 38% 有任何 novelty-verification 方法——"验证 agent 产出"已被钉为领域公认瓶颈 [2608.05179]
- LLM 事实性评估的逐条验证（FactScore/SAFE 谱系）已占——我们的差异化是**结构检查**：只有知识图能承载、逐条 entailment 原则上做不到的检查

## 2. 两个检查（均有实验数据支撑）

### 检查②（旗舰）：伪共识 / 引文祖先塌缩审计

agent 声称"领域共识"并引用 N 篇文献——审计器沿引文图追溯这 N 篇的证据来源，若它们的引文祖先高度重叠（都在抄同一批源头），表面 N 个来源实为少数证据的复读。

**E0 实验已实证主效应**（2026-09-03，n=31 agent 声明 vs n=34 人类综述同句引用组，同口径）：
- agent 引用集的引文祖先重叠（pairwise Jaccard）：**0.089 vs 人类 0.014（6 倍）**
- 置换检验 **p=0.0034**；n≥3 子样本 0.115 vs 0.015（8 倍）
- 结论：**伪共识在 LLM agent 输出上真实存在、可测量、与人类综述差异显著**——审计器有真实的检测对象，且这是关于"自动化科学如何失败"的实证发现（科学学贡献通道）

新颖性（第 4 轮调研）：组合层面真新颖。必引划界——JuryProbe [2608.20607]（同一认识论论点不同介质）、Citation Monoculture [2608.19230]（选择层集中度非 ancestry 层）、The Theory of Citing [1109.2272]（70-90% 引用是抄的，奠基）、引用完整性工具线（sciwrite-lint 等只做存在性不做独立性）。

### 检查①（第二卖点）：基线过时 / supersession 审计

agent 声称 "improves X"，审计器沿方法演化链判定 X 是否已被淘汰。

**E1 实验已验证逻辑天花板**（oracle 骨干 37 方法/37 边/6 家族 × 32 条模拟结论）：
- 检出率 1.00 / 清洁通过率 1.00 / 弃权正确率 1.00 / 误指控 0
- **核心机制发现**：正确语义需要**链传递性**（X 的后代链中出现被取代者 → X 过时；传播只向上游，取代者永不过时）——直接查 replaces 出边只检出 58%，链传递版 100%
- **链传递可达性恰好是逐条 entailment 做不到的图上推理**——"AdaGrad 过时吗"需要走 AdaGrad→RMSprop→Adam→AdamW 整条链，这是结构检查独有能力的直接实证
- 判定：逻辑成立，瓶颈纯粹是骨干密度（工程问题而非研究风险）

新颖性（第 4 轮调研）：三查中最强。现象有文献（撤稿持续被引 [2501.00473 等]、cited-reference 死亡率 [2203.08649]）；最近邻 E3 [2605.27072] 审人类论文判"弱基线"但不做图上 supersession 推理；MemStrata/Supersede 集群只做 agent 记忆新鲜度不做方法淘汰；Papers with Code 已死（302 重定向）——但本版只用它做市场背景不再当论证支柱（DA 修正：网站死≠需求存在）。

### 检查③（配套）：矛盾检查
被 FactScore 谱系+2026 密集 KG 矛盾检测占据，仅存差异化 = 对象是科研 agent 结论 + presence-only 语义。数据层已验证可行（V4-Flash 加显式负向抽取指令正确抽出 does_not_improve/fails_to_converge 带 polarity 标注）。

## 3. 骨干认证：跨家族交集投票（诚实命名）

v3 曾称 Dawid-Skene——第三轮审稿判定名实不符（2 个有效家族撑不起该框架），本版改名为**跨家族交集投票**，DS 列为相关工作。

机制：不同模型家族（DeepSeek 系 / gpt-oss 系）都抽到的边才进骨干。实验二已证：同家族（V4-Flash vs deepseek-chat）14/14 全重叠=假独立；跨家族只重叠 3 条且分歧集中在类型判断——一致性筛选的正是"事实+类型都稳"的边。

统计框架（审稿修正后）：多重列表分析（multiple-systems analysis，Fienberg log-linear 一脉）做骨干密度诊断，全程**下界语言**（"至少缺失 X%"），与 Snorkel label model 正面对比。诚实声明（R2 教训）：同源训练语料的 LLM 可能共享盲区——跨家族独立性是假设需持续检验，估计量在依赖假设违反下偏乐观，输出一律视为上界。

已知工程约束：CST 通道大输出超时——骨干认证按"小 chunk × 多模型"设计；K 倍成本作为一等指标报告。

## 4. 评测设计（预注册，含第三轮全部修正）

**双轴三态**：每条被审结论输出 accused / clean / not-audited（弃权），auditability rate 进头排双变量指标——**禁止输出层把三态折叠成通过/未通过两态**（DA 修正：not-audited 会被读作"查过了没问题"——沉默在审计场景是虚假背书，强制展示契约写进设计）。

**主表 = 错误类别 × 方法矩阵**：三类便宜护栏（数值代码重算/provenance 去重/答案时 entailment）作为必做基线臂，各类别分别报三态，弃权语义跨方法对齐。结构审计的存在权论证落在"逐条护栏结构性为 0 的格子"（supersession 和引文 ancestry）。已知风险预注册：MiniCheck 类工具有数据形态堵死前科（2026-08-09 实测地板效应）。

**错误分类学**：从真实 agent 失败记录派生 + held-out 类别冻结机制（分类学文件+时间戳，在任何检查器代码写下前完成分配）+ 红队分 naive/adaptive 两档（红队模型必须与审计器跨家族）。

**发现优先**（本轮新增，回应"分母不存在"的批评）：E0 已经是发现——v4 把它扩为正式研究：更大量 agent 输出（多模型多主题）上的伪共识发生率 + 人类基准，构成论文的实证章节。杀手级数字 = "agent 共识引用集的祖先重叠是人类综述的 N 倍（p<0.01）"——E0 已给出 6 倍/p=0.0034 的初步值。

**检出率三因子分解**：P(声明正确分解)×P(事实在骨干)×P(匹配命中) 分开测分开报（结论→可查询声明的分解是隐藏 NLP 难题，我们有对齐 bug 前科，不藏）。

**E1→真实骨干的桥接**：oracle 骨干证明逻辑成立；真实骨干密度是已知瓶颈。v4 承诺密度三选一路径（演化边专用第二遍抽取 / 借外部 method lineage 资源 / 审计驱动定向扩语料）按 backbone-size vs detection 曲线实证选择。

## 6. 风险与诚实声明

1. E0 样本量（31+34）是初步值——正式版需扩（多模型多主题，目标 200+ 声明），且人类对照需第三个主题补全（蛋白质主题 ar5iv 无全文）
2. 检查①骨干密度：oracle 证明了逻辑，真实骨干的演化边密度是最大工程风险（recall 0.10 起步）
3. 结论分解是隐藏 NLP 难题——三因子分解评测诚实处理
4. 审计器自身是 LLM——审计器的 judge 也交叉校验
5. 窗口收窄：Traxia（KG+矛盾检测 agent 发布框架）是并发 spec 无实验——若其扩展到结论审计，检查③缝隙关闭；检查①②的位置 4 轮调研确认仍空
6. OpenAlex 引文图质量依赖：429 限流已遇（退避+缓存+失败与未找到区分的教训写进工程协议）
