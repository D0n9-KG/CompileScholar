## 0. 采用判决（一句话，先给结论）

**有条件采用**：作为"有界领域语料上的配置/审计知识层"装在我的检索前端**后面**，服务实验设计与可审计新颖性判断两个环节——**不采用**它作为文献搜索/检索的替代品，**不采用**"科学 agent 必须有预编译 KB"这个形态的主张。条件有三：①补齐语料边界诚实标注与海量前端（F1）；②评测口径改锚可核验指标（本报告 §3）；③配置层供给残缺（56% 单层表头残留）在采用前修到可用线（F35 上提）。

## 1. 供需错位表（科学 agent 真实工作流 × 现系统供给）

环节划分取 AGENT-C Track 1-3 的科学 agent 实际工作流。每格：供给什么 → 够不够 → 形态对不对（API 粒度/返回结构/延迟/成本）→ 缺什么 → 证据锚。

### 环节 1：选题 / 领域认知（field awareness、趋势判断）

| 项 | 判决 |
|---|---|
| 供给 | genealogy 视图（as_of 时序）、coverage 视图（缺口）、cards 档案；typed tools：lineage/find_gap/as_of |
| 够不够 | **部分够，但被语料边界锁死**。53 篇的 KB 支撑不了"领域趋势"级判断——我的选题环节需要 field 级视野（数千篇尺度），现系统只给"这 53 篇里的谱系与缺口" |
| 形态对不对 | API 粒度对（typed 操作优于自由文本查询，RATIO 2608.27394 是评测版对应物）；延迟/成本优（预编译 amortized，答题 24.1k tok/题 vs 直读 ~180k，RESULTS-LEDGER 表 A1）。**返回结构缺一等公民：语料边界声明**——find_gap 返回"缺 X"时不带"此判断仅在 N 篇/截至日期内有效"的 scope 字段，消费者会误用为 field 级断言 |

### 环节 4：结果解释（对照文献定位自己的结果、异常归因）

| 项 | 判决 |
|---|---|
| 供给 | matrix 对比 + 条件性记录（67% 主张带条件实测）+ epistemic 三态（stated/demonstrated/cited）+ findings 工具 |
| 够不够 | 部分够。epistemic 三态对"这条证据多硬"的判断是真差异化（v1.4 仲裁实证 cited 294 条转正）；条件性记录对"我的结果和文献不一致是不是条件不同"对症。但结果解释还需要**失败知识**（"别人试过 X 为什么没成"），文献语料本身正向偏置缺失败记录（Bisht 2605.08956）——这是原则性天花板（F5，Personalized Auto-Research 2608.14881"隐默知识文献中不存在"），只能承认为边界条件，不能修 |

| 项 | 判决 |
|---|---|

### 跨环节横断错位：Type B 海量前端缺失（F1）

以上六环节里凡需要 field 级视野的（选题/新颖性/写作的引用广度）全部撞上同一堵墙：系统范式是"有界语料预编译"，无廉价海量前端。我的文献模块**不可能只活在 53 篇里**——采用形态必然是"live search 发现 + KB 深配置"双层，而现系统只有下层。通道消融已做完（query-decomp 最大杠杆 R@10 0.697；bm25 0.610>vector 0.530，ASSET-STATE §4），差的只是集成决策。这是**供需错位第一名**：不是能力问题，是产品完整性问题。

### 错位排序（严重度）

1. **有界语料 vs field 级需求**（环节 1/2/5 共因，F1）——采用阻断级
2. **实验设计配置层：最强需求 × 最残缺供给**（SCOPE 需求 vs 56% 表头残留，F4/B5）——卖点可信度级
3. **新颖性检查缺 claim 级进库接口**（环节 2，工具面全是 query-in，无 idea-in）——形态错配级，但修复最廉价

## 2. 存在性反证的处理：杀伤范围与诚实收窄

### 2.1 反证的准确杀伤范围

存在性反证清单（AGENT-C F1，全部正刊级一手）：
- AI Scientist v2：**摘要级 in-loop 检索**即达 Nature 发表级（DOI 10.1038/s41586-026-10265-5）
- Co-Scientist：裸检索+辩论锦标赛，三个湿实验验证案例（DOI 10.1038/s41586-026-10644-y）
- PaperQA2/3：全文 RAG、零语义预编译、repo 全仓 "knowledge graph" 0 结果，也超人（DOI 10.1038/s41586-025-10072-4；AGENT-C §4.3）
- 加码：MLE SOTA 链（47.7→70.2%）全不用文献层（F2）

**杀死了什么主张**：
- ❌ "科学 agent 需要预编译知识层才能做出好科学"——被存在性证明直接证伪，任何修辞救不回来
- ❌ "结构化知识提升生成质量表面分"——被消融反杀（F3：HypoKG endpoint-only 最高分、Graph2Idea +0.02），加上自有数据同向（PSV4 同题集均值差 0.000="判决器偏置吃掉材料改善"，RESULTS-LEDGER 更新日志 09-13）
- ❌ "KB 卖点建立在检索缺口上"——CRUX 五失败模式均非检索失败（F4）

**没有杀死什么主张**（每条带存活性理由）：
- ✅ **可审计性**：NovGauge 70%+ 判断对但证据不支持、17% phantom 引用、Verification Gap 零外部验证 oracle——即时检索给得出答案，给不出**可判定、可复核**的覆盖/新颖性判断。旗舰系统的成果是真的，但其新颖性验证过程不可审计（Sakana 官方仍认 inaccurate citations）
- ✅ **覆盖/缺失断言的结构性不可达**：即时检索能找"存在的东西"，枚举"不存在的东西"需要封闭语料+编译（NoLiMa 2502.05167：科研聚合/缺失/演化类=潜在关联密集负载，LC 直读虚标；BRINK 2508.08344 反证缺失知识推理之难）
- ✅ **成本摊销**：Kosmos 每 run 12h 读 ~1500 篇重建 world model——同一领域语料被反复消费时预编译省钱。**但此主张自己也没闭**：A2 的 CRITICAL"编译 vs 缓存不可区分"缺预算配对臂（DESIGN-DECISIONS A2 弱点），引用时必须带"待配对实验"标注
- ✅ **配置层供给**：SCOPE 实测 search 不解决 low-level 配置瓶颈——这是反证覆盖不到的地方（旗舰系统考的是 ideation/发现，不是"给方法配数据集超参"）

### 2.2 主张的诚实收窄形态（可直接进论文的措辞骨架）

从："为科学 agent 构建预编译文献知识层，使其具有强大的文献能力"

收窄为：

> **在语料有界、消费重复、判断需可审计的条件下**，预编译类型化知识层提供即时检索**结构性给不了**的三件事：①带语料边界声明的覆盖/缺失可判定判断（新颖性验证的审计原料）；②逐断言可溯源的证据纪律（quote 锚+epistemic 三态，编造 0/178）；③跨论文公平可比的方法配置矩阵（SCOPE 型实验设计瓶颈的对症供给）——并以摊销成本低于每 run 重复编译（成本主张待预算配对臂闭合）。它是检索前端的**下游深化层**，不是检索的替代品；"没有 KB 做不出好科学"不成立（F1/F5 承认为边界条件）。

三个佐证这个收窄形态有市场的独立信号：Co-Scientist 执行版在临床场景用"结构化指南语料 get_guideline 工具"（2608.26701）=旗舰系统自己也在结构成熟的有界语料上采用预解析 typed tool；PandaOmics/Edison 组织定制 world model 有客户付费（AGENT-C V5）=有界预编译已商业化；EMBL AI Librarian 机构级 agent-facing 预建知识层 +16pp（AGENT-A §5.4）。**模式：预编译在"有界+高价值+重复查询"语料上存活，在开放发现层死亡**——收窄主张恰好落在存活区。

## 3. 消融反杀警告落地：评测口径改什么

### 3.1 反杀机制复盘

F3 消融链：HypoKG endpoint-only（最少结构）拿最高 rubric 表面分、full-path 独特提升的是证据接地（打乱路径 Δ=−0.793 证明模型真用了结构）；Graph2Idea 图上下文仅 +0.02 novelty；Compressive KG top-k≈全 KG；ResearchAgent 随机元素竟好于无。规律：**结构化的收益兑现在证据纪律/接地/覆盖/多样性维度，常规 LLM-judge 表面质量分看不见甚至反杀**。自有数据三次同向印证：PS 风格维恒亏（内容维打平略胜但总分被风格拖死）、PSV4 均值差 0.000、fresh-16 泛化失败条款触发的总分 −0.062 之下藏着内容维正分。

### 3.2 现有口径逐项判决

| 口径 | 判决 | 理由 |

### 3.3 具体评测设计建议（预注册进下一战役，PS-53 冻结件不动）

## 4. 对照臂缺口：RL 内化臂 / live-search 臂

### 4.1 live-search 臂：**进，且现在就能低成本进**

- 该不该进：必须。四臂预注册要求（AGENT-C §5.3）：KB vs live-search vs 无外部知识 vs RL 内化；MLE-STAR 实测 live web search 是最大增益来源（2506.15692），不进这个臂，审稿人一句"你只是没给基线好工具"就能挂起整个主张
- 最小成本形态：**不是真接外部 API，而是"同语料 raw text + agentic 工具 harness"臂**——A-RAG 式三工具（keyword_search+semantic_search+chunk_read，2602.03442，training-free）或 DCI 式纯终端工具（2605.05242）跑在 PS-53 同 53 篇原文上。它把"预编译"与"有全文+好接口"两个变量干净拆开，恰好回答 A2 的 CRITICAL①"编译 vs 缓存不可区分"。现系统已有"同循环原文块对照臂"（+0.462，RESULTS-LEDGER 表 A1）是这个臂的雏形，升级点=把检索对象从原文块换成 A-RAG 式工具面。成本：纯推理侧，本地 3.8-27B 就绪后近零 API token；工程量=一个 harness 适配
- 真正的对外 live-search 臂只在 Type B 赛场（LitTraceQA/ScholarQuest 型）才需要，随 F1 集成一起进

### 4.2 RL 内化臂：**不进，用两个替代动作覆盖**

- 该不该进：不该。①不可行：Faraday 是 RL 训 27B（2608.13331），我方硬件现实是 GRPO 上 4090 且 1.5B-3B（memory 硬件可行性条目）——27B RL 不在预算宇宙内；②不对题：Faraday/ML-Agent 的 RL 内化考的是 MLE **执行**（Kaggle 型），不是文献理解——竞争假设成立的位置和我的考场不同；③有现成代理臂：RL 内化想证明的是"能力进权重后不需要外部结构"，这个威胁在文献 QA 上的可测代理是**强模型直读臂**（LC 臂）——E2 已有直读数据（Qwen3.8-Max 直读 4.00，e2-r2-scaling-verdict），NoLiMa 型负载上补设计题即可，零训练成本
- 替代动作：①LC 直读臂进四臂矩阵（AGENT-C §5.3 本就要求"另含 LC 直读臂"）；②引用+监测：论文中显式引 Faraday/ML-Agent 为竞争假设，写明"RL 内化在文献理解域未测，若出现 RL 训练检索 agent 在我方赛场 prompt 版胜出的工作则重审"——触发条件式披露，与 DIRECTION §4 推迟项体例一致
- 何时升级：ASearcher（RL 前后 +15~22 分，AGENT-A §3.1）一类工作若把 RL 检索 agent 打到文献 QA 赛场，用其**开源权重**（Harness-1 20B 权重开源）当现成臂——借别人的 RL，不自己训
