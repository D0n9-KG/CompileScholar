## 一、最强反方论点（拒稿 meta-review 第一段草稿）

> 本文的全部承重证据是：在一个由作者自己出题、自己设计判分协议、自己六轮修补执行 harness 的 50 题内部基准上，所提类型化访问臂以 0.02 分的余量通过了作者自己预注册的非劣性闸。这 0.02 分折合 50 题总分上的 1 个题分，小于作者自己披露的 ±0.1 单跑方差带；反事实核算显示，若把五个"修复靶题"（T08/C02/C03/T05/T06——harness 修复正是围绕它们设计并三轮验证的）的成绩换回其修复前实测值，本轮均分跌回 3.22，非劣性以 −0.28 FAIL，其余 45 题净贡献为 −2 分。换言之，PASS 的全部余量来自修复的在样本内收益，方法在未被修复循环检视过的题目上仍然净落后。归因实验（耦合交互项 +0.50）的对照腿跨判分协议取自另一个实验、每题只消耗实验臂一半的 token、且架设在作者自测材料覆盖率仅 50% 的无重排检索上；"收益来自表示语义"未排除"算力换质量"。唯一一次外部考核字面触发"劣于基线"，被一条事后发明的规则降级为"不可判定"，三天后又被作者自己的代码审读发现全程处于 oracle 泄漏形态；而构成整个项目动机的规模主张（C4）没有任何自有实验。本文证明的是：在整读完全负担得起的规模上，一个精心调校的 agent harness 能在其设计者的考卷上接近整读。

## 二、问题清单

### CRITICAL-1 非劣性 PASS = 定向修复循环的在样本内产物，无任何出样本余量
**维度**：实验效度 / "调到通过为止"边界 | **判定：成立**

**锚点**：
- EVIDENCE-B3-REPORT.md Round 2 §二（闸2 PASS，3.420 vs 阈 3.400，余量 0.02）、§三（靶题回收 T08 1→4 / C02 3→5 / C03 3→5 / T05 1→3 / T06 2→3；r1→r2 逐题 15升10降25平 净+0.16）、§八披露1（±0.1 单跑方差带）
- EVIDENCE-B3-PREREG.md IL-C4/C5/C6 节（修复从 T08/C02 失败设计，验证跑= T08×3、C02×2，"分数盲"但**题目选择=失败驱动**）
- B3-VERDICT-COMPUTED.md 闸4 节（逐题 vs old flat：**11胜22平17负**）

**算术（算给他看）**：
- PASS 余量 = 0.020 × 50 题 = **1.0 题分**。
- 五靶题 r1→r2 回收 = +3+2+2+2+1 = **+10 题分**；全体净移动 = +0.16×50 = +8 题分 ⇒ **其余 45 题净 −2 题分**。
- 从 round-1（3.260）到过线（3.400）需要 +7 题分：靶题带独占 +10，非靶题为负。
- 反事实：T08 单题回收（+3）拿掉 → 3.36，**FAIL**；C02/C03/T05 任一拿掉（各+2）→ 3.38，**FAIL**；T06 拿掉 → 3.400，余量归零。**五个靶题每一个单独都是 PASS 的必要条件**，T08 一题的回收（3 分）= PASS 余量（1 分）的 300%。
- 逐题战绩 11胜17负：非劣性均分靠少数大赢题（C07 +3、T05 +2——后者恰是靶题）撑住，多数可判题目上仍落后。

**攻击**：
1. "闸冻结一字未动"是真的但窄——**harness 就是方法**（笔记写入闸/断路器/合并分支全部是 H3/H6 文献驱动的设计组件，PREREG 循环参数节），对设计组件做六轮失败题定向迭代再全量重跑，等价于在同一考卷上迭代方法直到过线。round-2 不是独立观测，是"见过 round-1 全部失败细节之后的第一次 bug-free 观测"，n=1。
2. 修复的因果归因论证（"回收集中在缺陷带=因果非运气"，REPORT R2 §三）**是循环的**：修复从这些题的失败设计、在这些题上验证（T08 三轮重验、C02 两轮）、收益在这些题上兑现。真正的出样本读数藏在同一张表里而报告没有点破——**非靶题 45 题净 −2 分**。
3. 三代 pilot（IL-C1/C2/C3）在**同 5 题**上跑了三轮仍未拦住同族三个吞内容缺陷，全量跑才暴露——pilot 与靶题修复是同一个过拟合模式的两级：小样本反复迭代对失败模式的选择性敏感。这直接引出问题：round-2 harness 里还有没有 IL-C7？36% 触顶率、78% 闸通过率、A06 兜底形态说明系统仍不健康；若下一轮又"合法迭代出"缺陷，第几次重跑才算数？"调到通过为止"的边界声明（确定性修复/禁选择性重跑）不能回答这个问题，只有新考卷能（PaperScope R2）——所以 **B3 PASS 在证据学上是临时的，材料包却把它写成"三场证据战收官/闭环"**（REPORT §九），框架颠倒了证据权重。
4. 余量 1 题分 vs 作者自报方差带 ±0.1（=5 题分）：PASS/FAIL 二值判决施加在一个噪声 5 倍于余量的单跑点估计上，无 CI、无 seed 重复、无 bootstrap。同一批材料里 DSF 闸对同题给出了 T01 5→1、A15 5→1 的单题 4 分摆动（STAGE0 §5）——单题方差实锤就在自家档案里。
5. **前科量化**：hybrid-experiment-verdict.md 记录了同一循环的既往产出——记录对齐臂在作者原 50 题上 4.32"全场历史最高"，新 20 题反转 −0.45，判决原文写明"题目与记录字段的对齐是开发集效应（**出题人=记录设计者的老循环**）"。该先例实测的对齐膨胀量级（约 0.5-1.0 分）是 B3 余量（0.02）的 25-50 倍。B3 主臂比当年混合臂与记录结构耦合更深，同一膨胀机制没有理由消失。
6. 非劣阈 −0.10 本身无外部理据（未绑定任何实际等价性论证），而 PASS 余量是阈内 0.02；比较锚 old flat 3.500 也是单跑、同出题人、同裁判体系，且 flat 家族在不同渲染版本间横跨 3.00-3.50（REPORT R1 总分表：new flat v1.2 339k=3.000 vs old flat v2 166k=3.500）——**"直读基线"不是一个数，是作者渲染选择下 0.5 分宽的一条带**，0.02 的余量在这条带面前无意义。

**作者可辩护点（如实列出）**：三个缺陷是代码级死锁（部分拒写丢有效行/断路器只数全拒/拒写分支吞答案吞动作），修复确定性、"闸的牙齿不动"、验证分数盲、全量重跑禁挑题、两轮实录全披露。这些使它不是造假；但辩护救不了判决效力——bug-free 状态下的方法真实水平恰恰是唯一没有的东西（修复后仅一次运行，且在样本内）。

### CRITICAL-2 耦合增益 +0.50：归因的两条腿都瘸，"收益来自表示语义"未成立
**维度**：归因/对照设计 | **判定：成立**

**锚点**：
- EVIDENCE-B3-PREREG.md 三臂设计节（rag20=stageA-kimi 口径无 J1 冻结引用；对照臂 text_search k≤8、无重排、七招抽掉）+ H7(d) 挂账节
- B3-VERDICT-COMPUTED.md 闸5 节 + H8 节（对照臂 308k/26题）
- EVIDENCE-B3-REPORT.md Round 2 §二闸5行（"同轮配对"表述）、§五 frontier 表（"同题量级与主臂相当"）、§六（主臂单题 mean ~25.5k tokens）
- 离线检索审计：材料覆盖率 50%（142 未查到/119 截断）——PREREG 前史节 + 材料包 §3

**攻击**：
1. **token 不对称拆掉"同循环同预算"前提**：主臂 24-25.5k tokens/题（答案 1.206M/50），对照臂 11.8k/题（308k/26）——**实验臂每题烧 2.0-2.2 倍算力**。Δtyped +0.69 vs Δraw +0.19 的差，无法与"类型化观察更肥、循环更贵"的算力差分离。而 frontier 表用"同题量级与主臂相当"一句把这个 2 倍差抹平——这句在字面上不成立（11.8k ≠ 25.5k 的"相当"），且恰好出现在支撑归因主张的那张表里。
2. **Δraw 腿跨三重口径**：ReAct rawtext（round-1 harness、J1-adjusted）− rag20（另一个实验、Kimi 判分、无 J1、架构不同——rag20 是 top-20 chunk 单发 RAG，round-2 tools 是类型化工具一次性规划，两个"无循环基线"根本不是同构臂）。交互项=两条不可通约的差再做差。J1 的方向性已知是压分（主臂 raw→adj 降 0.04-0.08），若 rag20 同尺重判，Δraw 上移、交互项收缩 20-40%——报告只以"披露近似"处理，但材料包 §1 C3 把 +0.50 当作"收益可归因到表示语义（非通用 agent 技巧）"的**头号证据**在 headline 使用。
3. **"同轮配对 +0.462"不是同轮**：主臂取 round-2（修复后），对照臂沿用 round-1（修复前 harness），REPORT R2 §二闸5行的"同轮配对"四个字与 §八披露3"对照臂为 round-1 产物"直接矛盾。11胜12平3负的方向信号是真的，但它是跨轮、跨 harness 版本、跨 token 预算 2 倍的配对。
4. **对照臂被结构性养弱**（不必然故意，但效果同）：k≤8、无重排、无 hybrid/BM25、嵌入=CST 单一模型、架设在自测材料覆盖率 50% 的检索层上，且触顶 0%（对照臂从未用完步数预算——它的 +0.19 循环增益是在预算未约束状态下测的）。2026 年任何一个及格的 rawtext ReAct 基线（重排+hybrid+k 放大）都可能把 Δraw 抬到 +0.4 以上，交互项随之腰斩。**强化 rawtext 臂在所有材料里没有挂账**——H7(d) 只补强化 one-shot typed 臂，恰好没有补最能威胁归因主张的那个对照。
5. 对照臂 n=26 vs 预注册冻结的 25 题（PREREG 三臂设计节"25 题配对子集"），执行漂移无任何披露条目。

**结论**：同轮同判分下 typed-vs-rawtext 的配对差（+0.462，11W3L）是材料里最干净的耦合信号，但它撑不起"表示语义"的强归因；被 headline 引用的 +0.50 交互项撑不起任何归因。

### CRITICAL-4 "成本 1/7"的经济模型是稻草人：无摊销模型、无视 prompt caching、绝对金额在已证规模下无决策意义（v6 CRITICAL #1 未解除）
**维度**：主张经济学 / so-what | **判定：成立**

**锚点**：
- 材料包 §7 第一行（宣称"编译 vs 缓存"CRITICAL 由访问层三轮证据解除）

**攻击**：
1. **v6 要的是两件东西：能力配对对照 + 摊销模型。前者做了一半（见 CR-2），后者至今为零**，材料包却申请解除该 CRITICAL。frontier 表只计答题侧 token：记录层构建（40 篇抽取 6691 条）、治理环人工仲裁（218 表面名、468→295 实体、186 组待裁决）、schema 一周三版的返工，全部不入成本。flat 臂不付任何构建成本。"成本 1/7"是查询侧口径的 1/7，盈亏平衡查询次数 N* 从未被计算——这正是"编译 vs 缓存"质疑的原始形态。
2. **成本模型无视 2026 年标准基础设施**：flat 臂 9M/轮的成本假设每题为独立全量重读。同一语料作为缓存前缀（prompt caching 为标准 API 功能，缓存读价格约为原价 10-25%）可把 flat 的有效成本压缩数倍，零工程量。B3 的 7 倍优势里有多大一块是"未用缓存的朴素 flat"稻草人贡献的？无数据。（本条为 DA 推理，非档案实测——但举证责任在设计成本主张的一方。）
3. **绝对金额**：40 篇档 = 166k 字符 ≈ 单题一次 4-6 万 token 上下文的调用。2026 年 API 价格下，整读一轮 50 题的边际成本是个位数美元。"1/7"省下的钱在一次实验室决策里不构成变量。价值只在直读物理不可行的规模档兑现——而规模档（C4）自有实测=零（材料包 §5.7 自认）。**所以 so-what 的答案是：已证明的规模下没人在乎，在乎的规模下什么都没证明。**
4. 真实替代品对照缺席：NotebookLM（50 源免费、带引文）、PaperQA2/OpenScholar（材料包自己的基线名单）、任何长上下文模型直接塞。用户的替换成本=零工程；本方法的替换成本=抽取管线+治理环+schema 维护+单 provider 锁定（STAGE0 §5：CST 无 Qwen3.8-Max，全部作答臂锁单一供应商）。材料里没有一行与这些替代品的同努力量级对比。
5. C4 的"算术墙"是模型选择性的：~800k 字符 ≈ 20-50 万 token，撞的是所选模型的窗；2M 级窗口的模型把墙推到数千篇。官方 40.95 的引用还违反自家审计结论——part_A §2.5/§三.3 明文"官方数字基于 200 题子集、禁止裸引做主对比、四维不可比"（paperscope-external-verdict.md 也写了"官方40.95与我们的分四维不可比"）。C4 目前的证据形态=被自家档案禁止的引用方式。

"不可判定"的降级规则（协议教训3：混杂检查闸）是**看到 FAIL 结果之后发明的**，并追溯适用于已出的结果。预注册判据的字面输出是"劣于基线"；把它改写成"不可判定"的裁量权由协议设计者=被测者=审计者三合一的主体行使。三层混杂的证据（Q5 铁证、JEPA/CMA 版本差异）是实在的，但它们支持的最强结论是"该基准的 gold/judge 有缺陷"，不自动等于"我们的臂不受此影响"——direct 臂在同一缺陷协议下拿 3.62。**如果协议烂到判不了 view 的负，它也烂到证不了 view 的任何正**（+0.83 vs RAG 同样跑在 oracle+烂 gold 上）。材料包只降级了负结论，保留了正结论——不对称降级。

## 三、被忽略的替代解释

1. **算力换质量（最强，未排除）**：+0.58 循环增益与 +0.50 交互项均可由"每题 2.09× token（vs 一次性臂）/2.2× token（vs rawtext 循环臂）+多步重试"解释。缺失对照=同预算强化 one-shot（H7(d)，已设计未跑）与同预算 rawtext 强化臂（未挂账）。两个对照合计 <1.5M token。**在这两个对照跑出来之前，"表示语义"归因在逻辑上不可辨认。**
2. **开发集对齐效应（有前科、有量级）**：作者出题与记录字段措辞同构 → 记录对齐臂在旧题膨胀（hybrid 实测 +0.96→新题 −0.45 反转；判决原文点名"出题人=记录设计者的老循环"）。B3 在**同一批 50 题**上以 0.02 余量 PASS，该机制的预期膨胀量比余量大一个数量级以上。检验成本极低：Stage A 已有 20 道新题形态的先例，B3 主臂在 20 新题上重跑一次（~500k）即可测出对齐项——材料里没有这个计划。
3. **判分对"表面可溯源性"的奖励**：record_id 回指+verbatim 锚点让答案在裁判眼里显得 grounded；J1 补丁只核数字是否池内命中（A05 抽验 12 个数字仅 5 个命中而 raw=adj=2 的判词"扣分点非编造类"——B3-VERDICT 闸6节），不核答案是否覆盖题目所需材料。在材料覆盖率 50% 的底座上拿 3.42/5，一个未被检验的解释是：**gold 题只需要被覆盖的那 50%**（出题人看着记录层出题）——若真，则分数与覆盖率并存不是噪声鲁棒性，而是负载循环性的定量显影。
4. **修复的在样本内收益冒充方法收益**：round-2 相对 round-1 的 +8 题分中 +10 来自靶题、−2 来自其余 45 题。"bug 修好了"与"方法变好了"在单跑二值闸里不可区分；前者是工程事实，后者需要出样本观测（新题或重跑）才存在。
5. **flat 基线自身的渲染不稳定性**：old flat v2=3.50 与 new flat v1.2=3.00 差 0.5，说明"直读"成绩是渲染设计的函数。B3 与 flat 的 −0.08 差距，落在 flat 家族 0.5 宽的版本带内——"追平整读"的"整读"指哪一个，由作者选择。

## 四、缺失的利益相关视角

1. **独立出题人**：全链条零。PaperScope R2 是唯一计划中的解药，尚未跑（材料包 §6"开工令待用户"）——在它落地前，所有 PASS 都无此视角。
2. **知识库维护者/治理工程师**：186 组待仲裁、schema 一周三版、venue_year 回填 22/40 未完成——维护劳动既不入成本模型（CR-4）也无稳定性测量；"治理环=工程实践非卖点"的定位使这个角色的成本免于被任何闸约束。
3. **终端科研用户**：无用户研究、无与 NotebookLM/PaperQA2/长上下文直塞的同努力对比；"谁在乎 1/7"（CR-4.3）的问题没有提问对象。
4. **复现者**：单 provider 单快照无版本 pin（MA-4）、权威计算档嵌合（MA-3）、判分裁判型号未点名（MINOR-3）——2026 年生态位准入标准是 (b) 全自跑+统一性明文（part_A §三.1），当前档案连自家复现都困难。
5. **统计学家**：全证据链零 CI、零功效分析、零点估计外的不确定性量化；二值闸施加在噪声 5-45 倍于余量的单跑上（CR-1.4、CR-5.3）。
6. **手握 SciAtlas v2 成绩的审稿人**：对方已在 4 外部基准+约 20 具名基线全自跑+GPT-5.5 统一明文+judge 自评回避（part_A §2.5）；我方决定性证据是自研基准自研判分——同场投稿时的相对位置材料包没有评估。

## 五、Observations（非缺陷，如实记账）

1. **披露密度是真实的、罕见的美德**：每份报告带披露清单、两轮实录全保留、预算超帽报数、泄漏自曝降级——问题不在披露的真实性，在披露与 headline 的脱钩（MA-6）。
2. **"禁选择性重跑、全量 50 题重来"的纪律是真约束**，比多数同生态位工作严格；IL-C4 处置还把它写成决策点交用户而非自行执行。
3. **瓶颈迁移链（渲染算术墙→规划广度→绑定+螺旋→非劣）作为工程叙事是连贯的**；但三代 pilot（同 5 题三轮）没能预测出全量跑暴露的同族三缺陷——pilot 的题目多样性设计（5 题）对其要拦截的缺陷家族功效不足，这本身值得写进方法论教训而非只写"每轮各拦一个真缺陷"的胜利叙事。
4. **DSF 双快照闸的设计（判据冻结、双候选、结构闸+偏斜闸）是全材料包里方法学最严格的一份文档**——同样的严格性（重复测量、方差带对照）没有用在自己的决定性判决上。
5. 验证环节的三轮迭代各拦一个真缺陷（吞笔记/吞答案/吞动作），从工程角度是成功的防御性调试；本席的攻击全部针对这些修复被用作**判决证据**的方式，不针对修复本身的正当性。
6. 材料包 §7 主动把上轮三 CRITICAL 提请复核并自报"未重查/仍无系统实验"——提请复核的姿态诚实；本席的结论是三项中零项可解除、一项部分缓解。
