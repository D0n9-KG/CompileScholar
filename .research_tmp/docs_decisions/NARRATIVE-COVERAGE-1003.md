## 0. 一页结论

**旧叙事撑不起顶会**，三个原因叠加：
1. 新颖性被占：生长/知缺/定向探索已被 LKM v2（2609.27297）、Agents-K1（2606.13669）、ASKS（2608.29612）覆盖；
2. 系统里没生效：card 视图结构错配（31b 起全假阴性）、lineage 回放 41/41 空、findings 字母序截断——
   "状态指挥检索"在实测中贡献≈0（状态工具 2.8% 调用、1 次进答案）；
3. 证据输且不干净：CS2 同题配对输 harness −0.049（11 批全输）；KB 的 demand_core 层 803 篇是用 dev 100 题题面
   检索建的（held-out 不 held-out）；知识截止全臂未执行；judge 的"Perplexity"行实为 OpenAI DR。

**新主叙事（推荐）**：LLM 研究 agent 的主导失败不是"读不懂"或"组织不好"，而是**没找到**——而且它们**不知道自己没找到**。
我们把"漏了多少"从事后评测指标变成 agent 运行时可估计、可行动、可检验的量：已找到论文的参考文献表是对领域文献的
重复独立抽样，被几篇引用就是"重捕次数"，由此按子主题估计未见文献量，用它决定往哪找、何时停，并输出带置信区间的覆盖声明。

**为什么是它**（按用户的四条标准）：
- 意义：61% 的失分来自没找到长尾论文（§2.2）；所有系统重要参考文献覆盖 ≤0.19；系统综述、新颖性判断、related work
  都要求完整性，而现在没有任何系统能告诉用户"你还漏了多少"。
- 方法创新：一个新的运行时原则（引文自我采样→覆盖估计→驱动检索），不是组件拼装；统计估计本身借自生态学，
  贡献在依赖/异质校正、驱动 agent 决策、开放网络下的校准验证（§4）。
- 效果有尺子：DSB 现成基准 + 综述参考文献 gold + 系统综述集合，覆盖/预算曲线和校准都是客观数。
- 独特性：查新核过（§3），最近邻只占了其中一块。

| Bron et al. / Callaghan 2020 | 2404.01176 / Syst Rev 9:273 | TAR 统计停止规则（Chao / 超几何） | 封闭候选池+人工筛，非开放网络 agent |

**真空白（精确一句）**：LLM 文献 agent 在运行时把每篇已找到论文的参考文献表当作一次捕获，分子主题、带依赖与
异质性校正地估计未见相关文献量，并用这个估计同时驱动检索分配和停止，最终输出经过校准检验、带置信区间的覆盖声明。

**措辞纪律**：不说"首次用引文做捕获-再捕获"（Loe & Jensen 必须正面引）；贡献落在"运行时可行动的估计 +
开放网络下的依赖/异质校正 + 校准验证 + 预算效率"。

## 4. 方法：CoverScope（暂名）

**一句话**：把文献探索当作"给一个物种未知的生态系统做普查"——每篇读到的论文的参考文献表是一张捕获网，
一篇论文被几张网捕到就是它的重捕次数；从重捕频次分布估计每个子主题还剩多少没见过，把下一步检索预算投向
"未见量最大"的子主题，估计覆盖率达到目标就停，并告诉用户覆盖了多少、置信区间多宽。

### 4.1 组件
1. **捕获源（traps）**：语义检索、关键词检索、后向引文（参考文献表）、前向引文（被引）、作者/venue 邻居。
   每个源是一种"捕获网"，可捕获性不同（语义检索偏热门、引文偏同社区）。
2. **捕获历史**：每个候选论文记录被哪些已找到论文/哪些源捕到（频次向量）+ LLM 相关性判定（只判候选，不判全网）。
3. **子主题划分**：已找到的相关论文按内容聚类（嵌入+LLM 命名），每个子主题独立估计——
   异质性（热门 vs 长尾）主要发生在子主题之间，分层把它吸收掉。
4. **覆盖估计器**：分层 Chao1/ACE 作为下界基线；主估计用 log-linear 捕获-再捕获（建模源间依赖，
   例如"同一作者团队的参考文献表互相重叠"）；输出每个子主题的估计总量、已覆盖比例与 bootstrap CI。
5. **分配与停止策略**：下一轮扩展哪个种子/哪个子主题 = 期望新增相关论文数最大（估计未见量 × 该源在该子主题的
   历史产出率）；全局估计覆盖 ≥ 目标（如 80%）且 CI 下界 ≥ 阈值时停止。
6. **覆盖声明**：报告里给出"本综述覆盖了估计相关文献的 X%（95% CI [a,b]）；子主题 S 覆盖偏低"。

### 4.2 与"知缺"旧叙事的连续性
旧叙事的"知道自己缺什么"在这里落成一个可度量、可校准的统计量（未见量），"定向探索"=按未见量分配，
"会生长"=覆盖随探索单调上升且可追踪，"可追溯"=每篇入选论文的捕获历史。四件套变成一个算法的四个面，
但叙事主轴只有一个：**知道自己漏了多少**。

## 5. 实验设计

### 5.1 金标（三套，互相补短）
| 金标 | 规模 | 优点 | 短板 |
|---|---|---|---|
| DSB 重要参考文献 | 48 题（去重后），~18 篇/题 | 现成基准、可直接接下游 nugget | 人类引用表不完备（Sahu：51% 判相关） |
| 综述参考文献表 | 自建：截止日期前的 CS 综述 100–200 篇，参考文献中位 64 篇 | 综述追求完备，最接近"全集" | 需过滤非论文条目 |
| 系统综述集合（CLEF TAR 2017–19 等） | 公开、带完整相关性判定 | 真正的"全集"金标，校准实验首选 | 医学域 |

### 5.2 主实验
1. **覆盖-预算曲线**：同一预算（读/判定的候选论文数）下的真实召回。对比：语义检索 top-N、PaSa 式深度 3 扩展、
   PaperQA2 重叠阈值遍历、Sahu BFS、均匀分配的多源捕获、CoverScope。
   预期卖点："用 1/10 预算达到 BFS 的召回"（待验证，见 §7 门槛）。
2. **校准**：估计覆盖率 vs 真实覆盖率（可靠性图、ECE）。对照：朴素 Chao1（预期低估总量/高估覆盖）、
   LLM 自报"我觉得找全了"、RAAC 式饱和停止。
3. **停止质量**：目标覆盖 80% 时，实际覆盖的分布与浪费的预算；对比固定预算与启发式停止。
4. **下游**：把 CoverScope 的候选池喂给同一个写作器（B0 直写，已证明不输结构化写法），看 DSB nugget coverage
   能否逼近 oracle（我们的尺子上 0.379）；以及与 OpenAI DR 官方数（.392，不同 judge，仅引用行）的关系。

### 5.3 消融
估计器（朴素 Chao1 / 分层 / log-linear 依赖校正）；分配（均匀 / 按未见量）；捕获源（去掉后向引文 / 前向 / 语义）；
相关性判定器（27B / DeepSeek / 规则）对估计的影响。

### 5.4 分析节（今晚已有数据）
- 综合层：强加抽象轴伤分（§1 表），解释"为什么不在组织上做文章"。
- 基准效度：CS2 的 IR 被长度主导（官方 simplified_eval 无长度惩罚，harness 长度–IR r=0.76）；
  截止泄漏（harness 42/100 题引 2026 论文）；DSB 66 个 gt 目录仅 48 个唯一题（官方均值重复计 18 题）、
  organization 指标 23 目录错位；CS2 100 题功效不足（检 Δ=0.05 需 ~176 配对）。
  这些作为"评测注意事项"写进实验设置，不作主贡献。

## 10. 坦白的总体判断

> 10-03 晨用户质疑："这个新叙事就是增强一下检索召回是吗？"——答：目前被数据证明的部分就是召回增强，且手段已知；
> 让它不同的"估计漏了多少"未通过门槛 B；它是检索/覆盖方法，不是用户要的抽取/组织方法。本档降为"备选"，
> 主方向待用户在"接受检索方向"与"换一个组织真正是瓶颈的任务"之间裁定。

今晚的工作把方向收敛到了**正确的层**（覆盖层是公认基准上的主导失分，且有客观尺子），但**还没有找到一个已被
数据证明"效果很好"的方法**。可达性信号很强（召回翻倍），统计估计这一新颖部分在代理金标上没过关。
最诚实的说法是：这是目前证据最扎实、最接近顶会标准的方向，但需要 2–3 天的全集金标实验来决定它是一篇
"会估计自己漏了多少"的方法论文，还是退一步成为"引文自我采样驱动的高效文献覆盖"的方法论文。
