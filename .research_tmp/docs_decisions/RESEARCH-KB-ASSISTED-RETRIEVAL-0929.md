# 调研：结构化知识辅助 Agent 检索（2026-09-29）

来源：调研代理一手验证（arXiv ID 全部核实过，WebSearch 污染已弃用）。
权威档之一（与分层证据/预算调研档互补）。

## 核心结论：四条可吸收路线（按杠杆排序）

### 1. 谱系链兑现 = 最高杠杆：HippoRAG 式 PPR 遍历
实体注册表+方法谱系+跨论文矩阵**已是现成图结构**——查询实体作种子 →
Personalized PageRank 沿谱系边/引文边扩散 → 候选论文池，作为
Sciverse 外的第二检索通道。
- HippoRAG (2405.14831, NeurIPS'24)：单次 PPR 捕获多跳关联，零训练
- HippoRAG 2 (2502.14802, ICML'25)：+原文段落深度融合
- Interleaved snowballing (2402.08339)：引文链扩展+检索交替的经典系统化
- DeepSurvey (2605.29522)：引文图扩展做综述聚焦检索
**我们缺的只是遍历机制，结构已备好。**

### 2. 实体注册表 → 外部检索查询扩展（TaxoIndex/QeBERT 路线）
外部检索发 query 前用实体档案输出同义词/别名/上位词词表。
- TaxoIndex (2410.19218)：taxonomy 归一桥接查询词与论文表述（索引端）
- QeBERT (2301.11069)：引文网络信号进查询扩展（查询端）
- CODEC (2205.04546)：实体信息查询扩展提升排序的基准级证据
- OpenAlex (2205.01833)/S2 平台 (2301.10140)：工业级 concept 归一层对照
**我们的实体注册表就是词表源头，边际成本极低。**

### 3. 跨论文矩阵 → GraphRAG 社区摘要
矩阵按主题聚类预生成社区级摘要，服务综述级/全局性问题。
- GraphRAG (2404.16130)：community summaries
- RAPTOR (2401.18059, ICLR'24)：递归聚类摘要树（与我们分层同构）
- LightRAG (2410.05779)：local/global 双层检索（实体档案=local，
  矩阵/谱系=global 的直接映射）

### 4. PaperQA2 式矛盾检测 (2409.13740) 作为跨论文矩阵差异化输出
同题面多篇论文结论分歧检测——结构化跨论文知识独有、朴素 RAG 难复制。
