## 4. 判读规则（结果出来前写死）

- **格式对齐（W1-6）**：若片段截到与 harness 同长后，我们对 harness 的 CR+CP 优势仍 > 0 且 CI 下界 > 0，
  可写"逐句证据引用在格式对齐后仍提升引用质量"；否则写"官方格式下引用分更高，其中格式贡献占 X"，并删除"更扎实"类表述。
- **长度**：报 score ~ system + log(words) 的系数，不据此调整主表。
- **叙事二选一**：H1 成立 → 方法论文（主张：预编译的领域状态在领域级问题上有可归因收益）；
  H1 不成立 → 基准 + 评测效度分析论文；不再加题、不换指标。
- **状态层留出检验**：族成员按 TaxoBench 的 ARI / V-Measure；族级性质、局限、开放问题召回；每臂 3 次运行报均值 ± SD；
  人工校准判分后修正报数。
