# PROPOSAL v6：面向科研智能体的文献知识编译层（Need-Driven Knowledge Compilation）

> 状态：设计骨架稿，供审稿裁决。写作日期 2026-09-03。
> ⚠️ 审查焦点声明（作者自身已提出的质疑，请优先裁决）：
> (a) "提前把要用的处理好"本质上是数据库物化视图（40 年技术），Lacuna 已做粗糙版（预计算地图省 4 倍成本）——本提案的创新性是否足够支撑一篇顶会方法论文？
> (b) 与 KG / materialized views / Lacuna 的差异化是否真正成立？

## 1. 问题与动机

**需求侧实证（已完成）**：
- E2 三臂实验（12 个模拟智能体实验规划任务）：全文直读 2.83/5、平面 RAG 2.75/5、现有稀疏图 1.58/5——失效集中在跨篇聚合（2.33 最差）、时序、数值；强模型（gpt-oss）修不好聚合。
- Asta 平台 20 万条真实查询日志（arXiv 2602.23335）：关系型查询约占 30%（因果 19.1%+对比 7.3%+跨篇综合 2.1%）无任何原生接口；方法学筛选条件占 42%；时间/数据可得性查询失败率最高（OR 0.47-0.82）。
- 七个系统族代码级负载分析（AI Scientist v1/v2、Agent Laboratory、PaperQA2、OpenScholar、开源 deep research、Lacuna）：压缩是第一成本（PaperQA2 RCS 每块每查询一次 LLM 摘要，$1-3/查询主因）；Agent Laboratory 文献综述阶段失败率 60-80%（全阶段最高）；AI Scientist 新颖性检查=LLM 裸读 10 条摘要（无程序化查重）；全部检索入口是关键词；停止条件全是计数器。

**竞争格局（已完成六方向查新）**：SciAtlas（浙大+UCL，2605.22878，4300 万论文五层 KG）、Lacuna（2606.26246，预计算概念元素+MCP 接口）、Agents-K1（2606.13669，agent 原生 KG）已占位"为智能体的结构化文献资源"框架；但四个空轴有原文证据：①需求驱动方法论 ②内容四轴（SciAtlas 原文自认 "experimental procedures, conditions, measurements, and outcomes are not yet represented as explicit objects"）③演化机制（SciAtlas=periodic rebuild）④全文深抽取（SciAtlas=元数据级）。第五空轴：无基准把"agent 构建的结构化知识保真度"当一等测量对象。

## 2. 核心思想

**表示 = 无损基座 + 编译视图（一等公民）+ 维护语义；接口 = 类型化文献操作。**

设计裁决：物化的对象是**负载的答案结构**（照 agent 实际问的问题存），不是文献内容的三元组镜像（照论文内容存）。创新声明不住在记录层（记录层单独看是 KG 投影），住在编译层及其维护语义。

## 3. 架构

**L0 证据层**：逐篇 verbatim span + 表格单元格（带表格坐标）+ provenance。BM25/稠密检索永远保留在此层（召回红线：结构化永不取消访问通道）。

**L1 记录层**：L0 的字段化投影，四个记录族对应四内容轴：配置记录（超参/环境/协议）、结果记录（数值+指标+表格坐标+条件限定词）、谱系记录（方法间取代/改进/组件/复用）、条件记录（qualifier 结构化）。每条记录带条件限定词、认识状态（声明/实测/推导/共识）、归属、verbatim 指针。

**L2 编译视图层**（一等公民）：视图 = 一类负载查询的物化答案结构。六个视图按实测查询目录反推：
1. **对比矩阵**（服务对比/综合查询）：行=方法（经对齐键归一），列=(任务,指标)，单元格=**带条件的主张簇**而非单值，条件掩码参数化（"预算 B 下"是矩阵的一个切片）
2. **谱系 DAG**（服务关系查询）：边=取代/改进/组件/复用；delta 继承在此解析
3. **覆盖地图**（服务缺口查询）：任务×条件空间，有记录=已做格子，缺口=补集——"不存在"首次可查询
4. **方法卡**（服务配置查询）：delta 解析后的完整配置+前置+报告行为+已知坑
5. 概念表（定义查询）
6. 主张-引文索引（引用/证据查询）

**四个关键机制**：
- **对齐键**：跨篇 join 的规范实体（任务/数据集/指标/方法）——视图质量上限，含对齐置信度与"未对齐记录降级留在 L0 可检索"通道
- **条件掩码**：记录的条件限定词成为查询维度
- **Delta 继承解析**：编译期把 "same setup as [14] but X" 展开为完整配置记录（继承字段+覆盖字段+双溯源）——查新零先例
- **失效代数**：每个视图元素带派生轨迹；新论文摄入→轨迹反查→标记失效→局部重算。三类失效：轨迹失效（标准增量维护）、**对齐漂移失效**（实体 split/rename 导致 join 键级联变化）、**认识状态失效**（结果被质疑/撤稿，数据未变但状态变）

**接口层**：类型化操作，每类对应一个查询族：`compare(methods, task, metric, condition_mask)` / `lineage(method)` / `find_gap(task, condition_mask)` / `config(method, task)` / `evidence(claim)` / + `search()` 兜底。对 agent 而言，知识模型的 API 就是知识模型（消费协议=上下文窗口+工具循环）。

## 4. 创新声明（分层且诚实）

| # | 声明 | 依据与边界 |
|---|---|---|
| C1 | **问题定义**：knowledge compilation 是与 multi-hop retrieval 不同的独立问题 | KG-RAG 全系（GraphRAG/LightRAG/HippoRAG2/KAG 等）查询时临时拼装跨文档证据；2024-2026 全部评测协议（HotpotQA/MuSiQue/QASPER/LongMemEval）无跨篇数值聚合/方法谱系/条件查询任务 |
| C2 | **冲突感知编译**：科研文献无法朴素预计算——同方法不同论文报不同数字（条件异且常未声明）、取代声明矛盾、结果不可复现。单元格必须保留分歧/条件/出处的簇结构，而非静默合并单值 | 这是"编译"区别于 SQL 物化视图的核心：编译对象不是关系代数可计算的，编译器必须对抽取噪声鲁棒、对冲突敏感 |
| C3 | **语义失效代数**：对齐漂移失效与认识状态失效超出标准增量视图维护 | IVM 假设 schema 与 join 键稳定；实体 split/rename 级联、数据不变但认识状态变，是文献域特有 |
| C4 | **Delta 继承解析**：编译期展开省略式引用配置 | 查新零先例（"delta citation""same setup as"在科学文本挖掘中零命中） |
| C5 | **负载驱动 schema 方法论**：表示的 schema/物化集/更新语义由实测访问负载反推 | 四要件组合（实测负载/形式化刻画/表示输出/文献域）2026-09 查新真空；CQ 三十年传统用人工拟定问题，未用实测分布 |
| C6 | **表示保真度评测**：把编译产物的正确性当一等测量对象（第五空轴） | LitBench 用图出题不测构建；Lacuna 只测下游代理指标 |
| C7 | **缺失性查询可表达**：覆盖地图补集 | 检索范式原则上无法表达"不存在"；带认识论限定（仅声明"编译语料内未见"） |

## 5. 评测设计

1. **层消融**（直接检验创新承载位置）：L0≈平面 RAG 等价物 / L0+L1≈结构化检索（GraphRAG 对照位）/ L0+L1+L2=完整系统。若 L1 不拉开差距而 L2 拉开，即证明编译层承载创新。
2. **受控 PK**：同 agent 骨架（同 LLM/同工具预算）只换知识访问层：{全文直读/平面 RAG/PaperQA2/OpenScholar/HippoRAG 2/LightRAG/RAPTOR/本系统}。
3. **保真度评测**：视图单元格 vs 人工构造 gold（对齐我们的 gold 构造与四道闸传统）。
4. **E2 扩版**：需求驱动任务集（出题人分离/n≥50/多 judge+IAA/第二域），任务类型与视图类型一一对应。
5. **成本侧边指标**：每查询 token 成本/轮数（对位 Lacuna 的 4 倍口径）。

## 6. 与近邻的差异化表述

- **materialized views/IVM**：编译对象在关系代数内可计算；本设计的编译器要从非结构化文本+表格+省略式引用做语义编译，正确性无保证（故需要 C6 评测与冲突感知 C2）。差异不在"预计算"动作，在编译的语义难度与维护语义（C3）。
- **Lacuna**：预计算了概念元素/方向页，但 (a) 无四轴内容（配置/数值/取代/条件）(b) 无维护语义（无失效/重算）(c) 无冲突感知（概念元素是一句话摘要，无对齐 join）(d) recall 0.028 断崖（引 6-16 vs 专家 ~140）。它是"预计算内容摘要"，本设计是"预计算带维护语义的答案结构"。
- **SciAtlas**：元数据级构建/通用五层/periodic rebuild/自认四轴缺席。它是"为自动化科研建知识底座"的框架占位，本设计是其自认缺失的内容轴与演化机制的落地——正面引用，实验对照可选。
- **KG（含超图）**：物化的是内容镜像；关系查询靠查询时 join；无失效语义；覆盖补集不可表达。表达力上 KG 可表示本设计的一切（作者自认）；差异在一等公民与访问路径，非表达力。

## 7. 风险与局限（自陈）

1. 覆盖地图认识论陷阱：记录不存在≠科学上没人做过，接口必须带"编译语料内未见"限定。
2. 对齐键错误污染视图层：需要置信度+降级通道，但降级多了 L2 退化为 L1。
3. 编译正确性验证是新的评测负担（C6 是贡献也是成本）。
4. 规模：当前语料 2,355 篇单域起步；跨域对齐是未验难题。
5. E2 需求侧证据目前是 12 任务 pilot，扩版待做（出题人分离等五要件）。

## 8. 实施计划（若提案通过）

Phase 1 视图代数形式化+四个核心视图 schema（对比矩阵/谱系/覆盖/方法卡）→ Phase 2 抽取规格+对齐键（复用两遍 harness/gate-verify-fix 循环，重写语义层）→ Phase 3 失效代数 → Phase 4 接口+E2 消融挂钩。
