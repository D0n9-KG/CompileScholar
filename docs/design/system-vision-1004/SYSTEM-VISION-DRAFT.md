## 1. 问题本质

领域级问题（有哪些方法、怎么演化来的、共同局限、哪里有争议、还缺什么）的答案是关于"一组论文"的陈述。要答好，系统要做到四件事：

1. **身份**：同一个方法在几十篇论文里以不同名字、缩写、版本出现，要认成同一个；否则"几篇论文支持"只是在数字符串。
2. **集合**：每条领域级陈述背后的证据集合显式存在，能数、能查、能核。
3. **开放**：永远只读了领域的一部分。系统要知道边界在哪（已知存在但没读的论文、没覆盖的时间段和分支），并能主动扩。
4. **时间**：领域在变，陈述只在某个时间点之前成立。

所以领域地图 = 开放世界、带时间、身份已解析的领域模型；每条领域级陈述是证据集合的函数；地图知道自己的边界，补全模块按边界主动扩张。

## 2. 把四层串起来的关键：读一篇论文，地图得到三样东西

| 得到什么 | 例子 | 进入哪一层 | 现在拿了没有 |
|---|---|---|---|
| 内容 | 主张、结果、局限、设置 | 聚合（族级事实的支持项） | 拿了，但 98% 论文只读摘要 |
| 自我定位 | "本文提出 X，扩展了 Y，针对 Z 的局限" | 身份（X 由本文锚定）、演化边（自述） | 几乎没拿：提出/使用不分，P0-3 只是侧链 |
| 参考文献与引用语境 | "[12] 提出了 Y，但它需要大量标注" | 地图边界（[12] 成为已知未读节点）、演化边（他述）、局限指认 | 只对 130 篇综述的书目做了；普通论文一篇没做 |

综述只是第二、三样特别密的论文。走出"只靠综述"的路：**每篇读过的论文的参考文献和引用语境都在建图**，综述是高密度来源和金标来源，不是唯一来源。

## 3. 目标数据流

```
补全模块（取论文）→ 全文解析（正文 + 参考文献 + 引用标记）
→ 统一抽取（内容 / 自我定位 / 引用语境，一套 schema，带 role）
→ 身份层（论文 id + arXiv 首版日期；方法 = 由提出论文锚定；引用标记 → 论文）
→ 地图（方法节点、族、类型化演化边、已知未读节点、时间）
→ 聚合（族级事实 = 支持集的函数；独立数、条件、as-of 状态由计算得出）
→ 消费（答题：按地图规划、按成员取证、覆盖报告；人看的地图视图；评测导出）
→ 缺口诊断 → 补全模块（循环）
```

### 3.2 族与演化的具体设计要点

- **族成员多来源**：综述章节归属（他述分组）、自述演化（extends Y → 与 Y 同族候选）、结构（共被引 / 文献耦合）、LLM 对成员描述的归纳（field_state 降为来源之一）。多来源一致 → 置信度。
- **演化边**：`{from, to(可多个), type, asserter ∈ self|third_party|survey, quote, date, trigger, changed_dim}`。
  type 对齐 Intern-Atlas（extends/improves/replaces/adapts/uses_component/compares）+ n 元 combines；
  trigger = addresses_limitation 时，链到被指认局限所在的族级事实，可核验"这个局限确有其事"（自述或他人批评）。
- **族级事件**（emerge / split / merge / decline）由成员级边和成员日期派生，不直接让模型标。

### 3.3 补全模块

| 缺口类型 | 怎么发现 | 获取动作 | 成本 |
|---|---|---|---|
| 已知未读成员 | 族内多篇已读论文引用了它 | 按 id 取全文 → 抽取 | 低 |
| 时间前沿 | 族的最新已知成员早于 T | 正向引用（谁引了族成员）+ 时间切片检索 | 中 |
| 未覆盖区域 | 题目/规划落到地图空白 | 先找该区域的综述（高密度建图源）+ 语义检索 | 中高 |
| 已读论文缺方面 | 族级陈述的支持项只有摘要证据 | 补读全文 / 补抽 | 中 |

- 优先级 = 预期改变的领域级陈述（单一来源、有争议、覆盖低的族）× 相关性（在线：题目需求；离线：中心度）÷ 成本。
- 写回带出处：由哪个缺口触发、何时取得（as_of）。
- 覆盖账目：每族"已知成员 n_known（含未读）/ 已读 n_read"。总量估计（capture–recapture）只在校准过后才报（v7 门槛 B 未过）。
- **纪律**：离线生长题目盲；评测答题时的在线补全不写回跨题共享的库（否则等于按题补库）。摊销实验用独立任务流。

### 4.1 CDP 补查后的综合判断

每个组件都有部分先例（U1 闭环有弱形态，U2 有 MPR 句级与 Forer & Hope TACL 2026 跨文档概念共指，U4/U5 被 Intern-Atlas 的标签和宣称碰到）。
没有人做到、也是三份调研共同指向的空位：**领域级结论本身对不对，从没被评测过**——谁提出了什么、族有哪些成员、几篇独立论文支持、
还缺哪些论文、截至某日成立与否。LKM/ScholarStack 只报下游，Intern-Atlas 只评边与链的可达性，没人报身份误并/误拆率及其向领域结论的传播
（非科学领域的先例 2609.08698）。

可做的新实验：Intern-Atlas 的 HF 数据公开不设门（边约 2.5 GB；许可一处 MIT 一处 CC-BY，使用前核清），可以
(a) 用 E1 式抽样审计它的提出者/身份/族归属正确率，(b) 拿它当基线地图跑同一套补全与下游实验。
IG-Bench 仓库有 Hybridization 类型标注（License TBD），可测 n 元组合。

据此主论点 A、B 收敛为一条（见 §5 修订）。

## 5. 主论点候选

- **A（建议）会自己补全的领域地图**：把领域编译成一张身份确定、带时间、知道自己边界的地图；按地图上的缺口分型定向获取并写回；领域级陈述都落在一组可核验的论文上。贡献 = U2 + U4（表示）+ U1（闭环）+ U3（产出）。打在我们真正输的地方（CS2 内容召回、DSB 60.6% 检索层失分）。会场：WWW（Search/RAG 轨或 Semantics & Knowledge 轨）。
- **B 集合有据的领域陈述**：主打 U2 + U3，补全作为"集合怎么填满"。会场偏 ACL。
- **修订（CDP 补查后，建议）A+B 合一：领域级结论要对**。领域级结论取决于身份和边界是否正确；现有大规模学术图谱只在局部（边、主张）或下游评测，
  从未评测这些结论本身。我们做一张身份按引用锚定、带时间、知道自己边界的地图，证明 (1) 它的领域级结论更准（含对 Intern-Atlas 公开数据的审计）、
  (2) 正确的结构让缺口分型、补全检索更准更省（对照平铺 BFS / 模型自评 / Consensus 式临时缺口矩阵 / LLM Wiki 式未命中即补）、
  (3) 答案里的领域级陈述可核验。组合主张，每个组件必须单独消融。

## 6. 决定性实验（A）

1. 补全（核心）：留出综述，给种子（部分参考文献，或某日期前的论文），同预算下比较：闭环、平铺参考文献 BFS（Sahu 式）、共被引/耦合推荐、SPECTER kNN、模型自评缺口（HERO 式）、任务内覆盖引导检索（SciAtlas 式）。指标：综述参考文献召回、族成员归属、点名论文不存在率、成本。金标不完整 → 超出金标的发现做 pooled 判定。
2. 时间前沿：地图冻结在 T，测发现 T 之后、后来被综述归入该族的论文。
3. 摊销：同领域独立任务流，单题召回与成本随任务数的曲线。
4. 下游：DSB（金标参考文献召回 + nugget）、CS2（按 ingredient 类型分层 + 总分非劣）、FieldQA。
5. 组件内在：身份精度与误并/误拆率；演化边对 Intern-Atlas/IG-Bench 金标 + 打乱年份证伪（SciTraj 式）；族对 TaxoBench 协议；支持集人工审计。
6. 消融：−引用锚定身份（换字符串/嵌入身份）、−缺口分型（单一动作）、−写回（只在任务内）、−边界节点。

## 7. 风险

1. 平铺 BFS 很强（Sahu：召回 <20% → >80%），我们多源引文扩展在 CS2 上 −0.010 n.s.。闭环必须在同预算下明显好于 BFS，否则主张不成立 → 先做试点。
2. 金标不完整（人类引用只 51% 判为中等以上相关）→ pooled 判定。
3. 总量估计以前失败过（v7 门槛 B）→ 主报已知边界，不主报总量。
4. 全文获取规模（arXiv HTML 15.5 s/页；共享盘 common-pile 全文据记忆有 30.4 万篇，未复核）。
5. 最近邻（SciAtlas、Intern-Atlas 占位节点）需要读全文正面比较。
6. 语料要换：bulk 随机抽样不构成领域 → 改为若干个连贯领域（综述 + hub 播种，再由闭环生长）。
