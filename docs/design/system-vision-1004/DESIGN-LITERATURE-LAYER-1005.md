## 0. 一句话

人类科学家用文献做三件事：**找**（检索、追引用、判断还缺什么）、**读**（读懂一篇：贡献、方法、结果、设置、局限）、**懂领域**（方法族、演化、谁和谁比、公认局限、前沿、截至某时的共识）。
文献理解层把这三件事都做成智能体可调用的能力。特色在第三件：**领域认知是历时的**，由后续论文对每项工作的描述编译而来，可以回放到任意时间 T。前两件做扎实，是第三件的地基。

## 1. 能力清单（目标态）

| 能力层 | 智能体要什么 | 系统给什么 | 对应人类科学家的哪种能力 |
|---|---|---|---|
| **A 找** | 按主题、按问题、按方法找论文；从一篇论文出发追前人和后人；知道漏了什么 | 混合检索（BM25 + 向量，as_of 截止）；引文图双向遍历；"已知未读"边界；外部检索补全 | 检索、滚雪球、查漏 |
| **B 读（单篇）** | 一篇论文的贡献、提出了什么、怎么做、在哪些数据上用什么指标得到什么结果、和谁比、局限 | 论文卡（自述）：贡献、提出的方法、方法要点、实验设置、**结果表格单元**、局限、引用了谁，每条附原句 | 精读一篇论文 |
| **C 证据** | 某个说法的原文出处，可以逐句核对 | 原句级证据检索，每条带论文 id、节、原句；写作时逐句引用 | 查证、写作引用 |
| **D 懂领域（特色）** | 某方向有哪些方法族、怎么演化、谁是基线、公认局限、前沿、某工作现在被怎么看；截至 T 的状态 | 历时领域认知：族、谱系、论文画像（自述 vs 他述）、族级事实（支持集 / 独立数 / 状态）、认识变迁、边界；全部带 as_of | 领域理解、判断新颖性、选基线 |
| **E 跨论文比较** | 谁和谁比过、在什么任务上、谁声称更好 | **定性比较图**：他述里"被当作基线 / 对比对象""声称优于谁"的汇总，带原句和日期；单篇论文内的结果单元（只在该论文自己的表格内有效）。**不做跨论文数值比较表**（用户 10-05 裁定：实验条件不同，跨论文直接比数值易误导） | 判断该和谁比、谁是强基线 |
| **F 生长** | 库里没有的领域也能用 | 按缺口分型获取（未读成员 / 时间前沿 / 未覆盖区域 / 补读全文）→ 走同一条流水线入库 | 持续跟进文献 |
| **G 交付** | 能被各种智能体直接调用 | MCP 工具 + Python API；答题管线（报告写作）作为内置使用方 | — |

**主论点和能力的关系**：A/B/C/E 是完整文献层的必备能力，在论文里写成"系统组成"；D 是方法贡献，主实验检验的是它；F 支撑开放世界。主实验之外，A/B/C/E 用现成基准做"不退步 / 功能完整"的验证（CS2、DSB、LitSearch 或 ScholarQuest 类检索基准）。

```
L7 grow          缺口分型补全 → 回到 L0/L1                                           [设计已有，待写]
```

### 3.4 更正（10-05，用户指出）：旧系统的几处"降级"是有意取舍，新系统继承原则

| 旧设计 | 看起来像 | 当时的理由 | 新系统怎么继承 |
|---|---|---|---|
| 粗抽 1,105 篇、深抽只 21 篇 | 98% 只读摘要 | 深抽耗时；检索召回的论文远多于能深读的，粗抽保广度、深抽保重点 | **分层抽取**（§3.5）：元数据全量 → 粗抽覆盖领域内全部论文 → 深抽只给重点论文；答题时可按需深读 |
| 外检结果、运行期深读不写回共享 KB | 补全没有闭环 | 防"按题补库"作弊 | L7 只离线生长、不看题目；评测期一律不写回；答题期按需读到的内容只在本题内使用 |
| bulk 层从 6 个类别随机抽样 | 凑不成领域 | 题目盲的热启动：不能按基准题目挑论文 | 原则保留：**一切选择规则只用语料统计，不用基准标注**；做法换成"全量 CS 元数据 + 按引用统计分层" |

**我引入的违规，已更正**：首个切片 `first_field.py` 用 ScholarCatalyst 的正例和难负例当抽取目标，这违反题目盲（工具的库里会只有金标附近的论文）。改为题目盲选择：
- 引用层对全部 10.9 万篇全文运行。不用 LLM，约 0.02 s/篇，不存在挑选问题。
- 抽取目标按领域（类别）和语料内被引次数分层，与任何基准标注无关。
- 基准只决定"在哪个领域、哪个时间点上评测"，不决定"抽哪些论文"。

更多旧取舍的系统梳理见 §3.6。

### 3.6 旧系统有意取舍逐条判定（10-05，依据决策档与记忆原文）

判定只看"当时的理由现在还成不成立"，成立的原则在新系统里继承。

**理由仍成立 → 继承**

| 取舍 | 当时的理由（原文数字） | 新系统中的位置 |
|---|---|---|
| 分层抽取：粗抽保广度，深抽保重点 | 全量抽取约 2 min/篇，粗抽 11–16 s/篇；设计值 Tier-1 2–5k 篇、Tier-2 200–500 篇 | §3.5 T0–T2。实际深抽只做到 21 篇，远低于设计值 → 新 T2 先定 500 篇的规模 |
| 是否深读由确定性规则决定，且不在答题循环里做 | "never inside the latency-bound answer loop" | T2 由题目盲的确定性规则离线选出；答题期按需读，只在本题内使用 |
| 表格用确定性解析，LLM 只提列语义 | LLM 抽表有四种可复现的失效（只抽代表行、空壳、融合格、列串位） | 结果遍：旧 table_channel 迁入 |
| 综述的转述不进事实层 | 用户裁定 | 综述说的话一律是他述（kind=other），不当作被引论文的自述或结果 |
| 视图层是确定性编译，不用 LLM 做综合 | 秒级、零 token | L4 编译确定性；LLM 只用来命名族和写定义 |
| 固定流程的答题管线（不用 ReAct） | 旧循环 2,784 行补丁堆 | 内置答题管线仍是固定流程，规划和取证改为调用 L6 工具；外部智能体通过 MCP 自主调用 |
| 先检索再规划（probe） | 跑题小节从 20/74 降到 10/67 | 规划前调用 `field_map` / `search_papers` |
| 筛选用"剔除列表"，存疑不剔，剩不到 5 条就回退 | 保留列表版曾把 245 条全拒；Multi 严格 F1 +0.104 | 原样保留 |
| 不做跨节去重 | 去重后 AP −0.089 | 原样保留 |
| 外检直连 Sciverse + 令牌桶 | 30 req/min 账户限额；分层扇出时 15/45 查询为空 | L7 / 找能力的外部后端，原样保留 |
| 知识截止下推到服务端 | 单页 10 条，客户端事后过滤只剩 3–4 条 | Sciverse 侧保留年粒度；本系统内部按天截止 |
| 引文扩展只收共引 ≥2 且有摘要的 | 精度 5.8% 对 0.7% | `citations_of` 外部补充与 L7 沿用 |
| OpenAlex 批量、S2 冷却、同一时刻只跑一个用 S2 的任务 | S2 20/20 次 429；OpenAlex 每天 10k credits | sources 层原样保留 |
| 全程本地 27B；并发 48；单题限时 | 旗舰模型同等规模不可行；瓶颈在外部 API | 原样保留（实测聚合约 720 tok/s） |
| DeepSeek 判分；存档答案按同一判分器重判 | Gemini 地区 403；快 20–30 倍 | 原样保留，论文中披露 |
| KB 静态快照、多次运行、答题期不写库 | 小边际的结论要带方差；"永不按题补库" | 原样保留 |
| 题目盲热启动 | demand 驱动被判作弊 | 原则保留；做法改为全量元数据 + 按引用统计分层 |

**理由已被实测推翻 → 改掉**

| 取舍 | 推翻它的证据 | 新做法 |
|---|---|---|
| 注册表一次 LLM 全表归并 + n-gram 确定性绑定 | matched 0 / new 15,100；LEADING、WILL、ref[227] 等误绑 | 方法身份锚定提出它的论文；别名来自自述与他述；泛名标 generic |
| 方法族 = 综述 taxonomy 名做嵌入合并 | 消融 Δ≈0；4,164/4,164 条证据都是原记录 | 族由引用行为决定（共引组、类别、谱系），按独立施引论文数加权 |
| 长片段引用（snippet 最长 1,200 字符） | 截到 240 字符后 G −0.117，优势来自片段长度 | 证据片段 = 原句（句子级），长度在论文中报告 |
| harness 不重跑 | 截止未执行时 42/93 引了 2026 年的论文 | 已重跑；规则改为"截止规则变化时必须重跑" |
| 约 1,000 词预算的旧依据（"长度分封顶"） | 官方配置没有长度项 | 保留为按 dev 调出的超参，论文中如实披露 |

**没找到原文理由**：snippet 1,200 字符、每篇最多 2 条（per_paper=2）、hub 从 36 篇降到 21 篇。前两项在新系统的统一索引里重新调参（只在 dev 上调）；hub 名单由 T2 的选择规则取代。

### 3.5 分层抽取（新系统的一等设计）

| 层 | 覆盖 | 内容 | 成本（实测吞吐约 720 tok/s） |
|---|---|---|---|
| T0 元数据 | 全部 104.6 万篇 | 标题、摘要、作者、首版日期、类别 | 0 |
| T1 粗抽（自述卡，摘要级） | 领域内全部论文 | 贡献、提出、设置、局限、主要发现 | 约 300 输出 token/篇 → 约 8,000 篇/小时 |
| T2 深抽（全文） | 重点论文：领域内被引最多、族的代表成员、题目盲选出 | 方法要点、结果单元（表格）、完整自述 | 每篇约 1 次自述 + 约 4 张表的语义对齐 |
| R 他述 | 被引对象，按被引次数分层封顶（每对象 ≤30 对） | 被引者做了什么、角色、类别、局限、比较 | 约 2.1 万对/小时 |
| 运行期 | 答题时检索到、库里只有 T0/T1 的论文 | 按需深读，只在本题内使用 | 计入单题时延 |

|---|---|---|---|
| N1 | 全文结构化（L1 扩展） | 节、段落、句子、表格、图注，编号可引用 | Markdown 和 HTML 两种来源统一成 `doc_units(paper, unit_id, kind, section, text)`；引用标记已有 |
| N2 | 结果单元 | （任务, 数据集, 指标, 方法, 值, 方向, 设置, 来源论文, 来源表格行） | 旧 table_channel 先做确定性解析，27B 只做"列 → 指标 / 数据集、行 → 方法"的语义对齐；值必须是原表格单元格 |
| N3 | 论文卡 | 贡献、提出、方法要点、设置、主要结果、局限、引用了谁 | 自述遍补上方法要点与发现；结果来自 N2 |
| N4 | 实体身份 | 方法（锚定提出论文）、数据集、指标、任务 | 别名由自述与他述共同提供（"[n] 提出了 X"）；数据集和指标从结果单元与设置里来 |
| N5 | 谱系边与族级事实 | 谱系：自述关系 + 他述关系，两端是论文；族级事实：性质 / 局限 / 比较，带支持集、独立数、状态 | 支持集独立性：同作者合并计数；状态由支持集计算，不由 LLM 判定 |
| N6 | 认识变迁事件 | 重新归类、范围收窄、暴露局限、被替代、成为默认组件 | 由论文画像随 T 的变化检测，带日期与证据句 |
| N7 | 定性比较图 | 对象 A 被谁当作基线 / 对比对象、在什么任务上、谁声称优于它，按日期排列 | 只来自他述（function=baseline/contrast、role=compares）与比较句原文；**不跨论文对齐数值**（用户 10-05 裁定）。结果单元只在单篇论文卡内展示，不与别的论文的数字放在一起 |
| N8 | 多粒度检索 | 论文级、段落级、表述级；BM25 + 向量；as_of；按引文图扩展 | 复用 kb/index.py 的混合检索与 RRF；向量用本地 qwen3-embedding-8b |
| N9 | 证据工具 | `find_evidence(claim, as_of)` 返回原句，`read(paper, section)` 返回原文 | 写作与核验共用 |
| N10 | 补全（L7） | 缺口 → 获取 → 同流水线入库 | 外部通道：OAI-PMH、arXiv HTML、Sciverse、OpenAlex |
| N11 | MCP 封装与答题管线切换 | 工具集对外；答题管线成为内置使用方 | 旧管线保留为对照组 |

## 6. 实施顺序（全系统一起推进，不留割裂）

1. **L1 扩展**：doc_units（节、段、句、表）。citations 阶段改为在 doc_units 之上运行，同一份解析结果供后续所有层使用。
2. **L2 补齐**：自述遍补"发现 / 方法要点"；结果遍（旧 table_channel 迁入 + 语义对齐）；三遍共用 schema 与质量闸门。
3. **L4 补齐**：实体身份（N4）、谱系边与族级事实（N5）、比较表（N7）、认识变迁（N6）。
4. **L5/L6**：多粒度索引（迁入 kb/index.py）+ 全部工具 + MCP；答题管线切换为调用工具。
5. **验收**：
   - 内在：E1b 解析、抽取闸门、TaxoBench、留出综述；
   - 功能完整：CS2 非劣（界 −0.02）、DSB、检索基准；
   - 主实验：ScholarCatalyst、MasterSet、Old Ideas 等。
6. **L7 补全**：最后接入；评测期间不写回。

首个领域切片（ScholarCatalyst cs.LG，828 篇目标）在第 1–4 步之间持续作为集成测试数据：每加一层，就在它上面跑通。
