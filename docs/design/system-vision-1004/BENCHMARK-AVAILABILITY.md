# 候选基准可得性核验（2026-10-05）

核验方式：arXiv abs/HTML 页（curl）、HF 公开 API（`/api/datasets/{id}`、`/tree/main`）、GitHub raw 文件、CDP 浏览器（GitHub 目录树、HF gated 页、OneDrive、Google 发现层）。超过 200 MB 的文件只用 tree API / HEAD（`X-Linked-Size`）确认存在与大小，没有下载。小文件（≤35 MB）下载后实际解析计数。每条结论后的"实测"指本次实际打开的页面或 API 响应。

评测目标（下表最后一列）：给科学智能体接一个按时间组织的领域认知工具（方法族、演化、每个工作被后人怎么描述、已知未读论文）之后，表现是否变好。接入方式三类：**检索工具**（agent 调用）、**输入表示**（替换/补充喂给模型的历史文献表示）、**只评地图**（直接拿我们的领域地图对金标打分）。

## 分组

### 可直接用（数据公开免申请、许可明确）
- **ScholarCatalyst**：首选。作者标注金标、每题时间截止语料、2025–2026 源论文、自带 toolcall agent，接检索工具做 A/B 最直接。CC BY-NC 4.0，学术使用可。
- **IdeaForecastBench**：作为"输入表示"对照（我们的地图替换 history compression）。代码 MIT，语料按 arXiv 原许可；判分依赖 LLM judge，可换本地端点。
- **PreScience**：prior work selection（客观 nDCG）作检索工具评测；contribution generation 作输入表示评测（LACER 需 OpenAI）。ODC-BY + Apache-2.0。
- **TaxoBench（Bottom-Up）**：只评地图，零 API；CC BY-NC 4.0。注意记忆泄漏。
- **Proof of Time**：MIT，Inspect + Docker；可挂工具，但与领域认知相关的只有 Research Evolution 一族。
- **LitSearch / SurGE**：即下即用的客观检索 / 结构金标，适合健全性对照；时间早、泄漏高。LitSearch 数据许可未在 HF 卡声明（代码 MIT）。

### 需申请或需联系作者
