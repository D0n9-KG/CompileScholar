## 1. 主论点

**历时领域认知（Diachronic Field Cognition）**：把"领域怎么描述每个工作"编译成可回放到任意时间 T 的领域认知，作为工具接给科学智能体。

- 一篇工作在领域里的位置，由后续论文的描述（他述）不断重写，不等于发表时的自述。这一现象已被确立（Mei & Zhai 2008，Elkiss 2008，Divoli 2012，Chen 2025），本文只当动机引用。
- 智能体缺的是"截至 T 领域怎么看"：参数记忆分不清时间，靠提示"假装不知道"也做不到（2601.13717）；现场检索只能拿到片段；RAP（2609.10092）把恢复时间局部状态列为主要瓶颈，但每次查询都现场压缩。
- 方法：
  - 抽取：自述按每篇论文抽，他述按每个引用标记抽；
  - 解析：引用标记 → 论文、日期，确定性完成；
  - 编译：cognition(T) = 所有 ≤T 的表述汇总而得的纯函数，内容包括族、定位、演化、共同局限、比较对象、边界节点；
  - 在此之上检测类型化认识变迁；
  - 自述与他述的差异并列给出，不判对错；
  - 补全作为组件。
- 用途：
  - 主：给科学智能体的截止查询工具；
  - 次：给初学者的视图。

## 2. 划界（已被占 → 只引用）

- 他述 ≠ 自述、随时间变化：引用摘要一脉、科学计量学（Merton 吸收湮没，Cozzens 1982）。
- 单篇他述汇总、带时间的影响摘要：Arnaout/Sternlicht/Hope/Gurevych 2505.14838（威胁最大：无结构化、无领域级、无变迁分型、无截止作答、无智能体；年份归属仅 0.59）。另有 SECite 2601.07939。
- 给人看的他述：CiteRead、scite（含 MCP 与日期过滤），以及 Relatedly、Synergi、Action Science Explorer、GoAI。
- 给智能体的"自述 + 他述"画像：AgentExpt 2511.04921（只覆盖基线与数据集，无时间）。
- 方法演化边：Intern-Atlas 2604.28158（只取施引论文的单次表述，每对判断一次，不聚合，不报边精度，无时间维）。
- as-of 知识库（金融，2608.12984）；多 harness 即插即用配对评测（SkillsBench 2602.12670）：都写成实验方法，不写成贡献。
- 需要持续监控 UKP 组（Gurevych）。

## 3. 贡献（草稿）

1. 历时领域认知的表示与编译：双源表述 + 确定性引用/日期解析 + cognition(T) 纯函数 + 类型化认识变迁检测 + 边界节点。
2. "截至 T 领域怎么看 X"的评测：自建基准（留出综述出题，综述不作表述来源）。
3. 实证：
   - 认识变迁的分布与时间规律；
   - 在多个智能体上的下游收益，含按时间截止作答；
   - 对照臂：现场压缩、只用自述、LLM 直接生成。

## 4. 验证

- **主实验**：自建截止基准，加 PreScience、IdeaForecastBench、Proof of Time。臂设置：无 / 现场压缩（RAP 式）/ 只用自述（Intern-Atlas 式）/ 完整 / −时间 / −他述。智能体：自家管线、Claude Code 类 harness、GPT-Researcher。
- **机制与描述**：
  - 变迁分布；
  - 自述与他述的差异率；
  - 边界节点对补全召回的贡献；
  - 日期与引用解析精度，对照 0.59。
- **保底**：CS2 非劣。
- **次要**：初学者用户研究。12–16 人，被试内设计；任务为"把 T0 旧综述更新到今天"；用时间性理解客观题测，金标来自后来的综述；对照为同语料、不带时间的他述汇总。

## 5. 风险

1. 他述会走样（Greenberg 2009；引用错误率约 25%）：每条汇总都能回到原句，自述与他述并列，表述为"领域的认识"而非"事实"。
2. "变成默认组件"在引用里看不到：补正文中不带引用的提及频率。
3. 现场压缩可能已经够好：必须设这一臂，持久结构要证明多出的价值（跨查询累积、边界、变迁）。
4. UKP 组近邻：划界写在相关工作第一段。
