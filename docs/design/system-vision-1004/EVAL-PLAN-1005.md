> 原则：用户要求优先用现成基准、不做大规模人工标注。依据：BENCHMARK-AVAILABILITY.md（逐个实测可得性）、
> SCI-INNOVATION-EVALS.md（创新类评测）、SCI-AGENT-NEEDS.md（顶尖科学智能体的五类领域认知缺陷）、NOVELTY-AGENT-DOWNSTREAM.md。
> 所有智能体实验都做配对比较：同一智能体分别在"不接 / 同预算平铺检索 / 每次现做摘要 / 接我们的工具"四种条件下跑。
> 后两个对照是 Old Ideas、SCOPE、RINI 共同提出的要求：给更多文本没用，增益必须来自结构。

## 只评地图（零 API）

- **TaxoBench Bottom-Up**：用 ARI / V-Measure 评方法族的划分。CC BY-NC。风险：72 篇高被引 LLM 综述很可能已被模型记住；数据里只有论文标题，需要先做标题对齐。
- **SciPaths**（2605.14600）：评谱系和前置贡献，专家金标，MIT。数据可得性尚未实测。
- 我们自己的 P1 / P2 作描述性证据：P1 是认识变迁的统计，P2 是"他述带有自述没有的信息"的前提检查。

## 保底

- **CS2**：已有冻结的 test 数字，只要求不变差。
- **DSB**：保留作次要。它测"该引的论文找没找到"，与 PreScience 部分重合。

## 不用

- SurveyBench：没有客观金标，没有许可，只有 20 题。
- AutoSurvey：是生成框架，不是评测基准。
- ScholarQuest：没有许可，检索后端拿不到。
- SciNet：金标未发布。
- IG-Bench：许可 TBD，题目里几乎找不到可以挂工具的位置。
- CiteME：数据需要用户本人同意 gating 才能下载，只有 130 题，数据较旧。可选。
- LitSearch、SurGE：数据泄漏严重，最多作健全性对照。

## 对系统范围的影响

上述基准覆盖的是 cs.AI / LG / CL / CV / IR 这一大片，时间跨 2018–2026，不是两三个窄领域。因此：
- 领域认知需要建在大规模 CS 语料上，并且能按任意日期切片。可用的现成语料：
  - IdeaForecastBench：108,768 篇 CS 全文 Markdown（2023-01..2025-10，已含 MinerU 转换）；
  - 共享盘的 arXiv CS PDF；
  - ScholarCatalyst / PreScience 各自的候选语料（标题 + 摘要 + 日期）。
- 他述的来源：
  - 从全文里确定性地切出引用句（LaTeX 或 Markdown 中的引用标记 → 参考文献 → 论文 ID），这一步不用 LLM；
  - 只对被引次数多的论文做 LLM 汇总（族归属、定位、局限、认识变迁）。
  - 成本主要花在第二步，可以按"被基准候选池用到的论文"来限定范围。
- 工具接口按基准的需求设计：
  - 某方向的方法族与代表工作；
  - 某工作被后人怎么描述（截至 T）；
  - 与给定想法最相近的已有工作及其贡献；
  - 某方向常用的对比基线；
  - 某方向截至 T 的公认局限与开放问题。
