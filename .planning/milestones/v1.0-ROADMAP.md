# Milestone v1.0: Scientific Reasoning Compiler Pilot

**Status:** SHIPPED 2026-04-02
**Phases:** 1-6
**Total Plans:** 16
**Audit Status:** `tech_debt`

## Overview

v1.0 turned LogicKG's existing paper and textbook workbench into a bounded but real scientific-reasoning compiler pilot.

The shipped loop is now:

- `RoutePacket`
- `L1 HistoricalEnvironmentSnapshot`
- grouped `RouteState` package (`support / alternative / held_out`)
- replay inspection and failure taxonomy
- reviewed `DecisionPriorCard / AntiPatternCard`
- audited `DecisionEpisode` export

The milestone stayed intentionally conservative. It proved the end-to-end workflow on a bounded jamming slice, kept audit boundaries explicit, and preserved real remaining debt instead of polishing the story into a false "fully generalized dataset" claim.

## Milestone Summary

**Key Accomplishments:**

- Shipped the first real bounded `RoutePacket` and replay workflow for LogicKG's scientific-reasoning direction.
- Converted `L1 Historical Environment` from design-only intent into a typed snapshot that downstream replay logic can consume.
- Standardized grouped multi-route packaging and inspection, allowing replay, prior, and episode artifacts to be audited separately.
- Added a replay failure taxonomy and kept same-slice reruns honest about unchanged debt.
- Added reviewed prior / anti-pattern bundles instead of collapsing review state into replay prose.
- Shipped an audited `DecisionEpisode` export path and verified route-family anti-pattern carryover on real artifacts.

**Key Decisions:**

- Keep `L2` as the single-paper evidence layer and build `L3/L4` as multi-paper historical compilation layers.
- Use replay and audit artifacts to decide the next engineering move instead of expanding `L2` blindly.
- Keep review bundles separate from replay bundles and export bundles separate from both.
- Prefer conservative audit truth over optimistic carryover stories.
- Use stable `route_family_id` matching for reviewed anti-pattern carryover when route variants are in the same family.

**Issues Resolved During v1.0:**

- Missing packet / replay boundaries were replaced by stable JSON artifact contracts.
- `L1` stopped being placeholder-only and became a real replay input.
- Replay quality inspection and package validation are now first-class artifacts.
- The Phase 6 anti-pattern carryover mismatch is resolved for the bounded jamming slice.
- Milestone verification and validation coverage is now backfilled across all six phases.

**Issues Deferred To The Next Milestone:**

- Promote the current bounded jamming packet, replay, review, and export bundles from `tmp/` into committed canonical assets.
- Run at least one cross-topic Phase 03 -> 06 validation slice.
- Strengthen sparse support density for package-level prior acceptance.
- Resolve the original Phase 1 packet entries that still lacked resolved local trace exports during the first live pilot.

**Technical Debt Still Open:**

- The same-slice Phase 4 rerun stayed flat, so the real owner queue remains.
- Package-level prior review is still intentionally conservative because support density is thin.
- The current successful pilot is bounded to the jamming slice and should not be treated as a generalized dataset pipeline yet.
